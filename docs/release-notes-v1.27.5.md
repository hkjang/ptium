# Ptium v1.27.5

지난 판에서 **"이 키가 언제 멈추는가"** 를 API 키 화면이 잘못 말하고 있던 것을 고쳤습니다.
같은 질문을 하는 자리가 하나 더 있습니다 — **공유 링크**입니다.

## 기한이 지난 링크가 "열려 있는 링크"에 섞여 있었습니다

링크에 기한을 주면 그 날이 지나는 순간 열리지 않습니다. 그런데 목록은 **회수되었는지만**
보고 있었습니다. 그래서 사흘 전에 끝난 링크가 이렇게 보였습니다 —

```
만료 표시 점검 · 3일 전까지 · 0회 열림      [회수]
```

`3일 전까지`는 문법적으로는 맞지만, **"최근에 쓰던 링크"처럼 읽힙니다.** 옆에는 회수
버튼까지 있어서, 지금 살아 있는 링크로 보입니다. 무엇이 아직 밖에 나가 있는지 확인하려고
이 목록을 보는 사람이 **이미 죽은 링크를 다시 건네줄 수 있었습니다.**

## 상태를 그대로 말합니다

```
만료 표시 점검 · 만료됨 · 3일 전 · 0회 열림     ← 회수 버튼 없음, 회수된 링크와 같은 흐린 표시
```

- **회수됨** — 사람이 거둬들인 링크
- **만료됨 · (언제)** — 기한이 지나 스스로 멈춘 링크
- **…까지 / 직접 회수할 때까지** — 아직 열리는 링크

회수 버튼은 **아직 열리는 링크에만** 붙습니다. 거둘 것이 없는 링크에 거두는 단추를 두지
않습니다.

## 검사

- 네 가지 상태(기한 없음 · 기한 남음 · 기한 지남 · 회수됨)를 단위 테스트로 고정했습니다.
  기한 지남 판정을 되돌리면 그 자리에서 실패합니다.
- 화면 훑기가 기한 있는 링크를 만들어 그 줄이 **언제까지인지 말하는지**, 그리고 아직
  열리는 링크에 **회수 단추가 있는지**를 봅니다.
