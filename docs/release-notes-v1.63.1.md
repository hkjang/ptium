# 1.63.1 — 없는 장으로 가는 링크는 파일에 쓰지 않습니다

세 장짜리 덱에서 `[9장 참고](#9)` 라고 쓰면, 내보낸 `.pptx` 안에는
`ppt/slides/slide9.xml` 을 가리키는 관계가 적혔습니다. 그 파일은 패키지 안에
없습니다. 아무도 따라갈 수 없는 링크이고, 읽는 쪽에서 파일이 깨졌다고 해도
할 말이 없습니다.

흔한 일입니다. 링크를 써 둔 뒤에 장을 지우거나, 번호를 어림으로 적으면
그렇게 됩니다. 그리고 아무 말도 하지 않았습니다.

- **파일** — 덱에 없는 장을 가리키는 점프는 관계를 쓰지 않습니다. 글자는 그대로
  그려지고, 링크만 붙지 않습니다. 이 제품이 따라갈 수 없는 다른 주소를
  다루는 방식과 같습니다. 발표자 노트도 같습니다.
- **있는 장으로 가는 점프는 그대로입니다.** `#2` 는 여전히 눌러서 넘어갑니다.
- **측정** — 슬라이드의 글자든 노트든, 없는 장을 가리키는 링크를 찾아
  알려 줍니다: `"9장 참고" jumps to a slide this deck of 3 does not have`.

## 확인

- 세 장짜리 덱을 내보내 패키지 안의 모든 `.rels` 를 훑어, 들어 있지 않은
  슬라이드를 가리키는 관계가 하나도 없는 것을 확인했습니다.
- `#2` 관계는 그대로 남아 있고, "9장 참고" 라는 글자도 슬라이드에 그대로
  있습니다.
- 고침을 되돌려 `slide9.xml` 관계가 다시 나타나는 것을 확인했습니다.
