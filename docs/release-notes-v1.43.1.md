# Ptium v1.43.1

**측정이 스스로 정의한 것만 지적하게 했습니다.**

## 규칙이 자기 설명과 달랐습니다

`orphan` 지적의 설명은 이렇습니다 — *"한 단어나 한 음절만 남은 줄"*. 그런데 실제
조건은 **마지막 줄이 한 줄 폭의 30% 미만**이면 무조건이었습니다.

한국어 제목이 이렇게 나뉘면:

```
사내 PostgreSQL 전환 타당성
검토 결과                      ← 28%, 지적 대상
```

`검토 결과`는 한 단어가 아니라 **두 단어짜리 구**이고, 저 길이의 제목이 나뉘는
정상적인 방식입니다. 영어도 마찬가지로 `to cloud spend` 같은 꼬리를 지적했습니다.

## 이제

마지막 줄에 **단어가 둘 이상이면 지적하지 않습니다.** 남은 조건(폭 30% 미만)은
그대로입니다.

같은 브리프 여섯 개로 잰 결과:

| | 지적 | 지적받은 제목 |
| --- | --- | --- |
| 이전 | 4건 | `사내 PostgreSQL 전환 타당성 검토 결과` 포함 |
| 지금 | 3건 | 모두 `방안`·`로드맵`·`대응` 처럼 **한 단어만 남은** 경우 |

세 덱이 100점이 됐습니다.

작은 차이지만 방향이 중요합니다. 고칠 것이 없는 곳을 지적하는 측정은 읽히지 않게 되고,
읽히지 않는 측정은 진짜 결함도 함께 묻습니다.

## 확인한 것

이 릴리스에서 함께 검증한 1.43.0(템플릿 서체)의 영향 범위:

- **내장 디자인 50개 전부** 1.42.1과 결과가 동일 — 자리표시자와 테마가 일치하는
  템플릿에는 아무 영향이 없습니다.
- 사용자의 실제 템플릿 11개 중 **2개**가 `['Arial','Calibri']` → `['Calibri']` 로
  고쳐졌고, 나머지는 그대로입니다.
- 디자인을 바꾸면 색이 실제로 따라옵니다(자두 `8B5CF6` → 숲 `17A574`).
