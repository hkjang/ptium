## 세는 말이 가리키는 말로 읽히는 자리

v1.56.2에서 고친 것은 하나였습니다. 제품이 내는 한국어 메시지에서 `%d장`을 쓰는
자리를 모두 훑었습니다. 대부분은 안전했습니다 —

* `이 덱은 %d장입니다` · `%d장에서 %d장으로 줄입니다` · `%d장까지만 허용합니다`
  → 앞뒤 말이 개수로 묶어 줍니다
* `슬라이드 %d장 모두에` → `슬라이드`가 앞에 있어 개수로만 읽힙니다

**세 자리가 그 보호 없이 있었습니다.**

```
"%d장은 모델에게 다시 쓰게 했지만 나아지지 않아 그대로 두었습니다"   ← 개수
"%d장은 다시 쓸 시간이 없었습니다"                              ← 개수
"문서가 길어 %d장은 가져오지 않았습니다"                          ← 개수
```

앞의 둘은 **손으로 고쳐야 할 슬라이드**를 알려 주는 말입니다. "3장은…"이라고 하면
읽는 사람은 3번 장을 열고, 거기서 아무 문제도 찾지 못합니다.

## 개수가 아니라 어느 장인지 말합니다

고쳐야 할 장을 알려 주는 말이라면, 몇 장인지보다 **어느 장인지**가 쓸모 있습니다.
다시쓰기 반복문은 이미 그 자리를 알고 있었습니다.

```
2·5·6번 슬라이드는 모델에게 다시 쓰게 했지만 나아지지 않아 …
4번 슬라이드는 다시 쓸 시간이 없었습니다 …
슬라이드 7장은 다시 쓸 시간이 없었습니다 …          (여섯 장이 넘으면 개수로)
```

네 언어 모두 같게 했습니다 — `Slides 2, 5 and 6` · `2·5·6 枚目` · `第 2·5·6 页`.

문서 가져오기의 것은 잘려 나간 뒷부분이라 자리를 말하는 것이 도움이 되지 않으므로,
`슬라이드`를 앞에 붙여 개수로만 읽히게 했습니다.

## 고치면서 검사가 두 가지를 잡았습니다

**조사.** 한국어의 은/는은 앞 글자에 따라 갈립니다. `4번 슬라이드`는 모음으로,
`슬라이드 9장`은 받침으로 끝나므로 문장에 조사를 박아 두면 **"슬라이드은"**이 나옵니다.
앞말을 보고 고르게 했습니다.

**영어 수 일치.** `Slide 4 were sent back` — 한 장일 때는 `was sent back … it was
left`가 되어야 합니다.

둘 다 제가 이번에 새로 낸 것이고, 둘 다 **검사가 먼저 잡았습니다.**
