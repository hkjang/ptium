# Ptium v0.30.0

## 슬라이드가 있는 덱은 초안이 아닙니다

소스로 쓴 덱, 파일에서 가져온 덱이 라이브러리에서 계속 **초안**으로 보였습니다. 상태가 덱이
**무엇인지**가 아니라 **어떻게 만들어졌는지**를 기록하고 있었던 것입니다. 슬라이드가 들어 있는
덱은 완성된 덱입니다. 이제 소스에서 슬라이드를 저장하면 상태가 완료로 바뀌고, **생성이 진행
중인 덱은 자기 상태를 지킵니다.**

## 전수 점검이 왕복 전체를 따라갑니다

`deep.py`가 이제 한 바퀴를 통째로 돕니다.

1. 덱을 쓰고 → 2. `.pptx`로 내보내고 → 3. **그 파일을 템플릿으로 올리고** → 4. 그 템플릿에
생성하고 → 5. **그 파일을 덱으로 다시 가져옵니다.**

비어 있는 데이터베이스에서도 스스로 덱을 만들어 시작하므로, 갓 배포한 인스턴스에도 그대로
돌릴 수 있습니다. 가져온 덱의 결함 수까지 확인합니다(현재 0).

## 오프라인 설치

```bash
gzip -dc ptium-0.30.0.tar.gz | docker load
sha256sum -c ptium-0.30.0.tar.gz.sha256
```
