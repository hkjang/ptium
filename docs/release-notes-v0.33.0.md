# Ptium v0.33.0

## 다듬는 중이라고 말합니다

**AI로 다듬기**를 누르면 편집기가 기다리는 화면으로 바뀌는데, 그 화면이 "슬라이드를 생성하고
있어요"라고 말했습니다. 이미 가지고 있는 덱 위에서 그 문장은 **덱이 교체되는 중**이라는 뜻으로
읽힙니다. 이제 슬라이드가 있는 덱이면 **"덱을 다시 쓰고 있어요 — 숫자와 사실은 그대로 두고
제목·문장·구성을 다듬는 중입니다"**라고 말합니다.

브라우저로 전 과정을 확인했습니다: 편집기에서 **AI로 다듬기** → 기다리는 화면 → 모델 응답 →
편집기 복귀. 결과는 제목이 주장하게 바뀌고, 리드가 붙고, **모든 장에 발표자 노트**가 생겼으며
숫자는 그대로였습니다.

## 소개 페이지가 제품을 따라잡았습니다

프로젝트 소개 페이지가 아직 **v0.1.0**을 알리고 있었고, 5단계 이야기는 "pptx 다운로드"에서
끝났습니다. 가져오기도, 다듬기도, 편집도, 발표도, 그리고 내보낸 파일을 값지게 만드는 것들
(진짜 표·노트·페이지 번호)도 없었습니다.

한국어·영어 두 페이지를 지금의 제품으로 다시 썼습니다. 기능 여섯 가지는 **회사 템플릿 그대로 ·
이미 있는 자료 가져오기 · AI로 다듬기 · 그려 보고 재는 생성 · 구글 슬라이드급 편집 · 폐쇄망에서
완결**이고, 다섯 단계는 사람들이 실제로 시작하는 곳에서 시작합니다 — **브리프, 또는 이미 쓴 덱**.

## 오프라인 설치

gzip -dc ptium-0.33.0.tar.gz | docker load
