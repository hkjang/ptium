# Ptium v1.10.7

## 발표자 노트에 쓴 링크가 주소를 잃고 있었습니다

v1.10.3 에서 링크를 넣으면서 문단을 **런으로 쪼개는** 일은 모든 글에 적용됐는데, 링크를
매달 관계(relationship)를 둘 곳은 **슬라이드에만** 있었습니다. 발표자 노트는 슬라이드가
아니라 별도의 파트라서, 노트에 `[분기 보고서](https://…)` 라고 쓰면 이렇게 됐습니다.

- 화면에는 **"분기 보고서"** 만 남고
- **주소는 사라졌습니다** — 대괄호도 주소도 없이

마크업이 그대로 찍히는 것보다 나쁩니다. 적어 둔 곳이 거기 한 군데였는데 그게 없어지니까요.

이제 **노트가 자기 링크를 자기 관계로 가집니다.** 파워포인트 형식으로 읽어 확인했습니다:

```
notes: '근거는 '      link=None
notes: '분기 보고서'   link='https://reports.example.com/q3'
notes: '에 있습니다'   link=None
```

같은 이유로 슬라이드에 그려지는 **`!source` 출처 줄** 도 링크를 답니다. 그 줄은 슬라이드
위에 있으니 슬라이드의 관계를 쓰면 되는데, 지금까지는 이 줄만 런을 쓰지 않고 글자를
그대로 그리고 있었습니다. 미리보기도 같은 줄을 같은 모양으로 그립니다.

## 링크가 되는 곳 (전부)

요점·리드·제목·캔버스 글상자·`!source` 줄·**발표자 노트**. 덱이 글을 써 내보내는 모든
곳입니다.
