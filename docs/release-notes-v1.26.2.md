# Ptium v1.26.2

지난 판에서 개인화 화면과 관리자 화면이 **저장된 톤·언어를 그대로 보여 주도록** 고쳤습니다.
같은 값을 쓰는 화면이 하나 더 있었습니다 — **덱을 실제로 만드는 화면**입니다.

## 생성 화면은 고치지 않았습니다

생성 화면의 톤·언어는 개인 기본값에서 시작합니다. 그런데 목록은 여전히 정해진
몇 개였고, 목록에 없는 값을 가진 `select`는 **첫 항목을 대신 보여 줍니다.**

```
저장된 톤 'concise' · 언어 'fr'
생성 화면:  발표 톤 "전문적"   언어 "한국어"     ← 실제로 생성에 쓰이는 값은 concise / fr
```

**화면에 적힌 것과 다른 톤으로 덱이 쓰였습니다.** 값 자체는 제대로 전달되고 있었기
때문에 결과물은 맞았지만, 만드는 사람이 읽은 것은 틀렸습니다.

## 세 화면이 같습니다

이제 생성 화면도 저장된 값이 목록에 없으면 그 값을 그대로 넣어 보여 줍니다.

```
저장된 톤 'concise' · 언어 'fr'
생성 화면:  발표 톤 "concise"  언어 "fr"
```

## 검사

화면 훑기가 톤 `concise`와 언어 `fr`을 저장해 두고 **개인화 화면과 생성 화면을 모두**
읽습니다. 생성 화면만 되돌리면 그 자리에서 잡습니다 —
`the create screen does not carry the stored tone and language: ['professional', 'ko']`.

웹 131개 · REST 557개 · 화면 훑기 0 failures.
