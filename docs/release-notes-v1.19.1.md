# Ptium v1.19.1

어제 낸 **"장을 지정하면 그 장을 만든다"**를, **지정하지 않은 브리프**로 다시 돌려 봤습니다.

## 슬라이드라는 단어가 들어갔다는 이유로 주제를 빼앗고 있었습니다

부탁하는 문장을 알아보는 규칙이 **부탁 없이 그 단어만 있어도** 반응했습니다.

| 브리프 | 어제 나온 것 |
| --- | --- |
| 랜딩 **페이지** 개편과 전환율 개선 계획 | 주제 = "개편과 전환율 개선", **"랜딩" 장**이 생김 |
| 제품 소개 **페이지** 리뉴얼 계획 | 주제 = "리뉴얼 계획", **"제품 소개" 장** |
| 보안 **섹션** 강화 방안 | 주제 = "강화 방안", **"보안" 장** |
| The landing **page** redesign | 주제 = "redesign and conversion plan", **"landing" 장** |
| A pricing **page** experiment | 주제 = "experiment", **"pricing" 장** |

랜딩 페이지 개편을 보고하려던 사람이 **"랜딩"이라는 장이 붙은, 페이지 이야기가 빠진 덱**을
받게 됩니다. 어제 고친 것보다 흔한 브리프입니다.

**부탁이 있어야 부탁입니다.** `넣어주세요` · `포함해` · `추가해` · `include` · `add` 가 없으면
슬라이드·섹션·페이지·장은 그냥 그 사람이 쓴 단어입니다. 이제 그렇게 봅니다.

## 목록도 제대로 읽습니다

`일정 슬라이드와 예산 슬라이드를 포함해 주세요` 는 **동사가 하나**입니다. 그 하나에 두 개가
걸려 있어서, 어제 판은 `일정 슬라이드와 예산` 을 **한 덩어리 이름**으로 읽었습니다.
이제 부탁하는 문장 전체를 먼저 찾고 그 안에서 이름을 하나씩 꺼냅니다 — **일정** 장과 **예산** 장.
