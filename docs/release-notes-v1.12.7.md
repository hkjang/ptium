# Ptium v1.12.7

앞의 두 릴리즈는 장 제목을 고쳤습니다. 같은 자를 **슬라이드 본문**에 대 봤더니, 제목이 방금
버린 결함이 그 아래 수치 라벨에 그대로 남아 있었습니다.

## 라벨은 제목과 같은 자리에서 잘려 나옵니다

`"물류센터 자동화(AMR 20대) 도입 승인"` 브리프의 KPI 블록입니다:

```
label="물류센터 자동화(AMR"   value="20대"     ← 열지 않고 닫은 괄호
label="지연 6시간을"          value="30분"     ← 측정값이 측정값을 설명함
```

제목은 v1.12.5 에서 고쳤는데, **같은 슬라이드의 숫자 밑에 붙는 라벨**은 그 정리를 하나도
거치지 않았습니다. 이제 라벨도 닫지 않은 괄호를 버리고, 라벨 끝의 측정값을 떼어냅니다.
(→ `"물류센터 자동화" 20대`, `"지연" 30분`)

떼는 것은 확실한 것만입니다. 라벨은 이미 두 낱말까지이고, 더 가져가면 숫자가 무엇을 세는지
말할 것이 남지 않습니다 — `"개발 속도"` 는 그대로 `"개발 속도"` 입니다.

## 띄어쓰기가 없는 글도 낱말은 있습니다

일본어 라벨은 숫자 앞에서 **여덟 글자를 세어** 가져옵니다. 그 세기가 낱말 한가운데에
떨어졌습니다:

```
平均オンボーディング期間5週間  →  label="ボーディング期間"
```

이제 카타카나·라틴 문자·숫자가 이어지는 구간 **안에서는 자르지 않습니다**. 구간이 시작된
자리까지 물러나고, 그것이 너무 멀면 구간 뒤에서 시작합니다. (→ `"オンボーディング期間"`)

## 되돌려서 확인했습니다

네 개 수정을 하나씩 되돌려 테스트가 실제로 무는지 확인했습니다. 처음에는 `figureLabelName`
을 직접만 부르고 있어서 **연결이 끊겨도 통과**했습니다 — 덱이 실제로 쓰는 문으로 한 번 더
지나가게 했습니다.

gzip -dc ptium-1.12.7.tar.gz | docker load
