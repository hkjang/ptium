# Ptium v0.80.0

모델이 비교 슬라이드를 이렇게 썼습니다. 누구나 이렇게 씁니다.

```
# 투자 대비 위험 비용
@comparison
> 투자
> 유지
- 12억 원 초기 비용
- 안정성 확보 및 신뢰도 상승
- 장기적 유지보수 비용 절감
- 장애 리스크 완전 제거
- 추가 투자 없이 현재 상태 유지
- 장애 리스크 지속 및 확대
- 매출 손실 발생 가능성 높음
- 브랜드 이미지 훼손 지속
```

나온 슬라이드는 이랬습니다.

| 왼쪽 단 | 오른쪽 단 |
|---|---|
| **투자 유지** ← 두 머리말이 붙어 버림 | *(머리말 없음)* |
| 12억 원 초기 비용 | 추가 투자 없이 현재 상태 유지 |
| 안정성 확보 및 신뢰도 상승 | 장애 리스크 지속 및 확대 |
| 장기적 유지보수 비용 절감 | 매출 손실 발생 가능성 높음 |
| 장애 리스크 완전 제거 | 브랜드 이미지 훼손 지속 |

요점은 4개씩 제대로 갈렸습니다. **이름표만 망가졌습니다.** 왼쪽은 아무 뜻 없는 "투자 유지",
오른쪽은 아무것도 없음. 비교 슬라이드에서 **어느 쪽이 어느 쪽인지 알 수 없다면** 그건 비교가
아닙니다.

## 고침

요점이 시작된 **뒤** 에 오는 두 번째 `>` 는 이미 다른 단의 머리말로 읽고 있었습니다. 이제
요점이 시작되기 **전** 에 연달아 오는 두 번째 `>` 도 그렇게 읽습니다 — 양쪽이 **문장이 아니라
이름** 일 때만.

```
> 투자        =        > 투자 | 유지
> 유지
```

오른쪽 형태는 v0.60 부터 두 단으로 읽어 왔으니, 왼쪽도 같은 슬라이드로 읽으면 그만입니다.
문장 두 줄은 여전히 리드 한 줄입니다 — 두 단이 되려면 **이름 두 개** 여야 합니다.

## 확인

모델이 쓴 그 원문을 편집기로 다시 넣어 봤습니다.

```
body3  ['투자', '12억 원 초기 비용', '안정성 확보 및 신뢰도 상승', ...]
body4  ['유지', '추가 투자 없이 현재 상태 유지', '장애 리스크 지속 및 확대', ...]
```

포매터는 애매한 형태를 애매하지 않은 형태(머리말 · 그 요점 · 머리말 · 그 요점)로 정리하고,
덱은 **양쪽 형태 모두에서 왕복** 합니다.

## 설치

오프라인 설치 방법은 [docs/offline-deployment.md](offline-deployment.md) 를 보세요. 이미지에
Postgres 와 nginx 는 들어 있지 않습니다 — 배포할 때 `DATABASE_URL` 로 DSN 을 지정합니다.
