# Ptium v1.28.3

관리자 화면 두 곳에서 **기다림과 작성 중**을 구분했습니다(1.28.1 · 1.28.2).
마지막 한 곳이 남아 있었습니다 — **덱을 만든 사람이 보는 화면**입니다.

## 줄을 서 있는 덱에게 "쓰고 있어요"라고 말하고 있었습니다

웹은 서버의 `queued`를 **`generating`으로 바꿔서** 받고 있었습니다.

```
if (status === 'queued' || status === 'processing' || status === 'running') return 'generating'
```

그래서 앞선 작업이 끝나기를 기다리는 덱에 대해 화면은 이렇게 말했습니다 —

```
슬라이드를 생성하고 있어요
완성되는 대로 자동으로 편집기를 열어드릴게요.
```

아무도 그 덱을 쓰고 있지 않습니다. **워커가 아예 떠 있지 않은 배포**라면 이 문장은
페이지를 열어 두는 내내 사실이 아닙니다.

## 있는 그대로 말합니다

```
차례를 기다리고 있어요                         ← queued
앞선 작업이 끝나면 바로 시작합니다. 시작하면 이 화면이 알려드릴게요.

슬라이드를 생성하고 있어요                     ← generating
완성되는 대로 자동으로 편집기를 열어드릴게요.
```

덱 목록의 카드도 **대기 중 / 생성 중**을 나눠 보여 줍니다. "생성 중" 필터는 **둘 다**
보여 줍니다 — 진행 중인 것을 보려는 사람에게는 둘 다 진행 중이니까요.

## 검사

상태 변환 네 가지를 단위 테스트로 고정했습니다 — `queued`는 `queued`로 남고,
다른 서버가 쓰는 `processing` · `running`은 작성 중으로 읽으며, 모르는 값은 초안입니다.
워커를 세워 둔 배포에서 두 상태를 실제로 열어 확인했습니다.
