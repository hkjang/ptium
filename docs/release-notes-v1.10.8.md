# Ptium v1.10.8

## 공유 링크로 본 사람도 링크를 누를 수 있습니다

v1.10.6 에서 발표 화면이 슬라이드를 직접 그리게 했습니다. **검토용 공유 링크** 는 그대로
그림(`<img>`)이었습니다. 그런데 링크를 실제로 읽는 사람은 대개 그쪽입니다 — 숫자의 근거,
슬라이드가 가리키는 문서를 확인하는 건 발표하는 사람이 아니라 **검토하는 사람** 이니까요.

이제 공유 화면도 슬라이드를 직접 그립니다.

- **바깥 링크** 를 누르면 새 탭에서 열립니다
- **`#3` 같은 덱 안 링크** 를 누르면 검토 화면이 그 슬라이드로 넘어갑니다 — 링크를 따라
  부록을 보고, 다시 돌아와 의견을 답니다
- 다음 장은 **미리 받아 둡니다.** 덱 끝을 넘어선 장은 요청하지 않습니다

계정 없는 브라우저로 공유 링크를 열어 확인했습니다: 슬라이드 안에 링크 2개, `#slide-3` 을
누르면 `1 / 3` → `3 / 3`, 가만히 두면 추가 요청 없음.

## 설치

```bash
gzip -dc ptium-1.10.8.tar.gz | docker load
```
