# Ptium v0.2.0

슬라이드를 "칸 채우기"에서 "구성하기"로 옮긴 릴리스입니다. 템플릿에서 파생된
디자인 체계 위에 슬라이드 컴포넌트를 배치하고, 기본 제공 디자인을 30종으로
넓혔습니다. 런타임 이미지는 리버스 프록시와 번들 데이터베이스를 걷어내고 단일
바이너리로 줄였습니다.

## 디자인 체계

- 배경은 슬라이드가 실제로 칠하는 색에서 읽습니다. 다크 템플릿이 어두운 배경을
  `lt1`에 두는 정상적인 관행 때문에 이전에는 모든 잉크 색이 반대로 뒤집혔습니다.
- 본문·보조·흐린 텍스트는 대비 4.5:1 / 3:1을 만족하는 지점까지만 배경 쪽으로
  흐려집니다. 고정 비율은 밝은 테마에서만 맞고 어두운 테마에서 사라집니다.
- 카테고리 데이터 색 순서는 테마 액센트 6개에서 만들되, OKLab 지각 거리로
  계산합니다. 적·녹색약 시뮬레이션을 포함하며, 회색에 가까운 색·앞 색과 구분되지
  않는 색·배경에 묻히는 색은 제외합니다. 한도를 넘는 계열은 새 색을 만들지 않고
  회색으로 물러납니다.
- 타입 스케일과 8pt 간격 리듬, 글자 폭 실측(한글·한자 1em, 라틴 약 0.5em).

## 슬라이드 컴포넌트 14종

KPI 타일, 히어로 수치, 미터, 프로세스 스텝, 타임라인, 비교 카드, 막대·가로막대·
선·100% 누적 차트, 표, 인용, 콜아웃.

- 레이아웃을 한 번만 계산해 PPTX(DrawingML)와 SVG 프리뷰 양쪽으로 출력합니다.
  브라우저 미리보기와 내보낸 파일이 어긋날 수 없습니다.
- 차트는 차트 부품이 아니라 순수 도형으로 그립니다. 숨은 워크북이 없어 파일 복구
  프롬프트가 뜨지 않고, PowerPoint에서 도형 그룹으로 편집할 수 있습니다.
- 막대는 밴드를 채우지 않고 값 끝만 둥글며 기준선은 각집니다. 격자선 대신 직접
  라벨을 쓰고, 누적 구간은 테두리가 아니라 배경색 간격으로 분리하며, 계열이 둘
  이상이면 범례가 항상 붙습니다.
- AI가 숫자를 발명하지 못하도록 통제합니다. 수치 기반 컴포넌트는 브리핑에 근거가
  있을 때만 허용하고, 그 외에는 스텝·타임라인·비교·표처럼 구조만 전달하는
  컴포넌트나 산문을 쓰게 합니다. 모델이 만든 컴포넌트는 저장 전에 검증되며,
  그릴 것이 없으면 산문으로 되돌립니다.

## 기본 제공 디자인 30종

10개 팔레트 × 6개 레이아웃 계열(Classic, Rail, Centered, Panel, Editorial,
Minimal), 각 10개 레이아웃.

- 팔레트: Slate, Azure, Crimson, Coral, Ivory, Sand (밝은) / Midnight,
  Graphite, Forest, Plum (어두운)
- 모든 팔레트가 명도 대역, 채도 하한, 인접 색 구분(정상 시각과 색약), 배경 대비
  검사를 통과합니다.
- 이전 테마 이름(`aurora`, `modern`, `paper`, `mint`, `graphite`)은 그대로
  매핑되고, 손대지 않은 기본값은 `slate-classic`으로 옮겨집니다.

## 배포

- 런타임 이미지는 정적 바이너리 하나가 워크스페이스·REST·MCP를 8080 포트에서
  제공합니다. nginx와 셸 엔트리포인트가 없습니다. 이로써 템플릿 업로드를 막던
  프록시 본문 크기 제한도 없어졌습니다.
- 오프라인 번들에는 Ptium 이미지만 들어갑니다. 데이터베이스는 배포 환경이
  `DATABASE_URL`로 제공합니다.
- 쿠버네티스 예시 매니페스트 추가: 비루트 2 레플리카, 읽기 전용 루트 파일시스템,
  헬스 프로브, 인그레스 본문 크기 설정.

## 오프라인 자산

`ptium-0.2.0.tar.gz`는 `ptium:0.2.0`과 `ptium-0.2.0:latest`를 담은 Docker load
가능한 gzip 스트림입니다. 체크섬으로 무결성을 확인한 뒤 함께 제공되는 compose·
env·쿠버네티스 예시를 사용하면 외부 registry 접근 없이 배포할 수 있습니다.
절차는 `docs/offline-deployment.md`를 참고하십시오.
