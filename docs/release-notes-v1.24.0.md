# Ptium v1.24.0

## 브랜드 색상이 아무 데도 쓰이지 않고 있었습니다

개인 설정의 **브랜드 스타일**은 이렇게 적혀 있습니다.

> 브랜드 강조 색상 — **생성된 슬라이드의 강조선과 PPTX에 사용됩니다.**

색을 넣고 덱을 만들어 봤습니다.

```
슬라이드마다 accent: #0F62FE   ← 저장은 되어 있고
미리보기에서 그 색이 쓰인 장: 없음   ← 아무 데도 안 쓰임
내보낸 pptx에서: 없음
```

색은 **계산되고, 모든 슬라이드에 저장되고, 그리는 순간 버려지고** 있었습니다. 코드에 적힌
의도는 분명했습니다 — *"Accent는 컴포넌트를 칠한다. 비어 있으면 템플릿의 색을 쓴다."* —
그런데 **읽는 쪽이 없었습니다.**

## 이제 칠합니다 — 딱 그 자리만

- **이 제품이 직접 그리는 컴포넌트**(지표 타일 · 막대 · 달성률 · 강조선)에 그 색이 들어갑니다
- **템플릿이 정한 것은 그대로**입니다 — 마스터 · 레이아웃 · 글꼴 · 글자색 · 로고.
  회사가 디자인한 것은 회사가 디자인한 대로 남습니다
- 색을 비우면 **예전처럼 템플릿의 강조색**을 씁니다
- 색 위에 얹는 글자색은 **읽히도록 다시 계산**합니다(어두운 색 위엔 밝은 글자)

```
지금:  미리보기에서 그 색이 쓰인 장 [2]   ·  내보낸 pptx 슬라이드에서 3번 등장
```

## 이번에 함께 확인한 것

- **회사·직무는 원래 잘 되고 있었습니다** — 표지 아래 줄이
  `2026년 8월 · 케이씨비 AI 엔지니어링 파트장 · …`
- **기본 청중·톤·언어**는 화면이 약속한 대로 **웹에서 새로 만들 때** 적용됩니다(화면에도
  "웹에서"라고 적혀 있습니다)
