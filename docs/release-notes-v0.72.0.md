## "이 버전 이후 무엇이 바뀌었나"

버전 이력은 지금까지 **시각의 목록**이었습니다. 복원 버튼은 있는데 무엇으로 돌아가는지는
열어 보기 전에는 알 수 없습니다 — 어두운 데서 뛰어내리는 셈입니다.

이제 각 체크포인트가 그 뒤로 무엇이 바뀌었는지 말합니다.

```
버전 2 · 코드 적용 전                     1장 수정 · 1장 추가 · 1장 이동
  [수정] 2. 비용        − - 이관 비용 12억 원
                        + - 이관 비용 14억 원
  [추가] 3. 리스크      + # 리스크
  [이동] 4. 다음 단계   3번에서
```

- **단위는 슬라이드**입니다. 사람이 편집하는 단위이고, "비용 슬라이드가 바뀌었다"가 답이지
  저장된 JSON의 글자 차이가 답이 아니기 때문입니다.
- 바뀐 줄은 **덱의 언어 그대로** 보여 줍니다 — 코드 패널에서 보던 그 텍스트입니다.
- 슬라이드를 짝지을 때 **id → 제목 → 순서** 순으로 봅니다. 코드를 적용하면 모든 슬라이드가 새
  id로 다시 만들어지므로, id만 보면 모든 덱이 "통째로 교체됨"으로 읽힙니다. 제목이 같으면 같은
  슬라이드입니다 — 다시 쓴 비용 슬라이드는 여전히 비용 슬라이드입니다.
- 열어 볼 때 한 번만 물어보고, 그 뒤로는 기억합니다.

`GET /presentations/{id}/revisions/{revisionId}/changes` 로 API에서도 같은 답을 받습니다.
