# Ptium v1.14.3

## 회전으로 남의 권한을 가져올 수 있었습니다 (보안)

같은 자리의 세 번째 문입니다. 1.14.1 은 "키는 자기가 갖지 않은 권한을 **줄** 수 없다",
1.14.2 는 "범위를 안 적어도 마찬가지" 였습니다. 남은 것이 **회전(rotate)** 입니다.

키를 회전하면 **같은 권한을 가진 새 키가 만들어지고, 그 비밀값이 응답에 담깁니다.**

```
프레젠테이션 "조회"만 가진 키로 (api_keys:manage 보유):
  POST /api/v1/api-keys/{주인의 관리자 키 id}/rotate
  → 201, 응답에 새 비밀값 · 권한 [admin:users, presentations:read]
  → 그 키로 GET /api/v1/admin/users : 성공
```

읽기 전용으로 준 키가 **주인의 관리자 키를 회전시켜 그 권한을 손에 넣을 수** 있었습니다.

이제 **API 키로 인증한 요청은 자기가 가진 권한의 범위 안에 있는 키만 회전할 수 있습니다.**
거절할 때 어떤 권한 때문인지 이름을 댑니다. 자기 자신을 회전하는 것은 그대로 되고,
사람이 자기 계정으로 로그인해 회전하는 것도 그대로입니다.

## 이 자리에서 나온 것 정리

| 릴리즈 | 막은 경로 |
|---|---|
| 1.14.1 | 키가 **자기 권한을 넓히거나** 더 넓은 키를 **발급** |
| 1.14.2 | 범위를 **적지 않아** 기본 권한(편집 포함)을 받는 우회 |
| 1.14.3 | 더 넓은 키를 **회전**해 그 비밀값을 받는 경로 |

세 가지 모두 `api_keys:manage` 를 가진 키가 스스로 할 수 있었고, 세 가지 모두 스윕이
이전 바이너리에서 실패하는 것을 확인했습니다. (tenancy 101 checks)
