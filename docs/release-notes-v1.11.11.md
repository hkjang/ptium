# Ptium v1.11.11

## "고쳐 보려 했지만 그대로 두었습니다" 를 이제 말합니다

생성은 덱을 만든 뒤 템플릿에 대고 재고, 문제가 있는 슬라이드를 **모델에게 다시 쓰게 합니다.**
그리고 다시 재서 **더 나아졌을 때만** 씁니다. 나아지지 않으면 작성자가 쓴 것을 그대로 둡니다 —
여기까지는 옳습니다.

그런데 그 사실이 **서버 로그에만** 남았습니다. 덱을 여는 사람은 측정 결과에 문제가 보이니
**"AI로 고치기"를 누릅니다.** 이미 모델이 한 번 거절한 슬라이드에 대해서요.

이제 덱의 알림으로 나옵니다:

```
2장은 모델에게 다시 쓰게 했지만 나아지지 않아 그대로 두었습니다.
손으로 고치거나 다른 표현을 지시해 주세요.
```

시간이 모자라 끝내지 못한 경우도 마찬가지입니다:

```
3장은 다시 쓸 시간이 없었습니다. 편집기의 검사 결과에서 고칠 수 있습니다.
```

둘 다 한국어·일본어·중국어·영어로 나갑니다. **작성자가 할 일이 달라지는 정보** 는 작성자에게
가야 하고, 어떤 슬라이드를 어떻게 고쳤는지 같은 운영 정보는 로그에 남습니다.

## 재 본 것

실제 모델(122B)로 네 개 덱을 뽑아 쟀습니다 — 34장, **결함 0**. 권고만 남습니다(브리프에 없는
숫자 4, 같은 말 두 번 3, 줄 끝 한 음절 2). 보수 패스가 상한(3장)에 걸리는 경우는 없었습니다.
덱당 권고 두 개 남짓이고, 그중 작성자가 결정해야 하는 것이 대부분입니다.

gzip -dc ptium-1.11.11.tar.gz | docker load
