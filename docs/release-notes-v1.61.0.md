# 1.61.0 — 표 안에 쓴 글씨도 글씨입니다

표의 한 칸은 글자 한 덩어리로 쓰였습니다. 그래서 작성자가 굵게 표시한 낱말과
링크로 적은 주소가, 타자로 친 기호 그대로 파일에 남았습니다. 머리글에
`**1분기**`, 비고 칸에 `[근거](https://…)` 가 파워포인트 화면에 그대로 찍혔고,
미리보기는 그 기호를 지운 깨끗한 표를 보여 주었습니다. 작성자는 미리보기를
확인하고, 기호가 박힌 파일을 보냈습니다.

이제 표의 칸도 슬라이드의 다른 줄과 같게 읽고 씁니다.

- **내보낸 파일** — 굵게 쓴 칸은 굵게, 주소를 적은 칸은 눌러서 따라갈 수 있는
  진짜 링크로 나갑니다. 기호는 어디에도 남지 않습니다. 디자인이 칸을 줄여야
  했다면 그 칸은 글자만 남습니다. 반쪽짜리 링크는 링크가 아닙니다.
- **읽어 주는 말(대체 텍스트)** — 화면을 보지 못하는 사람에게는 낱말만
  읽어 줍니다. "별표 별표 1분기"는 보이지 않는 곳에 기호를 옮겨 놓는 일입니다.
- **가져오기** — 파워포인트에서 가져온 표의 칸에 링크가 걸려 있었다면 그 주소가
  함께 옵니다. 슬라이드를 아무리 들여다봐도 다시 칠 수 없는 것이 주소입니다.
  굵기는 일부러 가져오지 않습니다. 표의 머리글과 첫 열은 거의 모든 덱에서 표
  스타일이 굵게 만든 것이고, 그것까지 옮기면 스스로 굵게 쓰는 디자인 위에
  모든 머리글이 `**이렇게**` 표시됩니다.
- **취소선** — 줄뿐 아니라 표의 칸에 그어져 있던 취소선도 세어서 알려 줍니다.
  표는 칸에 든 낱말로 옮겨지기 때문에, 줄만 훑어서는 취소된 칸이 보이지
  않았습니다. 문구도 "줄 1개"에서 "자리 1곳"으로 바꿨습니다. 취소선은 줄에도
  칸에도 그어질 수 있습니다.

## 확인

- 파이썬 `python-pptx`(제품 바깥의 판독기)로 내보낸 파일을 열어 확인했습니다.
  머리글과 본문 칸의 주소가 진짜 하이퍼링크로 읽히고, 기호는 한 글자도 남아
  있지 않으며, 미리보기가 그리는 낱말과 파일이 담은 낱말이 같습니다.
- 고침을 되돌려 같은 판독기로 다시 읽어, 되돌린 자리에서 기호가 돌아오고 링크가
  사라지는 것을 확인했습니다.
- 표의 칸에 링크와 취소선이 있는 파워포인트 파일을 올려, 주소가 소스로 오고
  다시 내보낸 파일에서 링크로 살아 있는 것까지 한 바퀴 확인했습니다.
