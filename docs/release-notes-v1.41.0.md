# Ptium v1.41.0

**만들기 화면이 제공하는 네 개 언어 중 두 개는 브리프를 통째로 제목에 올리고 있었습니다.**

## 1.40.0을 확인하다가 발견했습니다

한국어 명령형 문제를 고치고 배포 이미지를 검증하면서, 같은 브리프를 영어·일본어로도
넣어 봤습니다.

```
Write me a 8 slide deck about reducing cloud spend
   → 표지: "Me a deck about reducing cloud spend"

新しい採用計画を8枚でまとめてください
   → 표지: "新しい採用計画を8枚でまとめてください"   (브리프 전체가 제목)

把数据仓库迁移的风险做成12页的汇报
   → 표지: "把数据仓库迁移的风险做成12页的汇报"       (브리프 전체가 제목)
```

일본어와 중국어는 **요청을 읽는 규칙이 아예 없었습니다.** 장수도(`8枚`, `12页`),
요청 동사도(`まとめてください`, `整理一下`), 청중도(`経営層向けに`) 모두 제목의 일부가
됐습니다. 두 언어 모두 만들기 화면의 언어 선택에 그대로 올라와 있습니다.

영어는 절반만 되어 있었습니다. 동사만 떼고 나머지를 남겨서 `Write me a … deck about`
이 `Me a deck about` 이 됐고, `Make a short deck about …` 은 자기 동사를 그대로
달고 있었습니다.

## 이제

- **영어**: 요청을 한 덩어리로 읽습니다 — 동사·`me`·관사·장수·`deck`/`presentation`·
  `about`/`on`까지. 문장 첫머리에만 적용되므로 본문 속 단어는 건드리지 않습니다.
- **일본어**: `枚`·`ページ` 장수, `まとめてください`·`作成してください`·`お願いします`
  같은 요청, `について`, 그리고 이름이 있는 청중(`経営層向けに`)을 읽습니다.
- **중국어**: `页`·`张` 장수, `请`·`帮我`·`整理一下`·`做成`, 문두의 `把`,
  문미의 `的汇报`를 읽습니다.
- 문장에서 들어낸 구절이 달고 나오는 조사(`を`·`は`·`が`·`へ`·`について`)도
  한국어와 같은 방식으로 정리합니다.

## 과하게 지우지 않도록

`向け` 앞의 아무 말이나 청중으로 보면 주제를 거꾸로 삼킵니다 — 실제로
`データ基盤移行のリスクを経営層向けに…` 가 **"データ"** 한 단어짜리 덱이 됐습니다.
이름이 있는 청중일 때만 지웁니다. `作成`·`整理` 는 일본어에서 평범한 명사이므로
정중한 어미가 붙었을 때만 요청으로 읽습니다. 두 경우 모두 테스트로 고정했습니다.
