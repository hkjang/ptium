# Ptium v1.23.2

## "이 배포가 허용하는 것보다 많습니다" — 얼마까지인데요?

50장 경계를 두드려 봤습니다. **50장은 그대로 저장되고, 51장은 거절되며, 이전 덱은 그대로**
남습니다 — 조용히 잘라내지 않습니다. 여기까지는 정확합니다.

문제는 거절할 때 하는 말이었습니다.

```
The deck source produced more slides than this deployment allows
```

**62장을 쓴 사람은 62라는 숫자를 이미 갖고 있습니다.** 필요한 건 나머지 하나 — 몇 장까지
되는지입니다. 그걸 말해 주지 않으니 자기 슬라이드를 세어 가며 짐작해야 합니다.

이제 **두 숫자를 다 말합니다.**

> 이 코드는 **62장**을 만드는데, 이 배포는 **50장**까지만 허용합니다. **12장**을 줄이거나
> 덱을 나눠 주세요.

## 이번에 함께 확인한 것

- **MCP 자원 목록** — 지난 판에서 목록 도구를 고쳤으니 자원 쪽도 확인: 50개 목록 · 커서 ·
  자원 읽기 모두 정상이고, 에이전트가 읽는 덱에는 **덱의 코드(`source`)와 슬라이드가 모두** 옵니다
- **그림이 모든 문을 통과하는지** — 실제 사진(1998×3146)을 올려 슬라이드에 넣고:
  `.pptx` 안에 미디어 1개, PDF 안에 이미지 객체 2개, 미리보기 SVG에도 그려집니다
- **큰 덱 내보내기** — 50장짜리: pptx 78KB를 11ms, pdf 2MB를 115ms

## 검사

한계를 넘긴 덱이 **두 숫자를 말하는지** 고정했습니다 — 서버 쪽은 REST 훑기(539개 점검),
화면 쪽은 한국어 문장에 62·50·12가 모두 나오는지.
