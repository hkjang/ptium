# Ptium v1.12.13

파워포인트에서 가져온 덱에서 **링크 주소가 사라지고 있었습니다.**

## 어떻게 알았나

덱을 pptx 로 내보낸 뒤 다시 가져와서, 글이 다 살아 있는지 봤습니다. Ptium 이 만든 파일은
완벽히 돌아옵니다 — 소스를 파일 안에 넣어 두기 때문입니다("Ptium이 만든 파일이라 원본
그대로 가져왔습니다"). 그래서 그 내장 소스를 **떼어 내고** 다시 넣었습니다. 남이 만든
덱을 읽을 때와 같은 조건입니다:

```
OK    클라우드 전환 승인
OK    42개 시스템
LOST  example.com/plan     ← 링크 주소
LOST  **전환 대상**          ← 굵게
```

가져오기는 문단의 런을 **글자만 이어 붙이고 속성은 통째로 버리고** 있었습니다
(`ImportedLine{Text, Level}`). 주소는 슬라이드를 아무리 들여다봐도 다시 칠 수 없는
단 하나의 정보입니다.

## 이제

런이 말하는 것을 함께 읽습니다. 덱 소스가 쓰는 그대로 적습니다:

```
자료는 [계획서](https://example.com/plan)에, **굵게**도 있습니다
```

- 하이퍼링크 → `[글](주소)`. 다른 장으로 가는 링크는 그 장의 번호로 — `#3`
- 굵게 → `**…**`, 기울임 → `*…*`

숨은 이유가 하나 더 있었습니다: `RelationshipByID` 는 **외부 대상을 일부러 제외**합니다.
그림은 반드시 파일 안에 있어야 하므로 맞는 규칙인데, 하이퍼링크는 바로 그 외부 대상입니다.
링크에는 링크의 해석기를 씁니다.

## 여전히 가져오지 못하는 것

`::steps`·`::kpi` 같은 **컴포넌트는 되살리지 않습니다.** 그려진 그림에서 어떤 컴포넌트였는지
확실히 알 수 없기 때문입니다 — 대신 그 안의 글은 요점으로 남습니다("준비 :: 범위 · 조직 ·
예산을 확정"). 짐작해서 그리는 것보다 낫다고 봅니다.
