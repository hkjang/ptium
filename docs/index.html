완벽한 프레젠테이션

회사 템플릿 그대로, AI가 만드는 슬라이드 덱

Ptium은 기존 PowerPoint 템플릿의 마스터, 레이아웃, 테마 색상, 글꼴, 로고를 100% 유지하면서 AI가 구조화된 슬라이드 콘텐츠를 생성합니다. 자체 호스팅으로 데이터 주권을 보장하고, REST API와 MCP 통합으로 기존 워크플로에 자연스럽게 연결됩니다.

핵심 기능

프롬프트에서 프레젠테이션까지, 모든 과정을 지능적으로 처리합니다

📑

회사 템플릿 기반 생성

업로드한 PowerPoint 템플릿의 마스터, 레이아웃, 테마 색상, 글꼴, 로고를 100% 유지하면서 슬라이드만 새로 생성합니다. 결과물은 직접 작성한 자료와 구분할 수 없습니다.

🧠

레이아웃 자동 선택

표지, 구역, 본문, 2단, 비교, 인용, 이미지, 마무리 등 슬라이드의 목적을 인식하여 최적의 레이아웃을 자동으로 매칭합니다.

📏

용량 인식 텍스트

각 자리 표시자의 글자 수를 em 단위로 측정하여 텍스트 넘침 없이 자동 조정합니다. 한글, 한자는 1em, 라틴 문자는 약 0.5em으로 정밀 계산합니다.

👁️

브라우저 SVG 미리보기

PowerPoint 없이 브라우저에서 실제 템플릿의 배치, 색상, 글꼴로 렌더링된 슬라이드를 실시간으로 미리봅니다. 내보낸 파일과 동일한 결과입니다.

🌐

폐쇄망/오프라인 지원

결정적 로컬 생성기가 AI 공급자 키 없이도 완결된 덱을 만듭니다. 오프라인 Docker 이미지 번들로 인터넷 없는 환경에서도 완전히 동작합니다.

🤖

MCP 통합

Claude Desktop, Cursor 등 AI 에이전트에서 MCP JSON-RPC를 통해 직접 프레젠테이션을 생성하고 관리합니다. 같은 인증과 권한 체계를 사용합니다.

🔐

OIDC / Keycloak SSO

표준 OIDC 인증 프로토콜과 PKCE(S256)를 지원합니다. Keycloak 역할이 Ptium 관리자에 자동 매핑됩니다.

🔄

API 키 회전

범위·만료일이 있는 해시 API 키를 발급하고, 무중단 유예 기간으로 안전하게 회전합니다. 원문은 생성 시 한 번만 표시됩니다.

🛡️

비밀 관리

AI 공급자 키와 OIDC 클라이언트 시크릿은 쓰기 전용으로 관리됩니다. 로그, 인시던트, API 응답에서 민감 정보가 자동 제거됩니다.

📋

인시던트 추적

서버 오류에 안정적 핑거프린트를 부여하고, 관리자 콘솔에서 심각도, 상태, 메모와 해결 이력을 관리합니다. 요청 ID로 로그를 추적합니다.

개발자를 위한 통합

REST API와 MCP로 기존 워크플로에 자연스럽게 연결됩니다

REST REST API v1

OpenAPI 스키마 기반의 버전형 REST API. OIDC 토큰 또는 API 키로 인증합니다.

bash — REST API 호출 예시
# 프레젠테이션 목록 조회
curl -H 'Authorization: Bearer ptium_...' \
  http://localhost:8080/api/v1/presentations

# 템플릿 업로드
curl -H 'Authorization: Bearer ptium_...' \
  -F 'file=@company-template.pptx' \
  -F 'name=사내 표준 제안서' \
  http://localhost:8080/api/v1/templates
MCP MCP JSON-RPC

Claude Desktop, Cursor 등 AI 에이전트에서 직접 프레젠테이션을 생성합니다.

json — MCP 도구 호출 예시
{
  "jsonrpc": "2.0",
  "id": 2,
  "method": "tools/call",
  "params": {
    "name": "ptium.create_presentation",
    "arguments": {
      "title": "2027 제품 전략",
      "prompt": "지역 리더를 위한 경영 의사결정 덱",
      "language": "ko",
      "theme": "slate-classic",
      "slideCount": 10
    }
  }
}

유연한 배포

환경에 맞는 최적의 배포 방법을 선택하세요

🐳 Docker Compose

PostgreSQL, Go 서비스, React 앱을 한 번에 실행합니다. 개발과 평가에 가장 빠른 시작점입니다.

cp .env.example .env
docker compose up --build

# 웹 UI: http://localhost:8080
# API:   http://localhost:8080/api/v1
# MCP:   http://localhost:8080/mcp

⚡ 단일 바이너리

Go 바이너리 하나와 PostgreSQL DSN만으로 실행합니다. 스키마와 기본 설정이 자동으로 생성됩니다.

cd server
DATABASE_URL='postgres://ptium:ptium@localhost:5432/ptium?sslmode=disable' \
  go run ./cmd/ptium

# 첫 실행 시 자동 마이그레이션
# OIDC/AI 키 없이도 서버 기동 가능

📦 오프라인 번들

인터넷이 없는 폐쇄망 환경을 위한 Docker 이미지 번들입니다. 체크섬 확인, 이미지 로드, 업그레이드를 지원합니다.

# 빌드 호스트에서 번들 생성
.\scripts\build-offline.ps1

# 대상 호스트에서 배포
docker load -i ptium-0.1.0.tar.gz
docker compose -f docker-compose.offline.yml up

자주 묻는 질문

Ptium은 프롬프트를 입력하면 회사의 기존 PowerPoint 템플릿을 100% 유지하면서 AI가 구조화된 슬라이드 덱을 생성해주는 자체 호스팅 서비스입니다. Go 백엔드, React 프론트엔드, PostgreSQL로 구성된 단일 서비스 아키텍처를 가집니다.

네, Ptium은 결정적 로컬 생성기를 내장하고 있어 AI 공급자 키 없이도 완결된 덱을 만들 수 있습니다. 이 기능은 특히 폐쇄망(에어갭) 환경에서 유용합니다.

네, Ptium은 오프라인 Docker 이미지 번들을 제공합니다. 인터넷이 없는 Linux/AMD64 환경에서도 배포할 수 있으며, 로컬 생성기를 통해 AI 연결 없이도 프레젠테이션을 생성할 수 있습니다.

표준 PowerPoint 프레젠테이션 파일(.pptx)과 서식 파일(.potx)을 모두 지원합니다. 기존 발표 파일도 템플릿으로 사용할 수 있으며, 마스터, 레이아웃, 테마 색상, 글꼴, 로고가 모두 보존됩니다.

Ptium은 /mcp 엔드포인트에서 Streamable HTTP 방식의 MCP JSON-RPC를 제공합니다. Claude Desktop, Cursor 등의 AI 에이전트에서 프레젠테이션을 직접 생성하고 관리할 수 있습니다. API 키에 mcp:use 범위를 부여하면 됩니다.

Keycloak 기반 OIDC 인증, PKCE(S256), 범위/만료일이 있는 해시 API 키, 무중단 유예 기간 키 회전, 비밀 값 쓰기 전용 관리, 구조화 감사 로그 등 엔터프라이즈급 보안을 제공합니다.

네, Ptium은 GitHub에서 공개된 오픈소스 프로젝트입니다. 자체 호스팅하여 완전한 데이터 주권을 유지할 수 있습니다.
