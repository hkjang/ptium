## 테스트가 문서 역할을 합니다

두 대화상자에 대해 테스트가 확인하는 것은 화면에 무엇이 그려지는가가 아니라 **무엇이 보장되는가**
입니다.

- **복원이 진행 중이면 두 번째 복원도, 닫기도 되지 않습니다.** 모달 머리의 `×` 는 공용
  컴포넌트 것이라 계속 눌리는데, 그래서 대화상자가 **직접 거절합니다** — 눌러도 닫히지 않는
  것을 테스트가 보장합니다.
- **파일을 만드는 중에는 다시 요청할 수 없습니다.**
- **PDF 줄은 있고 비활성입니다.** 감추면 사람들이 메뉴를 뒤지게 됩니다. 대신 무엇을 하면
  되는지 그 자리에 적혀 있습니다.
- 이력이 없는 덱은 **빈 목록이 아니라 그렇게 말합니다.**
