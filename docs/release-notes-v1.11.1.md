# Ptium v1.11.1

어제 넣은 PDF 를 실제 덱들로 밀어 보면서 두 가지를 고쳤습니다.

## 배경의 그러데이션이 단색으로 인쇄되던 것

템플릿 배경이 **워시(그러데이션)** 인 경우, PDF 는 그 중 첫 색 하나로 칠하고 있었습니다.
화면과 종이가 어긋나지 않게 만든다는 게 이 기능의 전부인데, 가장 눈에 띄는 부분이
어긋나고 있었던 셈입니다.

이제 **PDF 자체의 축 방향 셰이딩** 으로 그립니다. 방향과 양 끝 색이 화면의 그것 그대로이고,
칠하는 범위는 그 도형 안으로 잘립니다.

```
p1: /Sh1 [140, 461, 820, 79]  C0 [0.55, 0.36, 0.96]  C1 [0.38, 0.25, 0.68]
p2: /Sh2 [0, 4, 960, 4]        C0 [0.55, 0.36, 0.96]  C1 [0.77, 0.71, 0.98]
```

표지의 대각선 워시와 본문의 가로 강조 바가 각각 제 방향으로 들어갔습니다.

## 페이지가 자기가 안 쓰는 그림을 목록에 달고 있던 것

페이지마다 **덱 전체의 이미지 목록** 을 자원(resources)으로 달고 있었습니다. 그려지지는
않으니 틀린 그림이 나오지는 않지만, 페이지가 자기가 아닌 것을 가리키고 있는 상태입니다.
이제 각 페이지는 **자기가 그린 것만** 가리킵니다.

## 밀어 본 것들

- 사진·표·지표·단계가 든 덱: 화면의 글줄이 종이에서 하나도 빠지지 않음, 사각형 6개 → 채움
  6개, 타원 3개 → 베지어 12개
- 점(dot) 33개를 그리는 템플릿: 132개 곡선 그대로
- 남의 템플릿으로 만든 덱, 워시 템플릿 덱

스윕에도 넣었습니다(151 checks) — 워시가 단색으로 굳으면 실패합니다.
