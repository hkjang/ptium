# Ptium v1.59.1

**공유 링크를 받은 사람이 한국어 제목 아래 영어 설명을 읽고 있었습니다.**

## 워크스페이스 밖의 독자

공유 링크는 **이 제품을 처음 보는 사람**이 여는 화면입니다. 그 페이지는 처음부터
끝까지 한국어입니다 — 위에 "덱을 열 수 없습니다", 옆에 "이 슬라이드에 대한 의견".
그런데 그 제목 아래에 들어가는 문장은 서버가 **영어로** 보내고 있었습니다.

```
덱을 열 수 없습니다
This link is no longer open. Ask whoever sent it for a new one
```

페이지에는 서버가 아무 말도 하지 않을 때를 위한 한국어 문장까지 준비돼 있는데,
서버가 언제나 영어로 무언가를 말했으므로 **그 한국어 줄은 한 번도 보이지 않았습니다.**

다섯 문장을 페이지에 맞췄습니다 — 만료·회수된 링크, 없는 링크, 슬라이드가 없는 덱,
남의 덱 슬라이드에 단 의견, 그리고 링크를 만드는 쪽의 입력 오류까지.

```
만료된 링크   이 링크는 더 이상 열리지 않습니다. 보내 준 사람에게 새 링크를 요청해 주세요.
회수한 링크   (같음)
없는 링크     이 링크로 공유된 덱이 없습니다.
```

검사는 파일 안의 독자용 문장을 **전부** 훑습니다. 그래서 제가 못 보고 넘어간 다섯
번째 문장을 검사가 찾아냈습니다.

## 함께 재 보고 문제가 없던 것

* **네 가지 링크 상태** — 살아 있음·만료·회수·없음. 넷 다 제대로 구분해 말합니다
* **발표에서 뺀 장은 공유 링크에도 없습니다** — 4장 중 1장을 빼면 링크는 3장을
  보여 주고 `slideCount`도 3입니다
* **공유 페이지는 0.1초에 요청 5건으로 끝납니다** — 반복 요청 없음

## 재는 사람의 실수

이번 반복에서 측정 도구가 **세 번** 틀렸습니다.

1. 공유 토큰을 응답에서 잘못 꺼내 빈 문자열로 `/view/`에 접속했고, 그게 랜딩
   페이지로 떨어지자 **"만료된 링크가 랜딩 페이지를 보여 준다"는 없는 결함**을
   보고할 뻔했습니다
2. 링크 만료는 `days` 단위인데 타임스탬프로 만들려 해서 공유가 생성되지도 않았습니다
3. `networkidle`을 기다렸는데 이 페이지는 연결을 열어 두므로 영영 오지 않습니다

세 번 다 **다시 재서** 잡혔습니다. 첫 번째는 제품 코드를 열어 보고서야 제 쪽이
틀렸다는 걸 알았습니다.
