# Ptium v0.83.0

지난 판에 이어 **같은 9장을 계속 봤습니다.** 두 개가 더 나왔습니다.

## 숫자 하나가 조용히 사라졌습니다

모델이 이렇게 썼습니다.

```
::hero 투자
- 총 투자액 | 24억 원
- 회수 기간 | 3년
```

슬라이드에는 **24억 원만** 있었습니다. `layoutHero` 는 `items[0]` 을 그립니다. 나머지는
**아무 말 없이** 버려졌습니다.

모델에게 "hero 는 슬라이드가 말하는 그 하나의 숫자" 라고 이미 안내하고 있고, 그런데도 둘을
썼습니다. 안내는 안내고, **저자가 쓴 숫자를 말없이 버리는 것은 이 제품에서 가장 나쁜 종류의
결함** 입니다.

이제 이름 붙은 숫자가 둘 이상이면 **지표 행(kpi)** 으로 그립니다. 둘 다 남고, 덱이 컴포넌트를
바꿨다고 말합니다. 하나면 여전히 hero 입니다.

| 이전 | 이번 |
|---|---|
| **24억 원** | **24억 원** · **3년** |

## 비교의 요점이 반대편에 있었습니다

비교 슬라이드의 요점은 대개 자기가 어느 쪽인지 말합니다.

```
> 현재 | 자동화
- 현재: 0.8% 오배송, 인력 비용 증가
- 자동화: 0.1% 목표, 인력 30% 절감
- 처리 속도 2배 향상 기대
```

가운데서 반으로 자르면 **`자동화:` 요점이 `현재` 머리말 아래** 로 갑니다. 슬라이드가 말하는
것의 **반대를 주장하는 꼴** 이고, 게다가 모든 줄이 자기 단의 이름을 다시 말합니다.

이제 자기 쪽을 말하는 요점은 **그 쪽으로** 갑니다 — 이름은 떼고. 접두사가 없는 요점은 **바로
앞 요점을 따라갑니다** ("자동화: 0.1% 목표" 다음의 "처리 속도 2배 향상 기대" 는 누가 읽어도
자동화 이야기입니다). 한쪽만 자기 이름을 말한다면 다른 쪽에 대해 아무 말도 안 한 것이므로,
그때는 반으로 자르던 규칙이 그대로입니다.

| | 이전 | 이번 |
|---|---|---|
| 현재 | `현재: 0.8% 오배송` · `자동화: 0.1% 목표` | `0.8% 오배송, 인력 비용 증가` |
| 자동화 | `처리 속도 2배 향상 기대` | `0.1% 목표, 인력 30% 절감` · `처리 속도 2배 향상 기대` |

## 확인

같은 덱을 다시 그려 눈으로 봤습니다. 24억 원과 3년이 나란히 서고, 현재 단에는 현재 상태가,
자동화 단에는 달라지는 것이 있습니다.

## 설치

오프라인 설치 방법은 [docs/offline-deployment.md](offline-deployment.md) 를 보세요. 이미지에
Postgres 와 nginx 는 들어 있지 않습니다 — 배포할 때 `DATABASE_URL` 로 DSN 을 지정합니다.
