# Ptium v1.2.0

지난 판에서 공유 API 를 만들었는데, **작업 공간에서는 그걸 부를 방법이 없었습니다.**

## 편집기에 공유 버튼

`공유` 를 누르면 — 무엇을 위한 링크인지 적고, 기간을 고르고, **만들면서 바로 복사** 됩니다.

```
복사했습니다   http://…/view/OG1meWIsuBzQWvFRIGzI-h9zdQyq0KYu   [복사]
임원 검토
직접 회수할 때까지 · 0회 열림                                    [회수]
```

주소는 **한 번만 보이고**, 대화상자가 그렇게 말합니다 — 서버는 다이제스트만 갖고 있으니까요.
아래에는 열려 있는 링크와 각각 몇 번 열렸는지, 그리고 닫는 버튼이 있습니다.

## 그걸 브라우저로 몰아 보다가 더 나쁜 걸 찾았습니다

**파일에서 가져온 덱은 편집이 안 되고 있었습니다.**

가져오기는 덱을 만들면서 편집에 필요한 필드(테마·대상·어조)를 **비워 둔 채** 저장했습니다.
그 뒤 모든 저장은 **이미 비어 있던 것 때문에** 검증에 걸렸습니다.

```
PATCH /api/v1/presentations/… → 422 theme and language are required
```

편집기는 **키를 누를 때마다 조용히 422 를 받고 있었습니다.** 가져온 덱은 **볼 수만 있고 고칠
수는 없는 덱** 이었습니다.

- 가져오기가 이제 다른 모든 경로와 똑같이 **배포 기본값으로 채웁니다**
- 편집은 **비어 있는 것을 채워서** 진행합니다 — 이미 가져와 둔 덱들이 업그레이드 후 **바로
  편집 가능** 해집니다

다른 도구의 덱을 가져오는 스윕이 이제 **가져온 뒤 이름을 바꿔 봅니다.** 이 결함을 잡는 데는
그거면 충분했습니다.
