# Ptium v1.11.7

## 지시어를 다음 낱말에 붙여 쓴 경우

모델이 이렇게 씁니다 — 다음 낱말이 조사로 시작하면 띄어쓰기를 빠뜨립니다.

```
!notes이 장은 핵심 전략임을 강조합니다
```

`!notes` 는 원래부터 이걸 제대로 읽고 있었습니다(노트가 "이 장은…" 으로 시작). 그런데 그
처리를 하는 목록에 **`!skip` 과 `!출처` 계열 일부가 빠져 있었습니다.** 그래서 `!skip이 장은
부록입니다` 는 "알 수 없는 지시어"가 되고, **건너뛰기가 걸리지 않은 채 발표에 남았습니다.**
목록에 넣었습니다.

## 이름이 비슷할 뿐인 낱말은 지시어가 아닙니다

같은 자리를 보다가 반대쪽 구멍도 나왔습니다. 판정이 **접두사 일치** 였습니다:

```
!noteworthy 이건 지시어가 아닙니다   →  발표자 노트로 들어감
```

`note` 로 시작하는 낱말은 전부 노트가 됐습니다. 이번 세션에서 두 번 고친 것과 같은
종류입니다 — 숫자의 자릿수가 다른 숫자 안에 들어 있다고 인용으로 판정하던 것, `\b` 가
한글에서는 모든 자리를 낱말 경계로 보던 것. 이제 **`note`/`notes` 정확히 일치** 하거나,
조사가 붙은 형태일 때만 지시어입니다. 나머지는 경고와 함께 원래 글자로 남습니다.

저장된 덱 2,800여 개의 원본을 세어 보고 바꿨습니다 — 실제로 쓰인 지시어는 `notes` 3,248회,
`source` 416회, 그리고 붙여 쓴 `notes이` 2회뿐이라, 이 조임으로 뜻이 달라지는 덱은 없습니다.
