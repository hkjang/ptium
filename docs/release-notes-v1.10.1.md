# Ptium v1.10.1

v1.10.0 에서 적어 둔 "아직 없는 것들" 중 첫 번째입니다.

## 썸네일을 끌어서 순서 바꾸기

지금까지 순서를 바꾸는 방법은 **Alt+↑ / Alt+↓** 뿐이었습니다. 50장짜리 덱에서 1번을 40번 뒤로
보내려면 **39번을 눌러야** 했습니다.

이제 왼쪽 목록에서 **끌어다 놓으면** 됩니다.

- 놓을 자리에 **보라색 선** 이 뜹니다 — 슬라이드 위가 아니라 **슬라이드 사이** 라서, 어디에
  들어갈지 눈으로 확인하고 놓습니다
- 끌고 있는 썸네일은 흐려집니다
- **목록 끝까지 끌면 목록이 따라 스크롤** 합니다. 50장 덱에서는 이게 없으면 화면에 보이는
  범위 안에서만 옮길 수 있습니다 (가장자리에서 초당 약 700px)
- 옮긴 것은 **실행 취소** 로 되돌아가고, 저장하면 그대로 남습니다

### 한 칸 밀리는 실수를 피했습니다

끌어다 놓는 자리는 슬라이드가 아니라 **틈** 입니다(0은 맨 앞, 개수는 맨 뒤). 그런데 옮길
슬라이드를 목록에서 빼내는 순간 **그 뒤의 틈은 전부 한 칸씩 당겨집니다.** 이걸 빠뜨리면 뒤로
끌 때마다 한 칸씩 더 가서 놓입니다. 규칙을 따로 떼어 테스트로 고정했습니다 — 앞으로 끌 때,
뒤로 끌 때, 맨 앞·맨 뒤로 보낼 때, 제자리에 놓을 때.

실제로 A·B·C·D·E 덱에서 A를 D 뒤로 끌어 **B C D A E** 가 되는 것과, 저장된 원본도 같은 순서인
것을 확인했습니다.

## 설치

```bash
gzip -dc ptium-1.10.1.tar.gz | docker load
```
