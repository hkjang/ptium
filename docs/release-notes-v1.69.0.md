# 1.69.0 — 앞 화면이 덱을 전부 내려받지 않습니다

앞 화면은 카드 세 장과 숫자 세 개를 보여 줍니다. 그 숫자를 내려면 **계정의 덱을
전부 가져오고 있었습니다.** 한 번에 100개씩.

덱이 2,656개인 계정에서 잰 값입니다.

| | 고치기 전 | 고친 뒤 |
| --- | --- | --- |
| 앞 화면이 뜨기까지 | 4,046ms | **392ms** |
| API 요청 (전체) | 30건 | **5건** |
| 그중 `/presentations` | **27건** | 1건 |

덱을 하나 만들 때마다 이 비용이 늘어납니다. 3,000개면 30번, 10,000개면 100번.
덱이 늘어난다는 것은 이 제품을 쓰고 있다는 뜻이니, **잘 쓸수록 앞 화면이
느려지는** 구조였습니다.

이제 데이터베이스가 한 번에 셉니다.

- `GET /api/v1/presentations/summary` — 덱 수, 슬라이드 수, 내보낼 수 있는 덱 수
- 카드 세 장은 목록 한 페이지(3개)만 받습니다
- 휴지통에 있는 덱은 세지 않습니다

보이는 숫자는 그대로입니다: 2,656 · 15,407 · 2,326. 전부 가져와 세던 값과
정확히 같습니다.

## 덤으로

새 경로를 문서에 적지 않고 넘어가려다, **지난 판에 넣어 둔 시험이 잡았습니다** —
"답을 하는데 설명서에 없는 경로". 시험이 자기 일을 했습니다.

## 확인

- 브라우저로 앞 화면을 열어 요청 수와 시간을 재고, 숫자 셋과 카드 셋이 예전과
  같은지 확인했습니다.
- 요약이 세는 덱 수가 목록이 말하는 총계와 같은지 스윕에서 확인합니다.
