# Ptium v1.16.1

## 어느 덱이 나를 기다리는지 목록에서 보입니다

1.16.0 으로 검토가 대화가 됐는데, 한 가지가 빠져 있었습니다. **검토자가 링크에 의견을
남겨도 덱을 열어 보기 전에는 알 길이 없었습니다.** 덱이 열두 개면 열두 번 열어 봐야
했습니다.

이제 덱 목록의 카드에 `의견 2` 가 뜹니다.

- **실타래 단위**로 셉니다 — 의견 하나에 답글이 셋 달려도 처리할 일은 하나입니다
- **반영함** 을 찍으면 사라집니다
- 편집기 안의 `의견 N` 배지는 예전부터 있었습니다. 목록에 없던 것이 문제였습니다

## 확인

- 스윕: 의견 2건 중 하나를 반영하면 목록의 수가 1이 되고, 답글은 세지 않습니다 (452 checks)
- 목록 질의에 서브쿼리 하나가 늘었습니다(인덱스 `slide_comments_deck_idx` 사용)
