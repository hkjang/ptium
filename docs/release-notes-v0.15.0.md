# Ptium v0.15.0

AI가 만든 부분을 캔버스에서 그대로 고칠 수 있게 했습니다. 지금까지 편집기는 **생성된
슬라이드 위에 새 개체를 얹을 수만** 있었습니다. 생성된 제목·본문·컴포넌트는 배경 그림의
일부였고, 그림에 대고 할 수 있는 일은 그 위에 덧그리는 것뿐이었습니다.

## AI가 만든 영역이 개체가 됩니다

- 슬라이드의 글을 클릭하면 선택되고, 한 번 더 누르면 **슬라이드 위에서 바로 타이핑**합니다.
  글꼴·크기·색은 템플릿의 것이고 배경도 슬라이드의 것이므로, 입력하는 화면이 곧 인쇄될
  화면입니다.
- 드래그하면 영역이 통째로 움직입니다. 움직이는 것은 윤곽선이 아니라 **서버가 그린 실제
  그림**입니다 — 옮기는 동안 원래 자리에 잔상이 남지 않습니다. 모서리를 끌면 크기가 바뀌고,
  넓어진 상자는 더 많은 줄을 담습니다.
- 옮긴 영역은 **그 슬라이드에서만** 옮겨집니다. 템플릿과 다른 슬라이드는 그대로이고,
  **원래 자리로** 한 번이면 되돌아갑니다. 내보낸 PPTX도 같은 자리에 그립니다.
- 레이어 패널이 템플릿 영역과 자유 배치 개체를 함께 보여줍니다.

## 컴포넌트를 항목 단위로 고칩니다

핵심 지표·타임라인·비교·표·차트를 클릭하면 오른쪽 패널에서 항목의 이름·값·설명을 고치고,
더하고, 지웁니다. 형식도 바꿉니다 — 목록을 지표로, 지표를 단계로, 단계를 비교로. 고치는
즉시 템플릿으로 다시 그려집니다. 지금까지 컴포넌트를 고치려면 코드 탭에서 소스를 다시
써야 했습니다.

## 한 장만 AI에게 다시 시킵니다

선택한 영역을 짚어 **짧게 · 자세히 · 컴포넌트로 · 발표 노트**, 또는 직접 쓴 지시로 다시
쓰게 합니다(`POST …/slides/{n}/revise`).

- 덱 전체를 재생성하지 않으므로 나머지 슬라이드의 편집이 사라지지 않습니다.
- 모델에게는 그 슬라이드의 소스, **레이아웃의 영역별 수용량**, 앞뒤 슬라이드의 제목,
  그리고 **측정 결과**를 함께 줍니다. "0.9cm 넘침"은 고쳐 쓸 수 있는 지시이고,
  "너무 길다"는 그렇지 않습니다.
- 제안은 저장하지 않고 화면에 적용합니다. **AI 이전으로** 한 번이면 되돌립니다.
- 검사 결과 목록의 **AI로 고치기**가 같은 경로로 그 슬라이드를 고칩니다.

## 같은 말을 두 번 하는 슬라이드를 잡아냅니다

모델은 줄 수를 채우라고 하면 멈추는 대신 같은 말을 다시 씁니다. 실제로 생성된 덱에서
"온프레미스 유지비 증가로 비용 효율성 저하"와 "온프레미스 유지비 급증으로 비용 효율성이
심각하게 저하됩니다"가 한 장에 나란히 놓였습니다. 이제 이런 줄을 **다듬을 곳(`repeat`)**
으로 보고하고, 생성 프롬프트에도 "다른 말로 같은 요점을 반복하지 말 것, 더 할 말이 없으면
멈출 것"을 규칙으로 넣었습니다. 나란한 구조("매출은 전년 대비 12% 늘어…", "비용은 전년
대비 8% 줄어…")는 좋은 글쓰기이므로 걸리지 않습니다.

## 고쳐진 것

- **텍스트 상자를 두 번 눌러도 편집이 열리지 않던 문제.** 드래그가 포인터를 캡처하면
  뒤따르는 마우스 이벤트가 페이지로 옮겨가 브라우저의 더블클릭이 개체에 닿지 않았습니다.
  이제 같은 개체를 450ms 안에 두 번 누른 것을 직접 판정합니다.
- **코드를 적용하면 캔버스 작업이 사라지던 문제.** 슬라이드 수가 같으면 자리 그대로,
  달라졌으면 제목이 그대로인 슬라이드에 한해 자유 배치 개체와 옮긴 영역이 따라갑니다.
  전혀 다른 슬라이드로 옮겨 붙이느니 버리는 편이 낫기 때문입니다.
- `frames`를 언급하지 않은 수정은 옮긴 영역을 그대로 둡니다. `blocks`·`images`·`elements`와
  같은 규칙이며, 지우려면 `"frames": {}`를 보냅니다.
- **두 줄짜리 비교표의 머리글이 항목으로 그려지던 문제.** 모델이 `- 현재 | 목표` 다음에
  값 한 줄을 쓰면, 머리글이 카드 하나가 되고 진짜 비교가 나머지 카드에 우겨넣어졌습니다.
  이제 첫 줄이 대비되는 두 쪽의 이름이면 줄 수와 상관없이 머리글로 보고, 두 칸짜리 표로
  그립니다.
- 영역을 슬라이드 밖으로 완전히 끌어낼 수 없습니다. 4분의 1까지는 흘려도(의도된 디자인)
  그 이상은 잃어버린 것이지 배치한 것이 아닙니다.

## API

| 요청 | 하는 일 |
| --- | --- |
| `GET …/slides/{n}/regions` | 한 슬라이드의 모든 영역: 어디에 그려지는지, 무엇을 담았는지, 어떤 서식인지 |
| `GET …/preview.svg?slide=N&only=body2` | 그 영역만, 배경 없는 투명한 페이지에 |
| `GET …/preview.svg?slide=N&exclude=body2` | 그 영역을 뺀 슬라이드 |
| `POST …/slides/{n}/revise` | 한 장의 다른 초안. 저장하지 않고 제안만 |

좌표는 슬라이드에 대한 백분율입니다. 브라우저와 PPTX 양쪽에 변환 없이 줄 수 있는 단위가
그것뿐입니다.
