# Ptium v1.51.0

**모델 없이 만든 덱은 뼈대입니다. 그런데 아무 말도 하지 않았습니다.**

## 모델이 없는 배포가 받는 것

```
2. 기대 효과
   · 무엇이 어떻게 달라지는지 지표로 말합니다.
   · 6개월 안에 확인할 지표와 목표
   · 12개월 목표와 그때의 판단 기준
```

이 줄들은 **내용이 아니라 그 자리에 무엇이 들어가야 하는지 가리키는 말**입니다.
설계상 그렇게 만들어졌습니다 — 모델이 없으면 내장 작성기가 뼈대를 세웁니다.

그런데 그 덱의 `generationNotes` 는 **null**, `warnings` 도 **null** 이었습니다.
덱을 요청한 사람은 이것이 제품이 낼 수 있는 최선인지, 채워 넣어야 할 틀인지 알 길이
없었습니다.

## 제품은 다른 자리에서는 다 말합니다

- 가져오기: `표 4개를 다시 그렸고, 그 가운데 3곳은 잘렸습니다`
- 짧은 덱: `12장을 요청하셨고 9장을 썼습니다. 브리프가 다루는 주제가 1개라…`
- 모델이 쓴 덱: `브리프에 없는 출처 5건을 AI가 지어내 지웠습니다`
- 모델이 실패했을 때: `AI 모델이 이 덱을 쓰지 못해 Ptium이 대신 썼습니다`

**모델이 애초에 없는 경우**만 비어 있었습니다 — 폐쇄망 배포의 평상 상태인데도요.

## 이제 말합니다

```
이 배포에는 연결된 AI 모델이 없어 내장 작성기가 브리프로 뼈대를 썼습니다.
각 줄은 그 자리에 무엇이 들어가야 하는지 가리키는 말이니
발표 전에 본인의 문장으로 바꿔 주세요.
```

한국어·영어·일본어·중국어 네 언어 모두에 넣었고, 덱의 노트와 경고 양쪽에 제일 앞에
놓입니다. 네 언어 모두 테스트로 고정했습니다.
