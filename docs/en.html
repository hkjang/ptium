Core Features

From prompt to presentation, every step is intelligently handled

📑

Your Template, Untouched

Masters, layouts, theme colours, fonts and logos stay exactly as your designer made them; only the slides are filled. Page numbers appear where the template keeps a place for one, and tables and charts export as real PowerPoint objects — a chart opens its numbers in Excel when you ask to edit its data.

📥

Bring In What You Have

Upload last quarter's deck and its titles, points, speaker notes, tables, photographs and the numbers behind its charts come across, redrawn in the design you choose. A logo repeated on every slide is left out, and whatever could not be carried is reported rather than dropped in silence.

✨

Rewrite, Don't Replace

Hand a whole deck to the model and its facts stay: every number, name and claim reappears unchanged. What improves is the craft — titles that argue, points that carry one idea, speaker notes on every slide. The previous deck stays in version history.

📐

Measured, Not Hoped For

Every deck is drawn and measured — text past its box, lines that collide, a slide saying the same thing twice — and the slides that do not fit go back to the model with the measurement. A rewrite is kept only when it measures better.

🖊️

Editing That Feels Familiar

What the AI wrote is an object: drag it, double-click to fix it, add text boxes, shapes, tables and images over it, then present with a presenter view. Images and slides worth keeping stack up in your own library.

🌐

Whole Offline

With no AI key at all a deterministic local writer still produces a finished deck. One image tar.gz and a PostgreSQL DSN is the entire deployment, and uploaded images live in the database or on a mounted volume, whichever the site prefers.

Template Rendering Pipeline

Direct Office Open XML processing — no PowerPoint or LibreOffice needed

template-pipeline 
Upload .pptx/.potx
        │
   Analyzer  →  Manifest: slide size, theme colors & fonts,
        │        per-layout placeholders (role, position, text capacity)
        │
   Plan pass  →  Narrative arc, one layout chosen per slide
        │
   Write pass →  Copy written into named slots within budgets
        │
   Composer   →  Validates slots, repairs unknown layouts, fits overflow
        │
   Renderer   →  Original package + newly generated slide parts

Enterprise-Grade Security

Self-host for data sovereignty with industry-standard security protocols

🔐

OIDC / Keycloak SSO

Standard OIDC authentication with PKCE (S256). Keycloak realm or client roles automatically map to Ptium admin roles.

🔄

API Key Rotation

Issue scoped, expirable hashed API keys with zero-downtime grace period rotation. The raw key is shown only once at creation.

🛡️

Secret Management

AI provider keys and OIDC client secrets are write-only. Logs, incidents, and API responses automatically redact sensitive information.

📋

Incident Tracking

Server errors receive stable fingerprints. Manage severity, status, notes, and resolution history from the admin console with request ID correlation.

Built for Developers

Integrate with REST API and MCP for seamless workflow automation

REST REST API v1

Versioned REST API with OpenAPI schema. Authenticate with OIDC tokens or API keys.

bash — REST API Example
# List presentations
curl -H 'Authorization: Bearer ptium_...' \
  http://localhost:8080/api/v1/presentations

# Upload a template
curl -H 'Authorization: Bearer ptium_...' \
  -F 'file=@company-template.pptx' \
  -F 'name=Corporate Standard' \
  http://localhost:8080/api/v1/templates
MCP MCP JSON-RPC

Create presentations directly from AI agents like Claude Desktop and Cursor.

json — MCP Tool Call Example
{
  "jsonrpc": "2.0",
  "id": 2,
  "method": "tools/call",
  "params": {
    "name": "ptium.create_presentation",
    "arguments": {
      "title": "2027 Product Strategy",
      "prompt": "Executive deck for regional leaders",
      "language": "en",
      "theme": "slate-classic",
      "slideCount": 10
    }
  }

Flexible Deployment

Choose the deployment method that fits your environment

🐳 Docker Compose

Run PostgreSQL, Go service, and React app all at once. The fastest way to get started for development and evaluation.

cp .env.example .env
docker compose up --build

# Web UI: http://localhost:8080
# API:   http://localhost:8080/api/v1
# MCP:   http://localhost:8080/mcp

⚡ Single Binary

Run with just a Go binary and a PostgreSQL DSN. Schema and default settings are created automatically on first run.

cd server
DATABASE_URL='postgres://ptium:ptium@localhost:5432/ptium?sslmode=disable' \
  go run ./cmd/ptium

# Auto migration on first run
# Works without OIDC/AI keys

📦 Offline Bundle

Docker image bundle for air-gapped environments without internet. Includes checksum verification, image loading, and upgrade support.

# Build the bundle on a connected host
.\scripts\build-offline.ps1

# Deploy on the target host
docker load -i ptium-0.1.0.tar.gz
docker compose -f docker-compose.offline.yml up
