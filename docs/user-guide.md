# 사용 가이드

Ptium은 **쓴 글**을 **가지고 있는 템플릿**에 맞춰 그립니다. 그래서 순서는 언제나 같습니다.
무엇을 말할지 적고, 어느 디자인에 담을지 고르고, 고칩니다.

제품 안에서도 같은 내용을 **사용 가이드**(`/guide`) 화면에서 볼 수 있고, 편집기와 발표
화면에서는 아무 때나 <kbd>?</kbd>를 눌러 단축키를 볼 수 있습니다.

## 5분 만에 첫 덱

1. **새로 만들기**에서 무엇을 발표할지 두세 문장으로 적습니다.
2. **추천 디자인으로 바로 생성**을 누르거나, **디자인 고르기**에서 청중·톤·장수를 조정합니다.
3. 편집기가 열리고, 생성이 끝나면 슬라이드가 채워집니다.
4. 왼쪽 목록에서 장을 고르고, 캔버스에서 **더블클릭**해 글을 고칩니다.
5. **발표**(<kbd>F5</kbd>)로 보여 주거나 **내보내기**로 PowerPoint 파일을 받습니다.

저장 버튼은 없습니다. 고치는 즉시 자동 저장되고(<kbd>Ctrl</kbd>+<kbd>S</kbd>로 지금 저장),
**버전 이력**에서 예전 상태로 되돌릴 수 있습니다.

## 브리프 잘 쓰기

생성 품질의 대부분은 첫 화면에 적는 몇 문장에서 결정됩니다.

| 넣을 것 | 왜 |
| --- | --- |
| **주제** | "AI 도입"보다 "사내 개발팀의 AI 코딩 도구 도입 성과" |
| **청중** | 같은 내용도 경영진용과 실무자용은 다른 덱입니다 |
| **목적** | 승인·공유·교육 중 무엇인지에 따라 결론의 자리가 달라집니다 |
| **숫자** | 아는 수치를 적으면 지표로 그려집니다. 적지 않은 숫자를 지어내지는 않습니다 |

```
아쉬운 브리프:  AI 도입 발표자료 만들어줘

좋은 브리프:    사내 개발팀의 AI 코딩 도구 도입 성과를 경영진에게 보고하는 8장짜리 덱.
               개발 속도 32% 개선, 12개월 ROI, 내년 전사 확대 방안을 포함해줘.
```

## 이미 있는 자료 가져오기

지난 분기 보고서, 잘 먹힌 제안서, 늘 복사해 쓰는 회사 소개 — **프레젠테이션 → 기존 자료
가져오기**에서 `.pptx`를 올리면 Ptium 덱이 됩니다.

- 제목 · 요점(들여쓰기 그대로) · 발표자 노트 · **표**가 그대로 넘어옵니다. 표는 새 덱의
  디자인으로 다시 그려집니다.
- 표지 · 간지 같은 **슬라이드의 성격**도 함께 넘어옵니다.
- **그림과 차트는 넘어오지 않습니다.** 4:3에 맞춰 놓인 사진을 16:9 디자인에 옮겨 놓고
  괜찮기를 바랄 수는 없기 때문입니다. 몇 개가 있었는지 알려 주므로 이미지 탭에서 다시 넣거나,
  숫자를 `::bars`로 적어 다시 그리면 됩니다.
- 가져온 뒤에는 보통 덱입니다 — 템플릿을 바꾸고, 글을 고치고, AI에게 한 장씩 다시 쓰게 할 수
  있습니다.

## 템플릿 고르기

기본 제공 디자인은 50종입니다. 밝기·구성·성격 태그로 좁혀 고르고, 브리프를 적으면 어울리는
몇 개를 먼저 보여 줍니다.

- **회사 템플릿** — 가지고 있는 `.pptx`를 올리면 그 파일의 레이아웃·글꼴·색으로 생성합니다.
  슬라이드 마스터에 제목+본문, 2단, 그림 자리가 있는 파일일수록 잘 맞습니다.
- **메타포 계열** — Orbit(성장)·Arc(여정)·Diagonal(전환)·Dots(데이터)·Layers(구조)·
  Wash(비전)는 표지에서 도형으로 이야기를 한 번 말합니다.
- 디자인을 나중에 바꿔도 글은 그대로 옮겨집니다.

## 편집하기

캔버스에는 성격이 다른 두 가지가 있습니다.

| | 템플릿 영역 | 덧붙인 개체 |
| --- | --- | --- |
| 무엇 | 제목·본문처럼 템플릿이 정해 준 자리 | 글상자·도형·표·이미지 |
| 누가 채움 | AI 생성 결과가 들어감 | 내가 얹음 |
| 할 수 있는 것 | 편집·이동·**원래 자리로**·AI로 다시 쓰기 | 자유 배치·그룹·정렬·순서 |
| 내보내면 | 진짜 자리 표시자 | 진짜 도형·표·그림 |

- **AI로 다시 쓰기** — 영역을 오른쪽 클릭하면 그 한 장만 다시 씁니다. 되돌릴 수 있습니다.
- **측정 배지** — 실제로 그려 보고 글자가 넘쳤는지, 겹쳤는지를 셉니다. "결함"은 잘못 그려진
  것, "다듬을 곳"은 그래도 되지만 더 좋아질 수 있는 것입니다.

### 저장한 슬라이드

회사 소개·팀·연락처·면책조항처럼 매번 다시 만드는 슬라이드는 편집기 오른쪽 **슬라이드** 탭에서
저장해 두고 어느 덱에나 넣습니다.

- 그림이 아니라 **글로 저장**되므로, 넣는 순간 **그 덱의 디자인**으로 다시 그려집니다.
- 미리보기도 지금 덱의 디자인으로 보여 줍니다 — 넣기 전에 어떻게 될지 보입니다.
- 즐겨찾기·태그·검색은 이미지와 같고, 자주 넣는 것이 앞에 옵니다.
- 넣고 나면 보통 슬라이드입니다. 라이브러리에서 지워도 이미 넣은 것은 남습니다.
- 같은 이름으로 다시 저장하면 갱신됩니다(회사 소개를 고쳤을 때).

## 이미지 넣기

- **붙여넣기** — 캡처한 이미지를 캔버스에서 <kbd>Ctrl</kbd>+<kbd>V</kbd>.
- **끌어다 놓기** — 이미지 파일을 캔버스에 놓으면 놓은 자리에 들어갑니다.
- **영역 채우기** — 그림 자리가 있는 레이아웃이면 그 영역을 오른쪽 클릭 → 이미지.
- **코드에서** — `::image 로고` 로 부릅니다.

PNG · JPEG · GIF · SVG, 한 장당 16MB까지. 같은 이름으로 다시 올리면 교체되므로, 로고를
바꾸면 그 이름을 쓰던 덱들이 함께 바뀝니다. 같은 파일을 다시 올리면 새로 만들지 않고 이미
있는 이미지를 씁니다.

### 내 이미지

올린 이미지는 계정에 남아 모든 덱에서 다시 씁니다. **내 이미지**(`/images`)에서 자기 체계를
만드세요.

| | |
| --- | --- |
| **즐겨찾기** | 별표를 누르면 어느 정렬에서도 맨 앞. 로고처럼 매번 쓰는 것에 |
| **태그** | 로고·제품컷·배경처럼 쓰임으로 묶기. 태그를 누르면 그것만 |
| **덱 N개** | 그 이미지를 실제로 쓰는 덱의 수. 저장할 때마다 다시 세므로 덱에서 빼면 바로 줄어듭니다 |
| **정렬** | 최근 올림 · 최근 사용 · 자주 사용 · 이름순 |
| **이름 바꾸기** | 이름을 두 번 누르면 바로. 코드에서 부르던 이름도 함께 바뀝니다 |

### 자주 쓰는 디자인

템플릿도 같습니다. 별표를 눌러 둔 디자인과 **실제로 덱을 만든** 디자인은 템플릿 화면과 새로
만들기에서 맨 앞에 모이고, 추천에도 먼저 반영됩니다.

이미지를 어디에 저장할지는 배포에서 정합니다(데이터베이스 또는 마운트한 볼륨).
[offline-deployment.md](offline-deployment.md)의 "어디에 이미지를 두는가"를 참고하세요.

## 코드로 쓰기

덱은 원래 텍스트입니다. 편집기의 **코드** 탭에서 덱 전체를 글로 보고 고칠 수 있습니다.

```
# 클라우드 전환 로드맵
@cover
> 2026년 하반기 · 임원 보고

# 왜 지금인가
- 온프레미스 계약이 9월에 끝납니다
- 재계약가는 전년 대비 22% 인상됩니다
::kpi 핵심 지표
- 전환 대상 | 42개
- 예상 절감 | 18%
::
!notes 예산 질문이 나오면 3장의 표를 보여 줍니다.
```

전체 문법과 컴포넌트 목록은 [deck-source.md](deck-source.md)에 있습니다.

## 발표 자료다움

만들어진 덱은 사람이 만든 보고서의 관습을 따릅니다.

- **페이지 번호** — 템플릿이 번호 자리를 둔 디자인이면 자동으로 들어갑니다. 표지에는 넣지
  않습니다. 미리보기에도 같은 자리에 그려지므로 화면과 파일이 다르지 않습니다. PowerPoint에서
  순서를 바꿔도 번호가 따라옵니다(필드로 넣습니다). 번호 자리가 없는 디자인에는 넣지 않습니다 —
  디자이너가 그렇게 정한 것입니다.
- **목차** — 7장 이상이면 표지 다음에 목차가 들어갑니다. 그보다 짧으면 바로 뒤 네 장이 할 말을
  한 장 더 쓰는 셈이라 넣지 않습니다.
- **발표자 노트** — 각 장에서 무엇을 말할지 초안이 함께 들어갑니다.
- **표는 진짜 표로** 나갑니다. PowerPoint에서 셀을 고치고 행을 더할 수 있고, 다른 문서로
  복사해도 표로 붙습니다. 지표·차트·단계 같은 컴포넌트는 도형으로 나가므로 색과 위치를
  그대로 편집할 수 있습니다.

## 발표와 내보내기

- **발표**(<kbd>F5</kbd>) — 청중 화면에는 슬라이드만 나옵니다.
- **발표자 보기**(<kbd>P</kbd>) — 두 번째 창에 다음 장·노트·경과 시간. 프로젝터에 발표 창을,
  노트북에 발표자 창을 두세요. 어느 쪽에서 넘겨도 함께 움직입니다.
- **내보내기** — PPTX로 받습니다. 도형·표·차트가 진짜 개체이고 자리 표시자가 그대로 남아
  PowerPoint에서 계속 편집됩니다. **PDF가 필요하면** 내려받은 PPTX를 PowerPoint나
  LibreOffice에서 PDF로 저장하세요 — 글꼴이 설치된 그 컴퓨터에서 만드는 편이 더 정확합니다.
  (제품 안 PDF 내보내기는 아직 제공하지 않습니다.)

## 잘 안 될 때

| 증상 | 확인할 것 |
| --- | --- |
| 생성이 실패했어요 | 편집기 위쪽에 이유가 그대로 나옵니다. **다시 시도**를 누르세요. AI 연결이 없으면 관리자에게 서비스 설정의 AI 항목을 확인해 달라고 하세요 |
| 글자가 넘쳐요 | 측정 배지의 "결함"을 눌러 그 장으로 가서, 요점을 줄이거나 담을 수 있는 레이아웃으로 바꾸거나 AI로 다시 쓰기를 쓰세요 |
| 올린 템플릿이 어색해요 | 레이아웃이 적은 템플릿은 모든 슬라이드가 같은 모양이 됩니다. 마스터에 본문·2단·그림 자리가 있는 파일을 쓰세요 |
| 이미지가 안 보여요 | 저장소에서 사라진 것입니다(저장 위치 변경, 볼륨 복원 누락). 같은 이름으로 다시 올리면 교체됩니다 |
| 로그인이 자꾸 풀려요 | 세션 기간은 관리자가 설정합니다 |
