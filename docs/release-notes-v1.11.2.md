# Ptium v1.11.2

## 40장짜리 PDF 가 24MB 였습니다. 2.7MB 입니다.

큰 덱으로 밀어 보다 나왔습니다. 슬라이드마다 같은 사진이 들어간 40장 덱을 PDF 로 받으면
**24,433,348 바이트** 였습니다.

이유는 단순합니다. PDF 는 각 슬라이드의 그림에서 만들어지고, **그림마다 자기 사진 사본을
들고 옵니다.** 그걸 그대로 40번 파일에 넣고 있었습니다. PPTX 는 진작부터 같은 로고를 한 번만
저장하고 있었으니, 두 형식이 같은 덱을 놓고 서로 다른 말을 하고 있던 셈입니다.

같은 바이트는 이제 **한 번만** 들어갑니다.

```
40 페이지, 링크 78개
24,433,348 바이트  →  2,716,716 바이트   (0.6초)
```

한 페이지 안에서 같은 그림을 두 번 그려도 자원 목록에는 한 번만 적힙니다. 스윕에도
넣었습니다 — 다섯 장에 같은 사진을 넣은 덱에서 그림이 두 번 이상 저장되면 실패합니다
(157 checks).
