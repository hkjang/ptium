# Ptium v0.14.0

생성된 프레젠테이션을 별도의 슬라이드 프로그램으로 옮기지 않고 Ptium 안에서 세밀하게
다듬을 수 있는 자유 배치 편집기를 추가했습니다. 편집한 개체는 PowerPoint에서도 계속
수정할 수 있는 네이티브 개체로 내보냅니다.

## 자유 배치 슬라이드 편집기

- 텍스트 상자, 사각형·타원·삼각형·마름모·화살표·별·육각형, 선, 이미지, 표를 슬라이드에
  직접 추가합니다.
- 개체를 드래그해 이동하고 크기와 회전을 조정합니다. 다중 선택, 복제, 삭제, 그룹·그룹 해제,
  정렬·균등 배치, 앞뒤 순서 변경, 잠금을 지원합니다.
- 실행 취소·다시 실행, 복사·붙여넣기, 키보드 단축키, 확대·축소, 격자 표시와 맞춤을 지원합니다.
- 레이어 패널에서 개체를 선택하고 표시 여부와 잠금 상태를 관리합니다.

## 세부 서식과 표

- 텍스트의 글꼴, 크기, 굵기, 색상, 정렬과 도형의 채우기·테두리·투명도·모서리를 편집합니다.
- 선의 두께, 색상, 실선·점선, 시작·끝 화살표를 설정합니다.
- 표의 셀을 직접 편집하고 행·열을 추가하거나 삭제합니다. 헤더 행·열, 글꼴, 본문·헤더 색상,
  테두리와 두께도 조정할 수 있습니다.
- 자산 라이브러리의 이미지를 슬라이드에 놓고 위치·크기·회전을 조정합니다.

## 편집 가능한 PowerPoint 내보내기

- 텍스트, 도형, 선과 화살표는 DrawingML 개체로 내보냅니다.
- 표는 PowerPoint 네이티브 표로 생성되어 내보낸 뒤에도 셀과 서식을 수정할 수 있습니다.
- 브라우저 미리보기와 PPTX 내보내기가 같은 자유 배치 데이터를 사용합니다.

## 안전한 저장과 복구

- 변경 사항을 자동 저장하고, 다른 편집 세션이 먼저 저장한 경우 버전 충돌을 감지합니다.
- 프레젠테이션 버전 이력을 확인하고 원하는 체크포인트로 복원할 수 있습니다.
- 삭제한 프레젠테이션은 휴지통에서 복원할 수 있습니다.
- 템플릿 기반 배경과 자유 배치 개체를 분리해 기존 디자인을 보존합니다.

## 오프라인 설치

```bash
gzip -dc ptium-0.14.0.tar.gz | docker load
sha256sum -c ptium-0.14.0.tar.gz.sha256
```
