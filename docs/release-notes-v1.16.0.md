# Ptium v1.16.0

## 슬라이드 목록에서 ↓ 를 누르면 다음 장이 선택됩니다

편집기 왼쪽 슬라이드 목록에서 방향키를 누르면 **선택이 옮겨가야 하는데 목록이 스크롤만
되고 있었습니다.** 방금 누른 썸네일에 초점이 있으니 브라우저가 목록을 굴린 것입니다 —
손이 기대하는 동작이 아닙니다.

이제 목록 안에서:

- **↓ ↑** (또는 → ←) 로 **다음/이전 장 선택**, 선택을 따라 초점도 옮겨갑니다
- **Home · End** 로 처음/마지막 장
- 첫 장에서 ↑, 마지막 장에서 ↓ 는 **아무 일도 일어나지 않습니다** — 페이지가 대신
  스크롤되지도 않습니다
- **Alt+↑ ↓** 는 예전대로 **순서 바꾸기**입니다. 고르는 것과 옮기는 것은 다른 동작입니다

## 검토가 대화가 됩니다 (답글)

검토자가 "4번 숫자가 지난 분기 것입니다" 라고 남기면, 지금까지 작성자가 할 수 있는 것은
**반영함 도장을 찍는 것뿐**이었습니다. 무엇을 어떻게 고쳤는지 말할 자리가 없었고,
링크를 가진 검토자는 자기 의견이 어떻게 됐는지 영영 몰랐습니다.

- 작성자는 **워크스페이스에서 답글**을 답니다 (`POST /api/v1/presentations/{id}/comments`)
- 검토자는 **링크에서 그 답글을 읽고 다시 답합니다** — 계정 없이
- 답글의 답글은 **같은 실타래로 들어갑니다**. 대화는 실타래이지 나무가 아닙니다
- 답글은 원래 의견이 달린 **그 슬라이드에 붙습니다**(답글 쓸 때 보고 있던 장이 아니라)
- **반영함** 을 찍으면 그 의견과 아래 답글이 **함께** 정리됩니다

## 검사

- 스윕: 검토 의견 → 작성자 답글 → 검토자의 재답글이 한 실타래가 되고, 해결하면 셋이
  함께 닫히며, 남의 덱 의견에 답글을 달면 422 (447 checks)
- 브라우저: 슬라이드 목록에서 ↓ ↑ Home End 가 실제로 선택을 옮기는지 (deep 스윕)
