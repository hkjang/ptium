# Ptium v1.51.1

**제목이 문장 중간에서 끊긴 덱이 100점을 받았습니다.**

## 사람이 실제로 쓰는 브리프로 재 봤습니다

지시문("…8장으로 정리해줘")이 아니라 **줄글**로 적은 브리프 여섯 개를 넣어 봤습니다.

| 브리프 | 표지 |
| --- | --- |
| 우리 회사는 내년에 클라우드 비용을 크게 줄여야 합니다… | `우리 회사는 내년에 클라우드 비용을 크게 줄여야` |
| 데이터 거버넌스 체계를 세우려고 합니다… | `데이터 거버넌스 체계를 세우` |
| 신입 개발자 온보딩이 너무 오래 걸린다는… | `너무 오래 걸린다는 이야기가` |

**여섯 개 모두 100점이었습니다.** 지적은 한 건도 없었습니다.

## 두 가지가 겹쳐 있었습니다

**하나. 끊긴 제목을 찾는 규칙이 이 모양들을 몰랐습니다.** "…크게 줄여야"(해야 하는데
안 한 채 끝남), "…체계를 세우"(어미가 잘린 동사 어간). 규칙에 넣었습니다 —
`분야`·`시야` 처럼 그 음절로 끝나는 멀쩡한 낱말은 건드리지 않도록 `어야|여야|아야|해야`
형태로 적었고, 잘린 어간은 낱말 목록으로 열거했습니다.

**둘. 찾아낸 지적이 점수에 반영되지 않았습니다.** `unfinished` 와 `twiceTitled` 는
이 제품에서 **가장 비싼 조언(12점)** 으로 매겨져 있으면서 **어느 축에도 속해 있지
않아서**, 점수 계산이 그냥 건너뛰고 있었습니다. 지적을 인쇄해 놓고 100점을 주고
있었던 것입니다.

```
이전:  '데이터 거버넌스 체계를 세우'  →  100점 · 지적 0
지금:  '데이터 거버넌스 체계를 세우'  →   98점 · unfinished
```

모든 지적 종류가 어느 축엔가 속하는지도 테스트로 고정했습니다.

## 고치지 못한 것

줄글 브리프에서 **제목 자체를 더 낫게 뽑는 것**은 세 번 시도했고 세 번 다 되돌렸습니다.
문장이 표시하는 주어를 쓰는 규칙을 세 가지 방식으로 만들어 봤지만, 여섯 개 중
서너 개만 나아지고 나머지는 오히려 나빠졌습니다. **좋아졌다고 보일 수 없는 변경은
넣지 않습니다.**

대신 제품이 이제 그것을 **숨기지 않습니다** — 끊긴 제목은 지적되고 점수에도 반영되므로,
쓰는 사람이 고칠 수 있습니다.
