
**같은 열두 음절을 네 번 읽힙니다.** 그리고 2번 장과 3~5번 장이 **같은 덱에서 서로 다른
형식**입니다.

## 주제가 곧 제목이면, 각 장은 그 장이 맡은 면으로 부릅니다

```
[1] 보안 사고 재발 방지 대책
[2] 리스크와 대응
[3] 이행 순서
[4] 기대 효과
[5] 비용과 효과
[6] 다음 단계
```

표지가 주제를 말하고, 각 장은 **자기가 맡은 면**을 말합니다. 브리프가 절을 따로 적은
덱은 달라지지 않습니다 — 그 이름들이 이미 각 장의 제목입니다.

## 기존 검사 하나를 고쳤습니다

`TestATopicIsNotNamedFromTheMiddleOfAClause`는 "주제가 절 제목으로 살아남는가"를
**제목 앞부분 일치**로 확인하고 있었습니다. 이제 제목은 면 이름이므로, 같은 뜻을
**표지에서** 확인하도록 바꿨습니다. 이 검사가 원래 막던 것(주제가 절 중간에서 잘려
"개선을…"로 시작하는 제목)은 **그대로 검사합니다.**
