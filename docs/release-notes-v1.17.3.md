# Ptium v1.17.3

## 이름이 아무 말도 하지 않는 그림은 모델에게 주지 않습니다

살아 있는 모델로 영어 덱과 일본어 덱을 만들어 읽다가, **두 덱 모두 같은 그림**이 얹혀
있는 것을 봤습니다.

```
::image 해커톤_최종발표(해커톤_TeamKCB) (1) · image22.png
```

물류센터 자동화 이야기에도, 분기 실적 이야기에도 관계없는 화면 캡처가 들어갔습니다.

이유는 단순합니다. 모델에게는 **이름 목록만** 줍니다 — 그림을 볼 수는 없으니까요. 그런데
덱을 가져오면 그 안의 그림들이 `가져온 파일 · image22.png` 라는 이름으로 라이브러리에
쌓입니다. **주제를 한 글자도 말해 주지 않는 이름**이고, 모델은 추측할 수밖에 없습니다.

이제 **무엇인지 말해 주는 이름만** 목록에 올립니다.

| 올라감 | 올라가지 않음 |
|---|---|
| `현장 자동화` · `조직도` · `AMR 로봇 20대` · `2026 로드맵` | `보고서 · image7.png` · `IMG_4821.jpg` · `screenshot 2026-08-26.png` · `무제` · `사진.png` |

이미 덱에 들어가 있는 그림은 그대로입니다 — 이름으로 찾아 넣는 경로는 건드리지 않았으므로,
`::image 보고서 · image7.png` 라고 적힌 덱은 계속 그 그림을 그립니다. 바뀐 것은 **모델에게
고르라고 내미는 목록**뿐입니다.

## 설치

```bash
gzip -dc ptium-1.17.3.tar.gz | docker load
```
