# Ptium v1.20.3

어제 "비교는 반복이 아니다"를 넣었으니, **반대쪽**을 확인했습니다 — **진짜 반복은 여전히
잡히는가.** 가진 파일에서 가져온 덱 28개를 다시 재 봤습니다.

일곱 개는 진짜였습니다(제목과 그 아래 불릿이 같은 말인 슬라이드 등). **여덟 번째가 틀렸습니다.**

## 청구서의 두 날짜를 "같은 말"이라고 했습니다

```
⚠ 같은 말을 두 번 합니다:
   "Date due August 20, 2026" 와 "Date of issue August 20, 2026"
```

**만기일과 발행일**입니다. 서로 다른 사실이고, 값이 같을 뿐입니다.

단어가 많이 겹친 이유는 **값이 줄의 대부분**이기 때문입니다 — `August 20, 2026` 이 두 줄에
다 있으니 겹침 비율이 올라갑니다. 앞의 `due` / `of issue` 가 다르다는 것이 이 줄들의
**전부**인데요.

**끝이 같고 그 끝에 숫자가 들어 있으면**, 두 줄은 값을 공유하는 두 사실입니다. 이제 그렇게 봅니다.

- `Date due …` · `Date of issue …` → 지적하지 않습니다
- `Trello: 보드 기반 작업 관리` · `보드 기반 작업 관리` → **여전히 지적합니다**(공유하는 것이
  값이 아니라 말이니까요)

다시 재 봤습니다 — **28개 덱, 지적 7건, 전부 진짜.**

## 왜 이걸 계속 하는가

이 지적은 눈으로만 끝나지 않습니다. **`AI로 고치기` 를 누르면 그 문장이 모델에게 전달되고,
모델은 시키는 대로 지웁니다.** 틀린 지적 하나가 청구서에서 날짜를 지우게 만듭니다.
