# Ptium v0.11.0

격자 정의를 화면에서 편집합니다. 지금까지는 JSON API로만 만들 수 있었습니다.

## 격자 탭

편집기 오른쪽에 **격자** 탭이 생겼습니다.

- 정의 목록에 이름·제목·값 개수가 보입니다. 기본 제공 정의도 함께 나오며, 편집해 저장하면
  그것이 우선하는 자기 정의가 됩니다.
- 편집 화면은 폼입니다 — 제목, 줄 음영, 범례, 첫 열(행 이름)의 이름과 폭 비율, 그리고 값
  목록. 값마다 소스에 쓰는 글자(`R`), 슬라이드에 보일 글자(`실행`), 색 역할, 범례 설명,
  칩으로 그릴지를 정합니다.
- **색은 고를 수 없습니다.** 강조 1~6, 긍정, 부정, 흐림, 본문색 중 **역할**만 고릅니다.
  템플릿이 각자의 테마로 해석하므로 같은 정의가 회사마다 그 회사 색으로 나옵니다.
- 값의 순서가 범례 순서입니다. R·A·C·I는 알파벳순이 아니므로 여기서 정합니다.
- **코드에 넣기**를 누르면 `::grid 이름`과 예시 행이 코드 편집기에 들어갑니다. 코드 탭이
  닫혀 있으면 클립보드에 복사합니다.
- 삭제하면 같은 이름의 기본 정의가 되돌아옵니다.
