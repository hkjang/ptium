# Ptium v0.42.0

**4:3 사내 템플릿**을 만들어 올리고, 그 위에 덱을 지어 한 장씩 봤습니다. 4:3 자체는 문제가
없었습니다 — 영역이 그대로 따라오고, 표·차트·단계 도해가 제자리에 그려지고, 제목이 가운데로
정렬되는 것까지 그 마스터가 시킨 대로였습니다. 대신 **사진 슬라이드**에서 하나가 걸렸습니다.

## 사진에 붙인 설명이 아무 데도 보이지 않았습니다

`::image 매장 전경 | 지난달 문을 연 신규 매장입니다` 라고 쓰면, 그 설명은 v0.38부터
**대체 텍스트**로 들어갑니다. 그런데 그것뿐이었습니다 — 슬라이드 위에는 나타나지 않았고,
그림 옆의 글자리는 **비어 있었습니다.** 작성자가 쓴 문장이 눈에 보이지 않는 채로 남은 것입니다.

이제 캡션은 **비어 있는 글자리에 캡션으로** 들어갑니다.

- 글머리 기호 없이 한 줄로 — 캡션은 요점이 아닙니다(v0.41에서 리드에 준 것과 같은 대접).
- **요점이 이깁니다.** 이미 그 자리에 할 말이 있으면 캡션은 대체 텍스트로만 남습니다. 캡션이
  요점을 덮어쓰는 일은 없습니다.
- 대체 텍스트는 그대로 유지됩니다.

## 그리고 그 문법이 어디에도 적혀 있지 않았습니다

`| 설명` 형태는 사용 가이드에도, 제품 안 가이드에도 없었습니다. 쓸 수 있는지 모르는 기능은
없는 기능입니다. 두 곳 모두에 적었습니다 — 무엇이 되고(대체 텍스트), 언제 보이는지(자리가
남을 때).

## 확인

- 회귀 테스트 1건: 자리가 남으면 캡션이 **캡션으로**(글머리 없이) 들어가고, 요점이 있으면
  **두 요점이 모두 살아남는다**는 것.
- 4:3 템플릿(9144000×6858000)로 지은 6장 덱: 결함 0 · 권고 0.
- 전수 점검: api 75 · edges 32 · package 0 실패.
