# Ptium v1.38.0

관리자 고도화 — **배포 점검 리포트 한 장**입니다.

## 폐쇄망에서는 "생성이 안 됩니다" 한 문장이 전부입니다

닫힌 현장은 누구에게도 대시보드를 열어 줄 수 없습니다. 버전이 무엇인지, 데이터베이스가
최신인지, 출고값에서 무엇을 바꿨는지, 최근에 무엇이 실패했는지, 디스크가 얼마나 찼는지 —
**이 제품 안에 다 있는데 밖으로 보낼 방법이 없었습니다.**

## 관리자 개요 → [점검 리포트]

## 이 파일이 지키는 세 가지

**하나 — 비밀은 절대 적지 않습니다.** API 키·클라이언트 시크릿은 **"설정됨/설정 안 됨"**
으로만 나옵니다. 아직 설정하지 않은 비밀은 아예 적지 않습니다 — 출고 상태니까요.

**둘 — 바뀐 것만 적습니다.** 마흔 개를 늘어놓으면 누군가 바꾼 두 개가 묻힙니다.
그리고 **띄어쓰기만 다른 값은 바뀐 것이 아닙니다** — `["ptium-admin", "admin"]`과
`["ptium-admin","admin"]`을 다르다고 세던 첫 판이 안 바꾼 설정을 "바꿈"으로 올렸습니다.
이제 **뜻으로 견줍니다.**

**셋 — 읽는 사람의 말로 적습니다.** `unusedImagesOverAMonth`가 아니라
**"한 달 넘게 쓰이지 않은 이미지"** 입니다. 필드 이름을 아는 사람만 읽을 수 있는 문서는
보낼 수 없습니다.

## 검사

- REST 훑기: 여덟 가지 항목을 담는지, 마이그레이션이 0이 아닌지, 파일이 리포트로 읽히는지,
  **개발 시크릿·DSN·API 키가 들어 있지 않은지**, **필드 이름이 그대로 나오지 않는지**.
- 화면 훑기: 개요에 리포트 단추가 있는지. 실제로 눌러 파일을 받아 확인했습니다.
- 비밀 표기·필드 이름 번역·"띄어쓰기만 다른 값"을 단위 테스트로 고정했습니다.
