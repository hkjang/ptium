# Ptium v1.18.7

## README가 제품이 할 줄 아는 것의 절반을 말하지 않았습니다

**주요 기능** 목록에 **가져오기가 없었습니다.** 엑셀·CSV·워드·마크다운은 v0.47부터, PDF는
이번 판부터 읽는데, README는 `.pptx` 만 말하고 있었습니다.

기능 목록은 이 제품을 처음 보는 사람이 **읽는 전부**입니다. 거기 없는 기능은 없는 기능입니다.
1년 가까이 되는 기능을 아무도 못 찾게 두고 있었던 셈입니다.

- **주요 기능**에 가져오기 항목을 넣었습니다 — 무엇을 읽고, 각각이 어떤 장이 되고, 출처가
  붙고, 스캔본은 이유를 알려 준다는 것까지
- 본문의 가져오기 문단도 `.pptx` 만 말하던 것을 **읽는 형식 전부**로 고쳤습니다

## 다시 이렇게 되지 않도록

**읽는 형식과 말하는 형식이 어긋나면 실패하는 검사**를 넣었습니다. `Extensions` 에 형식을
추가하고 문서를 고치지 않으면 그 자리에서 실패합니다.

검사를 만들면서 **검사 자신이 스스로를 속이는 것**도 한 번 잡았습니다. 처음엔 문서에
"pdf" 라는 글자가 있는지만 봤는데, README에는 **PDF로 내보내기**가 이미 적혀 있어서
가져오기에서 PDF를 지워도 통과했습니다. 이제 문서가 형식을 적는 방식 그대로,
`` `.pdf` `` 처럼 코드 표시된 확장자를 찾습니다 — 지우면 실패합니다.
