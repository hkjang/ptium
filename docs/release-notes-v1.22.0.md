# Ptium v1.22.0

버전 이력 · 복원 · 휴지통을 실제로 돌려 봤습니다. **셋 다 정확했습니다** — 되돌린 코드는 글자
하나까지 그대로였고, 의견도 공유 링크도 함께 살아났고, 복원 자체도 되돌릴 수 있게 기록됩니다.

그러다 **관리자 화면이 말하지 않는 숫자** 하나를 봤습니다.

## 이 배포의 덱 4분의 3이 휴지통에 있습니다

```
살아 있는 덱   3,530
휴지통        10,751     ← 어느 화면에도 없던 숫자
```

관리자 개요의 모든 숫자는 **지워지지 않은 덱만** 셉니다. 그래서 지운 덱이 얼마나 쌓였는지는
**아무 데도 나오지 않습니다.** 그리고 **휴지통은 스스로 비워지지 않습니다** — 오늘 지운 초안이
1년 뒤에도 그대로 있습니다.

이제 개요에 함께 보여 줍니다.

> **휴지통 10,751** · 지웠지만 남아 있는 덱 · **자동으로 비워지지 않습니다**

## 지우지는 않았습니다

**자동으로 비우는 기능은 넣지 않았습니다.** 무엇을 언제 영구히 지울지는 운영하는 사람의
결정이고, 되돌릴 수 없는 일이기 때문입니다. 먼저 **보이게** 했습니다.

보관 기간(예: 30일 지나면 영구 삭제)이 필요하다면 설정으로 만들 수 있습니다 — 기본값은
지금처럼 **아무것도 지우지 않음**으로 두고요.

## 함께 확인한 것

- **버전 이력**: 저장할 때마다 체크포인트가 남고, 각 버전이 지금과 무엇이 다른지 슬라이드
  단위로 답합니다
- **복원**: 되돌린 덱의 코드가 **원본과 완전히 동일**(노트 · 출처 · 컴포넌트 포함).
  복원 전 상태도 별도 버전으로 남아 되돌리기의 되돌리기가 됩니다
- **휴지통**: 지우면 목록에서 사라지고 **공유 링크가 닫히며**(404), 복원하면 **링크가 다시
  열리고** 의견도 그대로입니다. 영구 삭제는 휴지통 안에서만 따로 실행됩니다
