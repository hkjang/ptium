# Ptium v0.87.0

편집기를 계속 몰아 봤습니다. 두 가지가 더 나왔습니다.

## 오른쪽 패널이 슬라이드의 절반만 보여 줬습니다

비교 슬라이드에는 글 영역이 넷인데 패널에는 **"본문" 한 칸** 뿐이었습니다. 나머지 세 영역은
패널 어디에도 없었고, v0.86 에서 머리말이 템플릿 자리로 옮겨 간 뒤로는 그 한 칸이 **한 줄짜리
머리말 영역** 을 "본문" 이라는 이름으로 보여 주고 있었습니다.

이제 슬라이드가 가진 **모든 글 영역** 을 나열합니다. 이름은 슬라이드에서 **어디에 있는지** 로
붙입니다.

```
왼쪽 위 영역      현재
오른쪽 위 영역    자동화
왼쪽 가운데 영역   0.8% 오배송, 인력 비용 증가
오른쪽 가운데 영역 0.1% 목표, 인력 30% 절감
                처리 속도 2배 향상 기대
```

컴포넌트나 이미지가 차지한 영역은 글 영역이 아니므로 나오지 않습니다. **글이 지워진 적은
없었습니다** — 본문 상자는 늘 한 슬롯에만 쓰고 나머지는 건드리지 않았습니다 — 다만 **보이지
않는 영역은 아무도 고치지 않습니다.**

## 한쪽 머리말에만 불릿이 붙어 있었습니다

모델이 일정 슬라이드를 이렇게 썼습니다. **어느 줄에도 표시가 없습니다.**

```
설계 및 구축
- 2026년 4분기
- 시스템 설계 완료
운영 및 최적화
- 2027년 2분기
- 전체 시스템 가동
```

첫 맨줄은 슬라이드의 리드가 됩니다 — 맞습니다. 그런데 **둘째 맨줄은 그냥 요점** 이 되어서,
왼쪽 단은 머리말이 있고 오른쪽 단은 **자기 머리말이 제 목록 안에 불릿을 달고** 앉아
있었습니다.

**표시가 없다는 것 자체가 신호입니다.** 파서가 이제 어떤 요점이 `- ` 없이 쓰였는지 기억합니다.
요점들 사이에 있고, 양옆에 요점이 있고, 문장이 아니라 이름으로 읽히고, 슬라이드에서 그럴
수 있는 **유일한 줄** 이면 — 그건 둘째 단의 머리말입니다. `- ` 를 달고 쓴 짧은 요점은 그대로
요점입니다.

## 설치

오프라인 설치 방법은 [docs/offline-deployment.md](offline-deployment.md) 를 보세요. 이미지에
Postgres 와 nginx 는 들어 있지 않습니다 — 배포할 때 `DATABASE_URL` 로 DSN 을 지정합니다.
