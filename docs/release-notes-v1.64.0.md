# 1.64.0 — 설명 없는 사진을 묻습니다

이 제품이 그리는 것은 모두 자기가 무엇인지 말합니다. 표도, 차트도, 컴포넌트도
대체 텍스트를 함께 씁니다. 딱 하나, **사람이 직접 써야 하는 것** 만 아무도
묻지 않았습니다.

사진에 설명을 붙이면 파워포인트 파일에 대체 텍스트로 들어갑니다. 안 붙이면
아무것도 들어가지 않습니다. 화면을 읽어 주는 프로그램은 "Picture Placeholder
2" 라고 읽고 넘어갑니다. 슬라이드를 볼 수 있는 사람에게는 전부 전해지고, 볼 수
없는 사람에게는 아무것도 전해지지 않는 내용이 덱에 남습니다.

- 설명 없는 사진을 **권고**로 알려 줍니다. 슬라이드에 놓인 사진도, 편집 창에서
  자유롭게 올려놓은 그림도 같습니다.
- 권고입니다. 무엇을 쓸지는 작성자만 압니다. 제품이 할 수 있는 일은 묻는
  것이고, 그것만 해도 지금까지의 침묵보다는 낫습니다.
- 점수의 **접근성** 축에서 값을 치릅니다. 이 축은 지금까지 대비만 세고
  있었습니다. 그려지지 않은 내용과 같은 무게(10)입니다 — 그 독자에게는 같은
  일이기 때문입니다.
- 설명을 붙인 사진은 예전처럼 조용합니다.

## 확인

- 같은 사진을 설명 없이 한 장, 설명을 붙여 한 장 넣고, 설명 없는 쪽만
  보고되는 것을 확인했습니다.
- 내보낸 파일을 열어 설명이 실제로 대체 텍스트(`descr`)로 들어가 있는 것을
  확인했습니다.
- 접근성 점수가 100 에서 96 으로 내려가는 것을 확인했습니다.
- 고침을 되돌려 다시 아무 말도 하지 않는 것을 확인했습니다.
