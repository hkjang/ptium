# Ptium v1.10.2

v1.10.0 에서 적어 둔 "아직 없는 것들" 중 두 번째입니다.

## 발표에서 건너뛸 슬라이드

부록, 산출 근거, 백업 수치 — **덱에는 있어야 하지만 발표에서는 넘어가는** 장이 있습니다.
지금까지는 발표 전에 지웠다가 나중에 다시 넣는 수밖에 없었습니다.

이제 슬라이드를 고르고 **눈 모양 버튼**(복제·삭제 옆)을 누르면 됩니다.

- **발표할 때 넘어갑니다.** 방향키로 넘겨도, 슬라이드 목록(G)에도 나오지 않습니다
- **덱에는 그대로 남습니다.** 왼쪽 목록에 흐리게, "건너뜀" 표시와 함께 보입니다
- **내려받은 pptx 에도 그대로 들어갑니다.** PowerPoint 가 자기 "슬라이드 숨기기" 에 쓰는
  것과 같은 표시를 달아 두기 때문에, 같은 파일을 PowerPoint 로 열어 발표해도 같은 장을
  건너뜁니다
- 코드 보기에서는 `!skip` (또는 `!건너뛰기`) 한 줄입니다

건너뛴 장에서 F5 를 누르면 **그 다음 발표할 장부터** 시작합니다. 전부 건너뛴 덱은 그냥 전부
발표합니다 — 아무것도 없는 발표는 F5 를 누른 사람이 원한 것이 아니니까요.

### 표시를 어디에 둘지가 이 작업의 전부였습니다

슬라이드에 컬럼을 하나 더 만들면 읽기·저장·복제·되돌리기·내보내기·스냅샷·복원 **여덟 군데**
를 고쳐야 하고, 한 군데만 빠뜨리면 표시가 조용히 사라집니다. 그래서 이미 **통째로 옮겨
다니는** 슬라이드 내용(jsonb)에 실었습니다. 덕분에 복제해도, 되돌려도, 체크포인트에서
복원해도 따라옵니다.

원본 코드 → 저장된 슬라이드 → pptx 파일 → 다시 쓴 원본 코드까지 **네 손을 다 거쳐도 남는지**
를 스윕에 넣었습니다. 브라우저에서도 눌러 보고, 발표해 보고, 새로 고쳐 확인했습니다.

## 그밖에

- `VERSION` 파일이 1.4.0 에 멈춰 있었습니다. 오프라인 번들과 배포 스크립트는 인자를 주지
  않으면 이 파일을 버전으로 씁니다 — 오늘 코드로 1.4.0 이라는 이름의 이미지가 만들어질 수
  있었습니다. 릴리즈 버전과 맞췄습니다.
