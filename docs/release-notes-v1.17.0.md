# Ptium v1.17.0

## 요점을 한 줄씩 내놓으며 발표합니다

목록을 한꺼번에 띄우면 방 안의 사람들은 **발표자보다 먼저 읽습니다.** 말하는 사람은
세 번째 줄을 설명하는데 청중은 이미 다 읽고 딴생각을 하고 있습니다.

원문에 `!build` (또는 `!하나씩`) 한 줄을 적으면, 그 슬라이드는 발표할 때 **요점을 하나씩**
내놓습니다.

```
# 이행 순서
@content
!build
- 준비: 범위와 조직을 확정합니다
- 이행: 단계별로 적용합니다
- 안정화: 운영으로 넘깁니다
```

- **→ 키가 다음 줄을 불러옵니다.** 줄이 다 나오면 그때 다음 장으로 넘어갑니다
- **← 로 되돌아오면 마지막 줄이 나와 있는 상태**입니다. 왔던 자리로 돌아옵니다
- 아직 말하지 않은 줄은 **자리는 잡되 그려지지 않습니다** — 다음 줄이 나타나도 이미
  나와 있던 줄이 **움직이지 않습니다**
- 제목과 리드는 처음부터 나와 있습니다. 그것은 요점이 아닙니다
- `!build` 가 없는 슬라이드는 예전과 똑같이 한 번에 넘어갑니다

**내보낸 파일·유인물·공유 링크에는 전부 나옵니다.** 종이에는 클릭이 없습니다.

### PowerPoint 애니메이션은 아직입니다

내보낸 .pptx 안에서도 한 줄씩 나타나게 하려면 `p:timing` 애니메이션을 써야 하는데,
잘못 쓰면 PowerPoint 가 "복구할까요?" 를 띄웁니다. **이 개발 환경에는 PowerPoint 도
LibreOffice 도 없어 열리는지 확인할 방법이 없어서** 넣지 않았습니다. 확인해 주실 수 있으면
그때 넣겠습니다.

## 검사

- 그리기: 3줄짜리를 1·2·3 단계로 그리면 감춰지는 줄이 2·1·0 이고, **모든 줄의 y 좌표가
  전부 같아야** 합니다(움직이지 않는다는 뜻입니다)
- 제목은 절대 감추지 않습니다
- 브라우저: 발표를 시작해 → 를 누르면 줄이 늘고 장은 그대로, 다 나온 뒤에야 다음 장
  (deep 스윕)
