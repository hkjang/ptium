# Ptium v0.99.0

어제 일본어 덱의 **두부(□)** 는 미리보기 문제였습니다 — 보는 사람의 글꼴 사정. 그럼 **밖으로
나가는 파일** 에도 같은 결함이 있는지 봤습니다. 더 나쁜 게 있었고, **이건 우리 잘못** 입니다.

## 모든 줄에서 한글을 라틴 글꼴로 지정하고 있었습니다

Ptium 이 쓰는 모든 텍스트 런(run)은 글꼴 이름을 **두 번** 적고 있었습니다.

```xml
<a:latin typeface="Aptos"/><a:ea typeface="Aptos"/>
                            ↑ 동아시아 문자도 Aptos 로 지정
```

`Aptos` 에는 **한글이 한 글자도 없습니다.** 그런데도 한국어 덱을 내보내면 **줄마다** "한글은
Aptos 로 그려라" 라고 적혀 나갔고, 이것이 **템플릿이 지정한 동아시아 글꼴을 덮어썼습니다.**

그다음에 회의실에서 무엇이 보이는지는 **PowerPoint 가 어떻게 수습하느냐** 에 달립니다.

## 템플릿의 동아시아 글꼴이 그 문자들을 위한 것입니다

런은 **그 요소를 안 쓰면** 템플릿 것을 물려받습니다. 여덟 군데에서 쓰고 있었고, 이제 한 곳도
쓰지 않습니다.

내보낸 파일을 다시 열어 확인했습니다.

```
동아시아 글꼴로 지정된 이름: +mj-ea, +mn-ea, 맑은 고딕
```

**라틴 글꼴이 동아시아 문자를 차지한 곳은 한 군데도 없습니다.**

골든 파일도 다시 기록했습니다 — 한글을 차지하고 있던 라틴 글꼴 지정 **17줄이 사라졌습니다.**

## 설치

오프라인 설치 방법은 [docs/offline-deployment.md](offline-deployment.md) 를 보세요. 이미지에
Postgres 와 nginx 는 들어 있지 않습니다 — 배포할 때 `DATABASE_URL` 로 DSN 을 지정합니다.
