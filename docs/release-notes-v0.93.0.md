# Ptium v0.93.0

지난 판에서 **생성은 지키는데 그 옆 패스는 안 지키는 필터** 를 찾았습니다. 그래서 모델의 답이
슬라이드에 닿는 **모든 경로** 를 걸어 봤습니다. 새는 곳은 **JSON 경로** 였습니다.

## 지원하는 경로 하나에 검사가 전혀 없었습니다

예전 JSON 스키마로 답하는 모델에 고정된 배포는 `compose` 에서 **바로 돌아갔습니다.** 답과
저자의 화면 사이에 있어야 할 것이 전부 건너뛰어졌습니다.

| 건너뛴 것 | 무엇을 놓쳤나 |
|---|---|
| 수리 패스 | 템플릿에 맞춰 재고 안 맞는 장을 다시 쓰는 일 |
| 지어낸 숫자 알림 | `가용성 99.99%` 같은 것을 아무도 말해 주지 않음 |
| 인용 안 된 출처 알림 | 브리프가 준 출처가 통째로 묻힘 |
| 지어낸 위치 표기 알림 | 진짜 출처에 가짜 페이지가 붙어도 조용함 |

이제 **두 형태가 같은 함수로 끝납니다.** 슬라이드 언어 경로는 그대로이고, JSON 경로가 빠져
있던 것을 전부 받습니다.

## 걸어 보다가: 갈 곳 없는 글이 말없이 사라졌습니다

본문 영역이 없는 레이아웃에 본문이 쓰이면, 컴포넌트를 놓을 자리가 없으면 — 슬라이드 언어
컴파일러는 **그렇다고 말합니다.** JSON 경로는 **조용히 버렸습니다.**

이제 말합니다. 어느 줄을 놓지 못했는지 이름을 대서.

```
slide 2: layout "마무리" has no free body region, so "예산 승인이 필요합니다" was dropped
```

## 설치

오프라인 설치 방법은 [docs/offline-deployment.md](offline-deployment.md) 를 보세요. 이미지에
Postgres 와 nginx 는 들어 있지 않습니다 — 배포할 때 `DATABASE_URL` 로 DSN 을 지정합니다.
