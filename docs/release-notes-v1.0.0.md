# Ptium v1.0.0

브리프 한 문단을 넣으면, **가지고 있는 PowerPoint 템플릿 그대로** 발표할 수 있는 덱이
나옵니다. 인터넷 없이, 사내에서.

이번 판은 1.0 입니다. 새 기능을 넣는 대신 **지금까지 만든 것이 실제로 작동하는지** 를
확인했습니다.

## 확인한 것

| | 결과 |
|---|---|
| 한국어 덱 (실제 모델) | **99점** · 지적 1건(요점 7개) |
| 영어 덱 (실제 모델) | **99점** · 지적 1건 |
| 일본어 덱 (실제 모델) | **98점** |
| 다른 도구의 파일 가져오기 → 내보내기 → 다시 가져오기 | **잃은 것 없음** |
| 미리보기와 내보낸 파일 대조 | **모든 줄 일치** |
| 스윕 (api · edges · flows · package) | **0 failures** |
| Go · 웹 테스트 | **전부 통과** |

마지막으로 고친 것: 브리프가 `세 개 시스템` 이라고 쓴 것을 덱이 `3개` 라고 받아 적었더니
"브리프에 없는 숫자" 라고 지적했습니다. **말로 쓴 수도 수입니다** — 이제 세 언어 모두에서
셉니다(다만 세는 단위가 따라와야 합니다. `한` 하나만으로는 `한국` 의 첫 글자일 뿐입니다).

## Ptium 이 하는 일

- **브리프 → 덱**: 구성을 먼저 설계하고, 슬라이드 언어로 쓰고, 템플릿에 묶습니다
- **템플릿이 결정합니다**: 레이아웃·글꼴·색은 회사 템플릿의 것이고, 덱은 그 안에서 씁니다
- **재고 고칩니다**: 넘침·겹침·대비·밀도·중복·출처를 재고, 안 맞는 장은 모델에게 다시
  씁니다. 나아지지 않으면 원래대로 둡니다
- **지어낸 것을 걷어냅니다**: 브리프에 없는 출처는 지우고, 없는 숫자는 알리고, 없는 위치
  표기는 떼어 냅니다
- **저자의 글은 지우지 않습니다**: 다시 쓰기가 머리말이나 영역을 잃으면 거절합니다
- **파일이 진짜입니다**: 진짜 표, 진짜 차트(편집 가능한 데이터 포함), 진짜 발표자 노트
- **오프라인**: 이미지 tar.gz 하나. Postgres DSN 만 주면 됩니다

## Ptium 이 하지 않는 일

- **글꼴을 함께 배포하지 않습니다.** 미리보기는 보는 사람 기기의 글꼴로 그려집니다 —
  한·중·일 글꼴이 없는 기기에서는 네모로 보일 수 있습니다
- **모델을 대신 판단해 주지 않습니다.** 브리프에 없는 숫자는 **알릴 뿐** 지우지 않습니다.
  문장 안에 있는 숫자를 빼면 문장이 다른 말을 하기 때문입니다
- **라이브러리 슬라이드를 항상 쓰지는 못합니다.** 덱이 그 슬라이드를 알아볼 수 있게 이름
  붙여야 하고, 제목은 결국 모델이 쓰는 문장입니다

## 설치

오프라인 설치 방법은 [docs/offline-deployment.md](offline-deployment.md) 를 보세요. 이미지에
Postgres 와 nginx 는 들어 있지 않습니다 — 배포할 때 `DATABASE_URL` 로 DSN 을 지정합니다.
