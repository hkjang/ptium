# Ptium v1.31.1

어제 고친 생성기로 여러 브리프를 돌려 읽어 봤습니다. 지시문은 더 이상 제목에 남지
않았고, 제목과 본문도 맞았습니다. 대신 **다른 것**이 보였습니다.

## 같은 장이 두 번, 띄어쓰기 하나 차이로

```
협력사 정산 프로세스 개선안 | 목차 | 기대 효과 | 현재 문제 | 개선 방향 | 기대효과 | 이행 일정 | 다음 단계
                                 ↑                                   ↑
                                 덱 주제의 몫                          브리프가 적은 절
```

브리프가 **기대효과**를 절로 적었는데, 덱 주제를 다루는 장도 **"기대 효과"** 라는 이름을
받았습니다. 사람이 보기에 **같은 절이 두 번**입니다.

그리고 1.29.0에서 넣은 **"앞 장과 같은 제목"** 측정은 이것을 잡지 못했습니다 — 글자
그대로 비교해서 띄어쓰기 하나가 다르면 다른 제목으로 봤습니다.

## 두 곳 다 고쳤습니다

**측정** — 이제 **띄어쓰기를 빼고** 견줍니다. 우리말에서 "기대 효과"와 "기대효과"는
한 절입니다. 어느 쪽이 앞에 오든 잡습니다.

**생성** — 덱 주제의 몫에 이름을 붙일 때, **브리프가 이미 쓴 절 이름은 피합니다.**
그 이름이 비어 있으면 그대로 쓰고, 이미 쓰였으면 주제의 다른 면(현황 · 이행 순서 ·
비용과 효과 · 선택지 비교 · 리스크와 대응 · 기대 효과) 중 비어 있는 이름을 씁니다.

```
협력사 정산 프로세스 개선안 | 목차 | 현황 | 현재 문제 | 개선 방향 | 기대효과 | 이행 일정 | 다음 단계
```

## 검사

- 측정: "기대 효과"와 "기대효과"를 한 제목으로 읽는지 고정했습니다(순서를 바꿔도).
- 생성: 브리프가 쓴 이름은 피하고, 비어 있으면 그 프레임의 이름을 그대로 쓰며,
  모르는 언어에서는 남의 언어 낱말을 가져오지 않는지 고정했습니다.
- 브리프 4개(한국어 3 · 영어 1)로 다시 읽어 확인했습니다 — 지시문 잔재 0건.
