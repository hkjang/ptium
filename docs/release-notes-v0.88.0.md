# Ptium v0.88.0

**모델이 처음 보는 브리프** 로 덱을 만들어 봤습니다 — 신입 개발자 온보딩 개편안, 지난 덱과는
전혀 다른 주제입니다. 최근 여섯 판의 수정이 그 덱 한 벌에만 맞춘 것인지 확인해야 했습니다.

**여섯 판이 다 버텼습니다.** 템플릿의 머리말 자리, 양쪽 단의 같은 머리말, 표의 제 열 제목,
브리프에 없는 숫자 — 아무도 맞춰 주지 않은 글에서 전부 제대로 나왔습니다.

틀린 것은 두 가지였고, **둘 다 같은 자리의 같은 실수** 였습니다.

## 한국어 머리말을 단어 수로 재고 있었습니다

단 이름의 조건이 **"세 단어 이하"** 였습니다. 그래서

```
첫 달 업무 파악 | 적응 저해 원인          ← 각 네 단어. 막대 든 불릿 한 줄로 남음
2주 집중 교육을 통한 업무 숙달 가속화       ← 일곱 단어. 옆 단은 머리말, 이쪽은 불릿
```

같은 모양의 머리말인데 한쪽만 머리말이 되는 슬라이드가 나왔습니다. 줄을 **탈락시키는 것은
길이와 문장으로 읽히는지** 이지 띄어쓰기 개수가 아닙니다. 이제 그것만 봅니다.

## 자기 산수를 인용하라고 요구하고 있었습니다

브리프: **34명 중 6명** 이 퇴사. 덱: **이탈률 17.6%**.

그런데 "브리프에 없는 숫자" 라고 알리고, 출처가 없다고 지적까지 했습니다. 34와 6을 말한
브리프는 **이미 17.6% 를 말한 것** 입니다.

브리프의 두 숫자를 나눠 나오는 백분율은 브리프의 것으로 봅니다. 다만

- 나누는 쪽(분모)은 **10 이상의 실제 개수** 여야 합니다 — 1을 2로 나눈 50% 는 파생이 아니라
  아무 브리프에나 걸리는 우연입니다
- 분자는 분모보다 **작아야** 합니다 — 같은 수로 나누면 100% 가 되어 그 언저리의 아무 숫자나
  통과시킵니다

지어낸 숫자(`50%`, `99.99%`)는 **여전히 잡힙니다.**

## 결과

이 덱은 이제 **99점**, 남은 지적은 첫 장의 마지막 줄이 20%만 차지한다는 정직한 한 건뿐입니다.

## 설치

오프라인 설치 방법은 [docs/offline-deployment.md](offline-deployment.md) 를 보세요. 이미지에
Postgres 와 nginx 는 들어 있지 않습니다 — 배포할 때 `DATABASE_URL` 로 DSN 을 지정합니다.
