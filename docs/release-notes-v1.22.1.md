## 사람이 친 글자가 와일드카드가 되고 있었습니다

검색은 입력을 `%…%` 로 감싸 `LIKE` 에 넘깁니다. 그런데 **`%` 와 `_` 는 LIKE의 문자**입니다 —
`%` 는 "무엇이든", `_` 는 "아무 글자 하나". 그래서

- **`%` 를 검색하면 라이브러리 전체**가 나옵니다
- **`50%`** 는 `50` 뒤에 무엇이든 오는 것을 다 찾습니다 — `500만원`, `50억`, `50개`
- **`metadata_demo`** 는 `metadataXdemo` 와도 맞습니다. 밑줄은 파일 이름에 흔합니다 —
  `AI_Coding_ROI_and_Debt_Strategy`, `metadata_demo-jask-db`

**와일드카드는 질의의 것이지 읽는 사람의 것이 아닙니다.** 사람이 친 `%` · `_` · `\` 는
그대로 그 글자로 찾습니다.

```
q=50%            →  1개  ("달성률 50% 보고")
q=metadata_demo  →  1개  ("metadata_demo 정리")
q=%              →  40개 (제목에 % 가 실제로 있는 덱)
```

덱만이 아니라 **템플릿 · 이미지 · 저장 슬라이드 · 사용자 · 감사 기록** 검색이 모두 같은
방식이었고, 전부 같은 자리에서 고쳤습니다.
