# Ptium v1.31.3

어제 고친 것을 내보낸 PDF로 다시 읽다가, **어제 만든 자리**를 찾았습니다.

## 이름만 바꾸고 몸은 그대로였습니다

어제, 덱 주제가 곧 제목이면 각 장을 **그 장이 맡은 면**으로 부르게 했습니다. 그런데
그 이름이 브리프가 적은 절 이름과 겹치면 **다른 면의 이름**을 가져다 붙였습니다.

```
[3] 현황     무엇이 어떻게 달라지는지 지표로 말합니다.   ← 제목은 현황, 몸은 기대효과
[6] 기대효과  투입과 회수를 같은 기준으로 놓고 봅니다.    ← 제목은 기대효과, 몸은 비용
```

**제목과 몸이 어긋나는 것을 없애려던 판이 뒷문으로 그것을 다시 들였습니다.**

## 이름이 아니라 각도를 바꿉니다

- 덱 주제의 몫은 이제 **다른 각도**를 잡고, **그 각도의 이름**으로 불립니다.
- 그리고 **브리프가 적은 절이 먼저입니다.** 주제의 몫은 절들이 이름으로 요청한 각도를
  피해서 남은 것을 가져갑니다.
- 말이 각도를 정하지 않은 절(예: "필요 인원")도 마찬가지로 **다른 절이 요청한 각도는
  비켜 갑니다.**

측정한 덱 4개 중 3개에서 **제목과 몸이 어긋나는 장이 0**이 되었습니다.

```
[3] 선택지 비교   선택지를 같은 축에서 견줍니다      ← 주제의 몫이 남은 각도를 잡음
[4] 현재 문제    지금 어디까지 와 있는지 정리합니다
[5] 비용        투입과 회수를 같은 기준으로 놓고 봅니다
[6] 일정        순서와 각 단계의 완료 조건을 나눠 적었습니다
[7] 리스크       가장 큰 위험부터 다룹니다
```

## 남은 한 가지 (구조입니다)

네 번째 덱에서 한 장이 남습니다. 브리프가 **"개선안 · 개선 방향 · 기대효과"** 를 적었고,
이 셋은 모두 *성과/개선* 계열이라 **같은 각도를 원합니다.** 각도마다 본문이 하나뿐이고
"한 덱에서 두 장이 같은 문장으로 시작하지 않는다"는 규칙이 있으니, 셋 중 하나만 그
각도를 쓸 수 있습니다.

**각도마다 두 번째 본문**을 쓰면 풀립니다. 그건 제품의 목소리를 새로 쓰는 일이라
그대로 남겨 둡니다.

## 확인한 것 (문제 없었습니다)

- 내보낸 PDF를 **이 제품의 PDF 판독기로 다시 읽어** 7쪽 모두 한국어 글자가 나옵니다.
- 12장·16장을 요청한 단일 주제 브리프는 9장을 쓰고 **왜 그런지 말합니다** —
  "12장을 요청하셨고 9장을 썼습니다… 주제를 더 적어 주시면 그만큼 늘어납니다."
