# 1.62.0 — 표 안의 링크는 인쇄해도 링크입니다

같은 덱, 같은 주소, 파일마다 다른 답이었습니다.

- `.pptx` 로 내보내면 표의 칸에 쓴 링크는 눌러서 따라갈 수 있었습니다(1.61.0).
- PDF 로 인쇄하면 그 자리에는 아무것도 없었습니다. 글머리 줄의 링크는
  인쇄해도 눌리는데, 표의 칸은 눌리지 않았습니다.
- 미리보기에서는 그냥 보통 글자였습니다. 링크인지 아닌지 보고 알 방법이
  없었습니다.

컴포넌트가 그리는 글자를 한 덩어리로 그리고 있었기 때문입니다. 이제
슬라이드의 다른 줄과 같게, 이루어진 조각대로 그립니다.

- **미리보기와 발표 화면** — 표의 칸에 쓴 링크는 템플릿의 링크 색으로,
  밑줄과 함께 그려집니다. 보면 링크인 줄 압니다.
- **인쇄한 PDF** — 그 자리가 눌립니다. 같은 덱의 글머리 줄 링크와 똑같이
  동작합니다.
- **내보낸 파일** — 1.61.0 부터 그대로입니다.
- 칸이 좁아 글자를 줄여야 했다면 그 칸은 글자만 남습니다. 반쪽짜리 링크는
  링크가 아닙니다.

표가 아닌 컴포넌트(카드, KPI, 단계 등)의 글자는 아직 표시 없이 그려집니다.
그리는 길은 이제 열려 있으니, 각 컴포넌트가 글자를 다듬는 자리에서 표시를
남기기만 하면 같은 규칙으로 그려집니다.

## 확인

- 제품 바깥의 판독기(`pypdf`)로 인쇄한 PDF 를 열어, 표의 칸에 쓴 주소가
  실제 링크 주석으로 들어 있는 것을 확인했습니다.
- 고침을 되돌려 같은 자리에서 링크가 사라지는 것을 확인했습니다.
- 미리보기 SVG 에 `<a href>` 와 밑줄이 들어가고, 대괄호와 주소는 어디에도
  그려지지 않는 것을 확인했습니다.
