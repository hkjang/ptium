# Ptium v0.29.0

## 이미 있는 자료를 가져옵니다

Ptium의 전제는 **회사가 가진 템플릿이 곧 디자인**이라는 것입니다. 그 전제의 나머지 절반은
**그 템플릿으로 이미 쓴 덱들**입니다 — 지난 분기 보고서, 잘 먹힌 제안서, 늘 복사해 쓰는 회사
소개. 지금까지 그것을 Ptium으로 가져오는 방법은 **다시 타이핑하는 것**뿐이었습니다.

**프레젠테이션 → 기존 자료 가져오기**에서 `.pptx`를 올리면 Ptium 덱이 됩니다.

넘어오는 것 — **논지**:

- 모든 제목, 모든 요점을 **쓰인 들여쓰기 깊이 그대로**
- **발표자 노트**
- **슬라이드의 성격**(표지 · 간지 · 2단 · 그림 등)
- **표** — 표는 격자에 담긴 글이고 Ptium은 바로 그것으로 표를 그립니다. 그래서 옛 디자인의
  사진이 아니라 **새 덱의 디자인으로 다시 그려진 표**가 들어옵니다.

넘어오지 않는 것 — 그리고 **말해 줍니다**:

- **그림과 차트.** 4:3에 맞춰 놓인 사진을 16:9 디자인에 옮겨 놓고 괜찮기를 바랄 수는 없습니다.
  "그림 3개는 가져오지 않았습니다"라고 말하는 편이 정직하고, 조용히 버리는 것은 그렇지
  않습니다. 몇 개였는지 알려 주므로 이미지 탭에서 다시 넣거나 숫자를 `::bars`로 적으면 됩니다.

가져온 다음은 **보통 덱**입니다: 템플릿을 갈아입히고, 글로 고치고, AI에게 한 장씩 다시 쓰게
하고, 한 장을 슬라이드 라이브러리에 저장할 수 있습니다.

실측(6장짜리 회사 덱, Office 기본 템플릿 → Ptium Slate Orbit): 6장, 제목·들여쓴 요점·노트·
표 모두 이동, 표는 새 디자인으로 재작성, **결함 0**, 그림 1개를 가져오지 못했다고 보고.

## API

```
POST /api/v1/presentations/import      (multipart: file, templateId?, name?, language?)
→ { presentation, slides, warnings }
```
