# 1.68.0 — 공유 링크를 열고 닫은 것을 남깁니다

공유 링크는 계정도 로그인도 없이 덱을 넘겨줍니다. 링크를 가진 사람은 누구나
봅니다. 이 제품에서 가장 멀리 나가는 동작입니다.

**그 동작이 감사 기록에 남지 않았습니다.**

무엇이 남고 있었는지 견주어 보면 분명합니다.

| 남던 것 | 안 남던 것 |
| --- | --- |
| API 키 발급 · 폐기 · 권한 변경 | **공유 링크 열기** |
| 덱 만들기 · 소스 수정 · 휴지통 | **주인이 자기 링크 닫기** |
| 설정 변경 · 이미지 올리기·지우기 | |
| 관리자가 남의 링크를 닫은 것 | |

관리자가 볼 수 있는 것은 **지금 열려 있는 링크**와, **관리자가 직접 닫은 것**
뿐이었습니다. 누가 언제 링크를 열었는지, 주인이 언제 거두었는지는 어디에도
없었습니다. 링크가 닫히고 나면 그 링크가 있었다는 사실 자체가 사라집니다.

이제 둘 다 남깁니다.

- `share.create` — 어느 덱인지, 어떤 이름을 붙였는지, 언제까지인지
- `share.revoke` — 주인이 자기 링크를 닫은 것

**토큰은 남기지 않습니다.** 나중에 알아야 할 것은 "이 덱에 링크가 열렸다" 이지
"그 링크를 여는 열쇠" 가 아닙니다. 기록을 읽을 수 있는 사람이 덱을 열 수 있게
되면 기록이 구멍이 됩니다.

## 확인

- 링크를 열고 닫은 뒤 감사 기록에 두 줄이 그 링크의 id 로 남는 것을
  확인했습니다.
- 토큰이 기록 어디에도 없는 것을 확인했습니다.
- 고침을 되돌려 같은 동작에서 `share.*` 기록이 **0건** 늘어나는 것을
  확인했습니다.
