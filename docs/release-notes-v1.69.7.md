# Ptium 1.69.7

## 지난 판이 창 안의 첫 글자를 삼켰습니다

1.69.6에서 창이 열릴 때 초점을 창 자체로 옮겼습니다. 낭독기가 제목부터 읽게 하려는
것이었는데, 만든 쪽이 "이 칸에 바로 쓰게 해달라"고 지정해 둔 창까지 함께 빼앗았습니다.

리액트는 그 지정을 커밋 단계에서 처리하고, 우리 코드는 그 뒤에 돕니다. 그래서
새 API 키 창은 이름 칸에 초점이 갔다가 곧바로 빼앗겼고, **거기서 친 글자는 전부
어디에도 들어가지 않았습니다.** 탭을 한 번 눌러야 비로소 쓸 수 있었습니다.

같은 창에서 하나 더 있었습니다. 창을 닫을 때 초점을 돌려줄 자리를 창이 열리는
순간에 읽었는데, 그때는 이미 이름 칸이 초점을 가져간 뒤였습니다. 그 칸은 창과 함께
사라지므로, 닫으면 초점은 본문(body)으로 떨어졌습니다.

이제,

- 창 안에 초점을 요청한 칸이 있으면 그 칸을 그대로 둡니다. 없을 때만 창이 받습니다.
- 돌아갈 자리는 창이 열릴 때 읽지 않고, 창 바깥에서 초점이 머문 마지막 자리를
  페이지 전체에서 지켜봅니다. 열려 있는 동안에만 그려지는 창(템플릿 자세히 보기
  같은)은 자기를 연 클릭을 아예 보지 못하기 때문입니다.

다섯 개 창과 서랍에서 초점 진입, 탭 40번 가두기, Escape, 초점 복귀, 그리고 타자가
칸에 들어가는 것까지 모두 확인했습니다.

## 지키는 장치

1.69.6의 검사는 이 창을 아예 열어보지 않아 두 결함을 모두 놓쳤습니다. 이제
`scripts/e2e/ui.py`가 새 API 키 창도 열고, 연 직후 친 글자가 이름 칸에 들어가는지
봅니다. 1.69.6 판으로 되돌려 돌리니 두 줄 모두 실패로 나왔습니다.
