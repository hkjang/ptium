# Ptium v1.34.0

관리자 고도화 두 번째 — **공유 링크 감독**입니다.

## 밖으로 무엇이 열려 있는지 아무도 몰랐습니다

공유 링크는 이 제품에서 **계정 없는 사람에게 닿는 유일한 것**입니다. 그런데 링크는
**덱 주인만** 볼 수 있었습니다. 운영자가 "우리 것 중 무엇이 밖에서 읽히나"를 물으면
답할 방법이 없었고, **떠난 사람이 열어 둔 링크를 닫을 방법**도 없었습니다.

## 관리자 · 공유 링크

```
326건                    이 화면에서 기한 없이 열린 링크 100    이 화면 링크가 열린 횟수 295
326건 가운데 최근 100건을 보고 있습니다. 검색으로 좁혀 주세요.

[직접 회수할 때까지] 마지막 11분 전 · 의견 · 공유 점검 776449 · Ptium Developer · 3회  [회수]
```

- **열려 있음 · 기한 지남 · 회수됨**으로 나눠 봅니다.
- 덱 제목 · 만든 사람 · 만든 날 · 열린 횟수 · 마지막 열람이 한 줄에 있습니다.
- 만든 사람은 **주소가 없으면 이름으로** 말합니다(프록시로 로그인한 계정처럼 주소가
  없는 경우가 있습니다).
- **기한 없는 링크**를 눈에 띄게 표시합니다 — 스스로 멈추지 않는 링크니까요.
- **회수**는 누가 만들었든 운영자가 누를 수 있고, **감사 기록에 남습니다**(누구 덱의
  링크를, 누가, 몇 번 열렸을 때 닫았는지).

숫자는 **화면에 보이는 수가 아니라 실제 건수**를 말하고, 보이는 것이 일부면 그렇다고
적습니다.

## API

```
GET  /api/v1/admin/shares?state=open|expired|revoked&search=…
POST /api/v1/admin/shares/{id}/close        → {"closed": true|false}
```

`closed`는 **이번 호출이 닫았는지**를 말합니다. 조금 전에 이미 회수된 링크는 `false`로
답합니다 — 하지 않은 일을 했다고 말하지 않습니다.

## 검사

- 데이터베이스: 기한 없는 링크는 `open`, 지난 링크는 `expired`, 회수하면 `revoked`이며
  **열린 목록에서 사라지는지**, 덱 제목과 주인이 함께 나오는지, 두 번째 회수는
  `false`인지.
- REST 훑기: 방금 만든 링크가 배포 목록에 있는지, 주인·덱을 말하는지, 회수가 한 번만
  참인지, 잘못된 state는 422인지. `closed`를 항상 참으로 바꾸면 그 자리에서 잡힙니다.
- 화면 훑기: 화면이 열리고 건수를 말하며 열린 링크에 회수 단추가 있는지.
