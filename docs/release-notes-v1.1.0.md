# Ptium v1.1.0

**덱은 보여 주려고 만듭니다.** 그런데 지금까지 계정이 없는 사람에게 보여 주는 방법은 **파일로
내보내 보내는 것** 뿐이었습니다. 파일로 나간 덱은 더 이상 Ptium 의 그 덱이 아니라 **네 사람
받은편지함의 사본 네 개** 가 되고, 그중 어느 것도 나중에 고친 내용을 받지 못합니다.

## 링크 하나로 엽니다

공유 링크는 덱 하나를 **읽기 전용** 으로 엽니다. 편집기가 그리는 그대로의 슬라이드와 덱 이름,
그게 전부입니다. **소스도, 템플릿도, 작업 공간도 아닙니다.**

- 링크에 **이름표** 를 달 수 있습니다 (`임원 검토`)
- **며칠 뒤 닫히게** 하거나, 직접 닫을 때까지 열어 둘 수 있습니다
- **몇 번 열렸는지** 보입니다
- 언제든 **회수** 할 수 있습니다

## 토큰은 다시 만들어 낼 수 없습니다

토큰은 **다이제스트로만 저장** 되고, 링크는 **그것을 만든 응답에 한 번** 나옵니다.
**데이터베이스 사본은 열린 덱들의 묶음이 아닙니다.**

회수했거나 기간이 지난 링크는 `404` 가 아니라 **`410`** 으로 답합니다. 링크를 쥔 사람은 그
링크가 **진짜였고 지금은 닫혔다** 는 것을 알아야 새 링크를 요청하지, 오타를 의심하지
않습니다.

## 보는 화면

작업 공간 장식이 없습니다. **누가 보고 있는지 서버에 묻지도 않습니다** — 고치기 전에는
낯선 사람의 브라우저가 `/me` 를 부르고 401 을 받고 있었습니다. 방향키로 넘기고, 아래 레일로
장을 고릅니다.

## 점검

api 스윕이 **낯선 사람의 입장에서** 전 과정을 걷습니다 — 링크 열기, 슬라이드 그리기,
자격 증명 없이 덱과 소스를 읽으려다 막히기, 회수, 닫힌 것 확인. **92 checks, 0 failures.**

## 설치

오프라인 설치 방법은 [docs/offline-deployment.md](offline-deployment.md) 를 보세요. 이미지에
Postgres 와 nginx 는 들어 있지 않습니다 — 배포할 때 `DATABASE_URL` 로 DSN 을 지정합니다.
