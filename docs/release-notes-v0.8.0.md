# Ptium v0.8.0

이미지를 화면에서 다룹니다. 지금까지는 API로만 올릴 수 있었습니다.

## 이미지 패널

편집기 오른쪽에 **이미지** 탭이 생겼습니다.

- 파일을 **끌어다 놓거나** 선택해 올립니다. 여러 개를 한 번에 올릴 수 있습니다.
- 올린 이미지가 썸네일과 함께 목록으로 보이고, 크기와 용량을 표시합니다. 썸네일은 세션
  자격증명으로 받아 blob URL로 그리므로, 서버가 보낸 SVG가 워크스페이스 오리진에서
  실행될 수 없습니다.
- **코드에 넣기**를 누르면 `::image 이름`이 코드 편집기에 들어갑니다. 코드 탭이 열려
  있지 않으면 클립보드에 복사하고 무엇을 붙여 넣어야 하는지 알려 줍니다.
- 삭제도 같은 자리에서 합니다. 이름을 지정하지 않으면 파일명이 이름이 되고, 같은 이름으로
  다시 올리면 교체됩니다.

## 그 외

- 업로드 요청이 `FormData`일 때 클라이언트가 JSON 콘텐츠 타입을 붙이지 않습니다. 멀티파트
  경계는 브라우저가 정합니다.
- 이미지 응답을 받을 때 `Accept`가 SVG만이 아니라 PNG·JPEG·GIF도 포함합니다.

## 오프라인 설치

```bash
gzip -dc ptium-0.8.0.tar.gz | docker load
sha256sum -c ptium-0.8.0.tar.gz.sha256
```
