# Ptium v0.82.0

이번 판은 **소스를 읽지 않고 그려진 슬라이드를 봤습니다.** 새 브리프로 9장짜리 덱을 만들어
전 장을 PNG 로 뽑아 놓고 눈으로 훑었습니다. 두 가지가 그림에서는 대번에 보였고, **어떤
측정도 잡지 못했습니다.**

## 표 이름이 열 제목이 되어 있었습니다

모델이 표 이름을 울타리 **안에** 썼습니다.

```
::grid checklist
준비 상태
항목 | 상태
핵심 인력 교육 | 완료
```

표의 첫 줄은 열 제목입니다. 그래서 이렇게 나왔습니다.

- 열이 **하나**, 제목은 `준비 상태`
- 진짜 열 제목인 `항목 | 상태` 가 **첫 데이터 줄** 로 내려감
- 이름은 **두 번** 인쇄 — 정의가 주는 캡션으로 한 번, 저 외로운 열로 또 한 번

아래 줄들이 두 칸씩인데 첫 줄만 **한 칸** 이면 그건 열 제목이 아니라 **이름** 입니다. 울타리에
이름이 없을 때는 그것을 이름으로 씁니다.

## 비교의 양쪽이 불릿 한 줄이 되어 있었습니다

```
@comparison
- 현재 | 자동화
- 현재: 0.8% 오배송, 인력 비용 증가
```

앞에 `> ` 를 붙여 쓰면 v0.60 부터 두 단의 머리말로 갈라 왔습니다. 안 붙이면 그냥 요점으로
남아서, 슬라이드 첫 불릿이 `현재 | 자동화` 였고 **어느 단에도 이름이 없었습니다.** 같은
슬라이드입니다. 이제 두 영역짜리 레이아웃에서 **이름 한 쌍인 첫 요점** 은 두 단의 이름이
됩니다. 막대가 들어갔을 뿐인 문장은 여전히 요점입니다.

## 확인

같은 덱을 다시 그렸습니다.

| | 이전 | 이번 |
|---|---|---|
| 표 8장 | `준비 상태` 두 번 · 데이터로 내려간 열 제목 | 이름 한 번 · `항목`/`상태` 가 열 제목 |
| 비교 4장 | 첫 불릿 `현재 \| 자동화` · 이름 없음 | 왼쪽 `현재` · 오른쪽 `자동화` |

## 이번 판이 말하는 것

**측정은 재는 것만 잡습니다.** 최근 네 판에서 나온 결함 — 붙어 버린 머리말, 리드로 올라간
1번 항목, 이름만 맞는 출처, 그리고 오늘 둘 — 은 전부 점수 96~98점짜리 덱에서 나왔습니다.
정기적으로 **그려진 것을 눈으로 보는 일** 을 대신할 수 있는 측정은 아직 없습니다.

## 설치

오프라인 설치 방법은 [docs/offline-deployment.md](offline-deployment.md) 를 보세요. 이미지에
Postgres 와 nginx 는 들어 있지 않습니다 — 배포할 때 `DATABASE_URL` 로 DSN 을 지정합니다.
