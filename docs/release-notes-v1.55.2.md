# Ptium v1.55.2

**발표자 타이머의 "일시정지"가 말한 두 가지를 모두 하지 않았습니다.**

## 브라우저로 쟀습니다

발표를 시작하고, 8초 뒤 일시정지를 누르고, 6초 기다렸다가 재개했습니다.

```
8초 발표한 뒤 시계        : 00:00:09
일시정지를 누른 직후      : 00:00:00      ← 시간을 잡아 두는 대신 0으로 지웠습니다
멈춘 채 6초 더 기다린 뒤  : 00:00:00
재개하고 2초 뒤           : 00:00:19      ← 멈춰 있던 6초가 그대로 들어 있습니다
```

두 가지가 틀렸습니다.

1. **멈추면 시계가 0으로 지워집니다.** 9초에 멈췄는데 00:00:00을 보여 줍니다.
2. **멈춰도 시간은 흘렀습니다.** 6초짜리 질문을 받고 돌아오니 9초가 19초가 되어
   있습니다.

버튼의 설명은 "타이머 일시정지"입니다. 둘 다 그 말과 다릅니다.

## 왜 그랬나

시계를 **멈춘 순간이 아니라 발표를 시작한 순간**에서 읽고 있었습니다.

```js
elapsed(startedAt + offset, paused ? startedAt + offset : now)
//                                   ^^^^^^^^^^^^^^^^^^ 자기 자신 → 언제나 0
```

멈춰 있는 동안 `now`가 갱신되지 않도록 하는 장치는 이미 제대로 있었는데, 이 삼항이
그걸 무효로 만들고 있었습니다. 그리고 재개하면 `now`가 실제 시각으로 돌아오므로,
멈춰 있던 시간이 총 시간에 그대로 남았습니다.

## 고친 것

멈춘 순간을 기억하고, 재개할 때 **멈춰 있던 만큼 시작 시각을 앞으로 밉니다** —
초기화 버튼이 이미 하던 것과 같은 방식입니다.

```js
export function talkElapsed(startedAt, offset, now, heldAt) {
  return Math.max(0, (heldAt ?? now) - (startedAt + offset))
}
```

발표가 멈춰 서 있던 시간은 발표가 쓴 시간이 아닙니다. 같은 측정을 다시 하면:

```
8초 발표한 뒤 시계        : 00:00:09
일시정지를 누른 직후      : 00:00:09
멈춘 채 6초 더 기다린 뒤  : 00:00:09
재개하고 2초 뒤           : 00:00:11
초기화를 누른 뒤          : 00:00:01
```

초기화도 함께 손봤습니다. 멈춘 채로 초기화하면 시계는 0을 가리키고, 재개해도 빚이
남지 않습니다.
