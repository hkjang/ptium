# Ptium v1.12.3

## 생성 중에 **지금 무엇을 하고 있는지** 보입니다

자체 호스팅 모델로 덱 하나를 쓰는 데 1~3분이 걸립니다. 그동안 화면은 처음부터 끝까지
같은 문장이었습니다 — **5초에도, 3분에도** 똑같이. 멈춘 화면과 구별할 방법이 없습니다.

이제 지나가는 단계를 그대로 말합니다.

```
  2s  무엇을 어떤 순서로 말할지 정하고 있어요
 57s  슬라이드를 쓰고 있어요
102s  자리에 맞는지 재고, 넘치는 장을 고치고 있어요
110s  템플릿에 맞춰 슬라이드를 앉히고 있어요
```

(실제 생성 한 건에서 측정한 값입니다. 112초에 끝났습니다.)

- 진행률 막대가 아닙니다. **실제로 지나간 단계** 만 말합니다 — 지어낸 퍼센트는 아무것도
  알려주지 않습니다
- 다시 쓰기일 때는 "슬라이드를 **다시** 쓰고 있어요"라고 합니다
- 서버가 새 단계를 말하면 **아무 말도 하지 않습니다**. 모르는 값을 화면에 그대로 찍는 대신
  이전처럼 두는 편이 낫습니다
- 폐쇄망 생성은 1초 안에 끝나므로 단계를 표시하지 않습니다

`GET /presentations/{id}` 의 `generationStage` 로도 읽을 수 있습니다(`planning` ·
`writing` · `binding` · `fitting` · `notes`, 끝나면 빈 값).

## 설치

```bash
gzip -dc ptium-1.12.3.tar.gz | docker load
```
