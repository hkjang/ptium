# Ptium v0.28.0

**살아 있는 모델**(자체 호스팅 122B)을 붙여 마이크로소프트 기본 템플릿에 9장짜리 보고서를
생성하고, 나온 것을 측정했습니다. 결함 2건이 나왔고 둘 다 고쳤습니다.

## 글자만 있는 차트가 빈 사각형을 그렸습니다

모델이 "현재 조직 | 개발/운영 분리"처럼 **문구로 된 항목**으로 세로 막대 차트를 요청했습니다.
문구는 그릴 수 없으므로 슬라이드에는 **논지가 있어야 할 자리에 빈 사각형**이 남았습니다.

차트는 숫자로 그립니다. 숫자가 하나도 없는 수치형 컴포넌트는 이제 통과하지 못하고,

- 값이 **문구**면 → **2열 표**(v0.25부터 PowerPoint에서 편집 가능한 진짜 표)
- 값이 **숫자**면 → 지표 카드

로 내려갑니다. 어느 쪽이든 빈 사각형은 나오지 않습니다.

## 지표 카드의 라벨이 숫자를 뚫고 지나갔습니다

"목표 가용성"이 좁은 카드(반쪽 슬라이드의 3분할)에서 두 줄로 접히는데 카드는 **한 줄만
확보**하고 있었습니다. 측정은 정확히 잡았지만("0.53cm 더 크게 그려짐", "두 줄이 겹침") 다시
쓰기로는 레이아웃 산수를 고칠 수 없습니다.

이제 카드는 **실제 라벨 높이만큼** 커집니다. 영역이 그만큼을 못 주면 **숫자가 양보**합니다 —
접힌 라벨 아래 작은 숫자는 읽히지만, 라벨이 관통한 숫자는 읽히지 않습니다.

같은 모델 생성 덱: **결함 2 → 0**.

## 그 밖에

- **표지에 날짜가 들어갑니다.** 브리프가 시점을 말하지 않으면 덱의 생성 월을 씁니다
  ("2026년 8월 · 경영진 보고"). 날짜 없는 표지는 초안처럼 보입니다.
- **"임원에게 보고"에서 조사만 지워지고 "임원"이 남던 문제.** 남은 조각이 덱 제목까지
  따라가 "2026년 하반기 클라우드 전환 로드맵을 임원"이 됐습니다. 주소절을 통째로 지우고,
  두 명사 사이를 지웠을 때 양끝에 남는 것도 정리합니다 — "계획을 자료" → "결제 시스템 이중화
  계획", "고객에게 전달할 …" → "신규 요금제 안내 자료".
