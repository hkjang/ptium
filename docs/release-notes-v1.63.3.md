# 1.63.3 — 인쇄한 PDF 에서도 3장은 3장입니다

지난 판에서 공유 링크를 고쳤습니다. 같은 어긋남이 종이에도 있었습니다.

유인물은 건너뛴 장을 빼고 인쇄합니다. 그래서 덱의 세 번째 장은 세 번째 쪽이
아닙니다. `[3장 참고](#3)` 를 PDF 에서 누르면 앞에 건너뛴 장이 있는 만큼
뒤쪽으로 밀린 쪽이 열렸습니다.

- 점프는 그 장이 실제로 인쇄된 쪽으로 갑니다.
- 건너뛴 장을 가리키는 점프는 그 다음으로 인쇄된 쪽으로 갑니다 — 발표 화면,
  공유 링크와 같은 규칙입니다.
- 발표자 노트 안의 점프도 같습니다. 노트도 종이에 인쇄됩니다.

## 아무 데도 가지 않는 링크는 쓰지 않습니다

덱에 없는 장을 가리키는 점프(`#9` 를 다섯 장짜리 덱에서)는 PDF 에
`/URI ()` — 주소가 빈 링크 주석으로 적혔습니다. 누를 수는 있고, 누르면 아무
일도 정의되어 있지 않습니다. 이제 그런 자리에는 주석을 아예 쓰지 않습니다.
이 문서 안의 쪽도 아니고 주소도 아니면 링크가 아닙니다.

## 확인

- 5장 덱에서 2장을 건너뛰고 인쇄해, 제품 바깥의 판독기(`pypdf`)로 링크 주석을
  읽었습니다. `#3` 과 `#2` 모두 2쪽(셋째 장)으로 가고, `#9` 자리에는 주석이
  없습니다. 노트를 붙인 유인물도 같습니다.
- 고침을 되돌려 `#3` 이 3쪽(넷째 장)으로 가는 것을 확인했습니다.
