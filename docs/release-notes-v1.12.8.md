# Ptium v1.12.8

v1.12.7 은 수치 라벨의 모양을 고쳤습니다. 이번에는 라벨이 **어디서 오는지** 입니다. 하나는
남의 문장에서 낱말을 가져왔고, 하나는 아무것도 가져오지 못해 **수치가 통째로 사라졌습니다.**

## 라벨은 자기 문장 안에서만 읽습니다

```
"물류센터 자동화(AMR 20대) 도입 승인 요청. 투자 18억, …"
                                  ↑ 앞 문장
label="요청. 투자"   value="18억"
```

라벨은 숫자 바로 앞의 낱말들인데, 되짚기를 멈추는 표시에 쉼표·가운뎃점은 있고 **마침표는
없었습니다.** 앞 문장의 마지막 낱말이 딸려 왔습니다. 문장 끝(`.` `。` `!` `?`)도 벽입니다.
(→ `label="투자"`)

## 라벨이 없으면 수치가 사라집니다

브리프가 `"투자 18억, 3년 내 회수"` 라고 하면 `3년` 앞에는 이름이 없습니다. 라벨이 비면 차트는
그 수치를 **건너뜁니다** — 브리프가 말한 것을 덱이 한 번도 보여주지 않습니다.

한국어는 숫자 뒤에 이름을 두는 일이 그만큼 잦습니다("3년 내 회수", "18개월 손익분기").
앞에 없으면 뒤를 읽습니다. `내`·`후`·`이내` 처럼 **자리를 말하는 낱말**은 이름이 아니므로
건너뜁니다. (→ `label="회수" value="3년"`)

이 브리프의 네 수치가 이제 모두 이름을 갖습니다:

```
물류센터 자동화 20대 · 투자 18억 · 회수 3년 · 인력 재배치 12명
```

## 되돌려서 확인했습니다

두 수정을 각각 되돌려 테스트가 무는지 확인했습니다.

## 설치

```bash
gzip -dc ptium-1.12.8.tar.gz | docker load
```

## 검사가 제품을 잘못 고발했습니다

이 릴리즈를 처음 빌드할 때 업그레이드 검사가 이렇게 멈췄습니다:

```
docker: Conflict. The container name "/ptium-upgrade-5880-old" is already in use
The image that was just built does not open a database an older release wrote.
```

이미지는 아무 문제가 없었습니다. 이전에 중단된 실행이 남긴 컨테이너가 이름을 쥐고 있었고,
검사 이름이 **네 자리 난수**뿐이라 그 이름을 다시 뽑은 것입니다. 그런데 마지막 줄은 릴리즈를
세우면서 제품 탓을 했습니다.

- 이름에 프로세스 번호를 넣습니다 — 동시에 도는 두 검사가 부딪히지 않습니다
- 컨테이너를 띄우기 전에 그 이름을 먼저 비웁니다 — 남은 것은 검사 자신의 흔적입니다
- **검사가 돌지 못한 것과 제품이 떨어진 것을 구분합니다.** 전자는 exit 2 로 나가고,
  빌드는 그대로 멈추되(돌지 못한 검사는 아무것도 증명하지 않았으므로) 이렇게 말합니다:
  "검사를 이 호스트에서 돌리지 못했습니다 — 이미지에 대해 증명된 것이 없습니다."
