# Ptium v0.95.0

이번 주에 만든 덱은 **전부 한국어** 였습니다. 그래서 하나를 **영어로** 만들어 봤습니다.
**100점** 이 나왔고, 잘못된 것이 둘 있었습니다. **둘 다 우리 잘못이었습니다.**

## 예시 덱이 언제나 한국어였습니다

작성 안내 끝에 붙는 두 장짜리 예시가, 어떤 언어를 요청하든 **한국어** 였습니다. 영어로 쓰던
모델은 **본 대로 따라 했습니다.**

```
::kpi 규모        ← 영어 덱의 컴포넌트 캡션
```

예시에 있던 인용도 같이 따라왔습니다 — `내부 시스템 대장 | 2026-03`. 그동안 아무 상관 없는
덱과 다시쓰기에서 **지어낸 출처** 로 계속 튀어나오던 그 문자열의 **출처가 여기였습니다.**

**예시는 규칙만큼 읽힙니다.** 이제 예시가 둘이고, 덱의 언어가 하나를 고릅니다. 둘 다 모든
구문을 가르칩니다.

## 영어 제목이 슬라이드 밖으로 나갔습니다

미리보기는 템플릿의 글꼴을 요청합니다 — **Aptos** 는 Microsoft 365 에만 딸려 옵니다. 그게
없는 기기에서는 브라우저가 부르는 `sans-serif` 로 떨어지고, 리눅스에서는 보통 **DejaVu Sans**
입니다. 소문자 폭이 템플릿용 휴머니스트 서체보다 **5분의 1 더 넓습니다.**

**SVG 는 줄을 다시 흘릴 수 없습니다.** 그래서 "들어간다" 고 잰 제목이 상자 밖으로 **1.2cm**
나가 그려졌습니다.

이제 대체 목록이 이렇습니다.

```
<템플릿 글꼴>, Segoe UI, Roboto, Noto Sans, Helvetica Neue, Arial,
Liberation Sans, Malgun Gothic, Apple SD Gothic Neo, Noto Sans KR, sans-serif
```

라틴 서체가 앞에, 한국어 서체가 뒤에 옵니다 — 브라우저는 **글자마다** 고르기 때문에 한글은
여전히 자기 글꼴을 찾습니다. 같은 제목이 이제 상자 **안쪽에서** 끝납니다.

## 다시 만든 영어 덱

- 한국어 **한 글자도 없음**
- 지어낸 출처 **없음**
- **99점**, 남은 지적은 한 영역에 요점 7개라는 정직한 한 건

## 설치

오프라인 설치 방법은 [docs/offline-deployment.md](offline-deployment.md) 를 보세요. 이미지에
Postgres 와 nginx 는 들어 있지 않습니다 — 배포할 때 `DATABASE_URL` 로 DSN 을 지정합니다.
