# Ptium v1.19.0

## "리스크 장을 꼭 넣어주세요" 가 슬라이드 제목이 되고 있었습니다

브리프에 이렇게 쓰면:

> 물류센터 자동화 도입을 임원에게 보고합니다. **마지막에 리스크 장을 꼭 넣어주세요.**

폐쇄망 생성기가 만든 덱은 이랬습니다.

```
# 물류센터 자동화 도입
# 이행 순서
# 물류센터 자동화 도입 — 기대 효과
# 물류센터 자동화 도입 — 리스크와 대응
# 리스크 장을 꼭 넣어주세요          ←
# 리스크 장을 꼭 넣어주세요 — 현황     ←
# 리스크 장을 꼭 넣어주세요 — 선택지 비교 ←
# 다음 단계
```

**부탁하는 문장이 그대로 제목**이 되었습니다. 그것도 세 장이나. 영어도 같았습니다 —
`Include a slide on rollback` 이 세 장의 제목이었고, `일정 슬라이드와 예산 슬라이드를
포함해 주세요` 는 표지 제목까지 `신규 서비스 출시 · 일정 슬라이드` 로 만들었습니다.

문장이 **이름 붙인 것이 그 장의 주제**이고, 나머지는 부탁입니다. 이제 그렇게 읽습니다.

```
# 물류센터 자동화 도입
# 이행 순서
# 물류센터 자동화 도입 — 기대 효과
# 물류센터 자동화 도입 — 리스크와 대응
# 리스크                              ←
# 리스크 — 현황
# 리스크 — 선택지 비교
# 다음 단계
```

- `일정 슬라이드와 예산 슬라이드를 포함해 주세요` → **일정** 장과 **예산** 장
- `Include a slide on rollback and a timeline slide` → **Rollback** 장과 **Timeline** 장
- **부탁받은 장은 덱의 제목이 되지 않습니다.** 물류센터 자동화 보고서는 리스크 장이 있어도
  물류센터 자동화 보고서입니다

### 세 가지를 구분합니다

- **장 수** — `10장으로 정리해줘` 는 길이입니다. 주제가 아닙니다(전부터 그랬고, 그대로입니다)
- **위치** — `마지막에` 는 순서에 대한 말이라 제목에서 뺍니다
- **남은 서술어** — `임원에게 보고합니다` 에서 청중을 걷어내면 `…도입을 합니다` 가 남습니다.
  표지에 `물류센터 자동화 도입을 합니다` 라고 적히던 것을 이제 `물류센터 자동화 도입` 으로 적습니다

## 실제 모델에서도 확인했습니다

같은 브리프를 **살아 있는 모델**로 돌렸습니다 — `리스크 관리 전략` 장이 들어간 8장짜리 덱이
나왔고 표지는 `물류센터 자동화 도입` 이었습니다. 모델 경로는 원래 잘 하고 있었고,
**망가져 있던 건 폐쇄망 경로**였습니다. 폐쇄망이 이 제품의 기본값입니다.
