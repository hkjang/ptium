# Ptium v0.94.0

지난 판의 감사에서 문 두 개가 남아 있었습니다 — **다른 도구로 만든 파일** 과 **MCP**.
둘 다 걸어 봤습니다.

## MCP 는 스스로 쓰지 않습니다

MCP 의 생성 도구는 **웹 앱과 같은 워커를 큐에 넣습니다.** 그래서 최근 세 판이 모델의 답 앞에
세워 둔 것들이 그 경로 앞에도 그대로 서 있습니다. 고칠 것 없음.

## 가져오기: 다섯 장 전부 들어왔습니다

python-pptx 로 덱을 하나 지어서 넣어 봤습니다 — 표지, 발표 노트가 달린 목록 슬라이드, 표,
차트, 빈 레이아웃 위의 텍스트 상자 하나.

| 넣은 것 | 나온 것 |
|---|---|
| 목록 3줄 + 노트 | `- 검색 실패율 31%` … `!notes 여기서 실패율을 강조합니다.` |
| 표 3×3 | `::table` 로 행 그대로 |
| 세로 막대 차트 | `::columns` 로 **숫자째** |
| 텍스트 상자 | 슬라이드 제목으로 |

Ptium 이 자기 디자인으로 다시 그린 두 개(표·차트)는 **그렇다고 말합니다.**

## 그리고 다시 나갔다 들어왔습니다

내보낸 파일에서 **Ptium 이 안에 숨겨 둔 소스를 지우고** 다시 넣었습니다. 누군가 내보낸 파일을
PowerPoint 에서 손보고 되가져올 때 지나는 길입니다. **그림만 읽어서** 복원한 결과도 잃은 것이
없습니다.

## 고칠 게 없으면 지킬 것을 둡니다

`package.py` 스윕이 이제 **매번** 다른 도구의 덱을 가져와 넣고, 내보내고, 소스를 지우고, 다시
넣습니다.

**한 번 걸어 본 문은 다음 달에는 아무도 안 보는 문입니다.**

## 설치

오프라인 설치 방법은 [docs/offline-deployment.md](offline-deployment.md) 를 보세요. 이미지에
Postgres 와 nginx 는 들어 있지 않습니다 — 배포할 때 `DATABASE_URL` 로 DSN 을 지정합니다.
