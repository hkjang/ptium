# Ptium v1.50.2

**덱의 원문을 그대로 다시 적용하면 그림 두 장이 자리를 바꿨습니다.**

## 문 사이에서 내용이 바뀌는지 쟀습니다

사용자의 실제 파일 12개를 가져온 뒤, **각 덱의 원문을 읽어 아무것도 고치지 않고
그대로 다시 적용**해 봤습니다. 아무 일도 일어나지 않아야 합니다.

```
12개 중 2개가 달라졌습니다
```

무엇이 달라졌는지 보니:

```
슬라이드 2 「도입 배경 및 전략적 목표」
  before   body=image16 · picture=image15
  after    body=image15 · picture=image16
```

**저장할 때마다 두 그림이 자리를 바꿉니다.**

## 쓰는 쪽과 읽는 쪽이 서로 다른 순서를 쓰고 있었습니다

원문을 쓸 때는 슬라이드를 **읽는 순서**대로 — 왼쪽 글 영역, 그 다음 오른쪽 그림
영역 — 돌면서 `::image` 를 적습니다. 반대로 원문을 덱으로 만들 때는 **그림 영역을
먼저** 채웁니다. 그래서 글 영역에 있던 첫 줄이 그림 영역으로 들어가고, 둘이
맞바뀌었습니다.

이제 원문은 **읽는 쪽이 가져갈 순서대로** 그림을 적습니다. 글의 순서는 그대로입니다.

```
고친 뒤: 12개 중 0개가 달라짐
```

## 재 보지 않았으면 틀렸을 뻔했습니다

처음에는 원인을 **map 순회 순서**로 짚었습니다(Go의 map은 매번 다른 순서로 돌기
때문에). 고치고 테스트도 붙였는데, **되돌려도 테스트가 통과했습니다** — 그 경로를
아예 지나지 않는 테스트였던 것입니다. 덕분에 진짜 원인이 따로 있다는 것을 알았습니다.

map 순회 쪽도 실제로 불안정한 것은 맞아서, 그 자리를 지나는 테스트로 고쳐 함께
남겼습니다.
