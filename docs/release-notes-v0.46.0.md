# Ptium v0.46.0

회사에서 슬라이드 위의 숫자가 받는 첫 질문은 언제나 같습니다.

> 이거, 어디서 나온 겁니까?

지금까지 Ptium에는 그 답을 적을 자리가 없었습니다.

## 숫자 옆에 출처를 적습니다

```
# 실적
- 매출 1,240억 ^1
- 이익률 9.8% ^2
!source 1 | 2026 시장 조사 보고서 | p.42
!source 2 | 사내 결산 자료
```

- `!source` 는 **표시 | 제목 | 어디** 순서이고, 표시와 어디는 생략할 수 있습니다.
- 출처는 **슬라이드와 함께** 저장됩니다. 덱을 복제하든 버전을 되돌리든 파일로 내보내든 근거가
  주장을 따라다닙니다. (별도 테이블은 덱을 가로질러 찾을 일이 생길 때 만듭니다.)
- **왕복이 보존됩니다.** 소스로 다시 쓸 때 `!source` 줄이 그대로 돌아옵니다 — 여기서 사라지면
  근거는 편집할 때마다 조금씩 지워집니다.
- 내보내면 **발표자 노트 끝에 출처 목록**이 붙습니다. 슬라이드 디자인은 그대로 두고, 질문을 받은
  사람이 실제로 보는 자리에 답이 놓입니다.

## 그리고 없으면 그렇게 말합니다

측정에 한 줄이 늘었습니다. **숫자를 말하면서 출처가 하나도 없는 슬라이드**는
`숫자의 출처 없음` 으로 표시됩니다. 숫자가 없는 슬라이드에는 묻지 않습니다 — 물어 봐야 소용
없는 질문을 반복하면 사람들이 경고 전체를 무시하게 됩니다.

품질 점수에는 다섯 번째 축이 생겼습니다: **근거**. 가독성 · 구성 · 시각 · 접근성 옆입니다.

## 도중에 잡은 버그

이번 회귀 테스트가 v0.40의 실수를 잡았습니다. 한국어 띄어쓰기 정리가 단어를 잡아먹고 있었습니다.

```
2026 시장 조사 보고서  →  2026시장 조사 보고서
```

단위 목록의 `시` 가 `시장` 의 첫 글자와 맞은 것입니다. 이제 **단위는 단어가 끝나는 자리에서만**
붙습니다: 뒤에 오는 것이 한글이 아니거나, 조사·접미(에·으·을·간·짜·씩…)일 때만. `4시간에서`,
`3단계로`, `2장짜리` 는 그대로 붙고 `2026 시장`, `7 월요일` 은 그대로 둡니다.

## 확인

- 회귀 테스트 2건: `!source` 가 파싱·저장·**왕복**되는 것, 그리고 단위가 다음 단어를 먹지 않는 것
  (7가지 표현).
- 전수 점검에 한 줄: 내보낸 파일의 **노트 페이지에 출처가 있는지** python-pptx로 확인.
- 실측: 출처가 있는 장과 없는 장을 나란히 둔 4장 덱 → 없는 장만 `source` 로 표시, 근거 축 97,
  가장 낮은 슬라이드 3번.
- 전수 점검: api 76 · edges 32 · package · deep 0 실패.
