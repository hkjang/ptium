# Ptium v0.98.0

**일본어 덱** 을 하나 만들어 봤습니다. 세 번째 문자 체계이고, 여기 있는 규칙들이 **한 번도 대
본 적 없는** 언어입니다. 세 가지가 잘못돼 있었습니다.

## 1. 숫자와 단위가 떨어져 있었습니다

```
2026 年 8 月    8,400 万円    3 時間 12 分    月間 4,200 件を 9 名で対応
```

**아무도 이렇게 쓰지 않습니다.** 이 간격을 닫는 정리기는 한국어 덱 시절부터 돌고 있었는데
**한글 단위만** 알고 있어서 일본어는 그냥 통과했습니다.

이제 일본어·중국어에서도 같은 간격을 닫습니다(`年 月 日 時間 分 件 名 万円 割 四半期 …`).
작성 안내도 "한국어에서" 가 아니라 **세 언어 모두** 에 대해 요구합니다.

## 2. "문장인지" 판정이 한국어만 알았습니다

어떤 줄이 단 이름이 될 수 있는지를 이 판정이 정합니다. 그런데 두 가지가 틀려 있었습니다.

- 한국어 어미(`다 요 죠 …`)만 알고 일본어(`ます です する …`)는 몰랐습니다
- **줄의 마지막 바이트** 가 마침표인지 물었습니다 — 한국어·일본어 어미의 마지막 바이트는
  **언제나 연속 바이트** 라 마침표일 수가 없습니다

이제 **마지막 글자** 를 보고, `。！？` 와 일본어 어미도 압니다.

## 3. 한자가 네모(두부)로 그려졌습니다

```
回答□延が業務□率を阻害      (遅, 効 가 빈 네모)
```

미리보기 글꼴 목록에 **한국어 글꼴만 있고 일본어 글꼴이 없었습니다.** 한국어 글꼴은 한국이
쓰는 한자는 담고 있지만 **쓰지 않는 한자는 담고 있지 않습니다.**

이제 제품이 생성하는 **모든 문자 체계** 를 이름으로 부릅니다 — `Yu Gothic, Hiragino Sans,
Meiryo, Noto Sans JP, Microsoft YaHei, PingFang SC, Noto Sans SC`.

**정직하게**: 이 기계에는 일본어 글꼴이 **하나도 설치돼 있지 않아서** 목록을 어떻게 바꾸든
여기서는 여전히 네모로 보입니다. 이 수정이 하는 일은, **글꼴을 가진 사람이** 그 글자가 없는
글꼴로 떨어지지 않게 하는 것입니다.

## 설치

오프라인 설치 방법은 [docs/offline-deployment.md](offline-deployment.md) 를 보세요. 이미지에
Postgres 와 nginx 는 들어 있지 않습니다 — 배포할 때 `DATABASE_URL` 로 DSN 을 지정합니다.
