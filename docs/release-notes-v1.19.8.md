# Ptium v1.19.8

평범한 한국어 브리프 **여섯 개**를 실제 API로 돌렸더니 **다섯 개의 제목이 말이 안 됐습니다.**

| 브리프 | 나온 제목 |
| --- | --- |
| 협력사 정산 프로세스를 **개선하려고 합니다** | 협력사 정산 프로세스를 **개선하려고** |
| 회사 소개 자료 **만들어줘** | 회사 소개 **어줘** |
| AI 챗봇 도입 검토 **보고서** | AI 챗봇 도입 검토 **서** |
| 체계를 새로 **만들려고 하는데** … 8장 정도 **필요합니다** | **새로 만들려고 하는데 필요** |
| 실행 계획을 팀원들에게 **공유하려고 합니다** | 실행 계획을 **하려고** |

**품질 점수는 98~100점이었습니다.** 그리는 것은 흠잡을 데가 없었고, **글이 말이 안 됐습니다.**

## 주제 주변의 말은 주제가 아닙니다

사람은 주제만 쓰지 않습니다. **무엇을 하려는지**(개선하려고 합니다), **무엇이 필요한지**
(8장 정도 필요합니다), **무엇보다 나쁜지**(작년보다 나빠졌습니다), **문서 이름**(보고서)까지
같이 씁니다. 그것들을 하나씩 알아보게 했습니다.

- **하려는 일** — `개선하려고 합니다` · `만들려고 하는데` · `공유하려고` → 주제만 남깁니다
- **동사의 어미** — `만들어줘` 를 `만들` 만 떼어 `어줘` 가 남던 것을 통째로 뗍니다
- **문서 이름** — `보고서` · `제안서` · `기획서` 는 **한 단어**입니다. 반만 떼어 `서` 를
  남기지 않고, **주제의 일부이므로 그대로 둡니다**(`AI 챗봇 도입 검토 보고서`)
- **필요하다는 말** — `8장 정도 필요합니다` 는 길이 요청이지 주제가 아닙니다
- **지난 일과 비교** — `나빠졌습니다` · `작년보다` 를 걷어내 `재고 회전율` 이 남습니다
- **제목은 한 문장** — 마침표 뒤는 다른 생각입니다
- **주격 조사** — `재고 회전율이` 의 `이` 는 뗍니다. 단, **여러 단어일 때만** —
  `높이` · `길이` · `손잡이` 를 `높` 으로 만들지 않기 위해서입니다

## 지금

```
협력사 정산 프로세스를 개선하려고 합니다…   → 협력사 정산 프로세스를 개선
회사 소개 자료 만들어줘                → 다음 주 전사 워크숍에서 쓸 회사 소개
AI 챗봇 도입 검토 보고서               → AI 챗봇 도입 검토 보고서
…새로 만들려고 하는데 8장 정도 필요합니다   → 고객센터 상담 품질 관리 체계  (청중 임원 · 8장)
…팀원들에게 공유하려고 합니다            → 우리 팀 2026년 목표와 실행 계획
재고 회전율이 작년보다 나빠졌습니다…       → 재고 회전율
```

## 왜 지금까지 몰랐나

**아무도 읽지 않았기 때문입니다.** 검사는 통과하고, 점수는 100점이고, 오류 로그는 비어 있습니다.
평범한 브리프를 넣고 나온 글을 **사람처럼 읽는 것** 말고는 이걸 찾는 방법이 없습니다.

실패합니다.
