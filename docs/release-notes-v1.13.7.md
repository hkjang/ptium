# Ptium v1.13.7

v1.13.6 이 넣은 30초 캐시를 따라가 보니, **바뀐 설정을 옛 결과로 덮고** 있었습니다.

## 바뀐 것에 대한 옛 읽기는 그것에 대한 읽기가 아닙니다

운영자가 제공자를 다른 호스트로 돌려놓고 개요를 봅니다. 화면은 **이전 호스트가 "응답함"**
이라고 말합니다 — 최대 30초 동안:

```
설정: base_url → http://127.0.0.1:9/v1   (아무것도 없는 주소)
화면: reachable=true, baseUrl=http://222.107.52.227:11300/v1
```

두 릴리즈 전에 없앤 "무조건 연결됨" 배지와 같은 잘못입니다 — 화면이 지금 설정에 대해
사실이 아닌 것을 말합니다.

이제 **`ai.` 로 시작하는 설정이 하나라도 저장되면 그 읽기를 버립니다.** 다음에 화면이 물으면
새 설정으로 새로 묻습니다.

## 확인

스윕이 이것을 잡으려면 **설정 변경과 화면 읽기 사이에 아무것도 없어야** 합니다 — 명시적
확인(POST)은 언제나 새로 물으므로 그 사이에 끼면 결함을 가립니다. 처음 쓴 검사가 정확히
그렇게 되어 있어서, 버리기를 떼어내도 통과했습니다. 순서를 고치자 걸립니다:

```
✗ a screen reads the provider as it was before the change:
  'http://127.0.0.1:9/v1', want 'http://222.107.52.227:11300/v1'
```
