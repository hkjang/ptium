# 1.61.1 — 1200*800*750 은 크기입니다

`1200*800*750` 은 한국어 문서에서 크기를 적는 방식입니다. 가로*세로*높이.
제품은 가운데 별표 두 개를 기울임 표시로 읽었고, 슬라이드에는
**1200800750** 이 그려졌습니다. `(가로*세로*높이)` 는 `(가로세로높이)` 가
되었습니다.

기호가 화면에 찍히는 것은 누가 봐도 눈에 띕니다. 숫자가 조용히 다른 숫자로
바뀌는 것은 아무도 못 봅니다.

- 글자나 숫자에 붙어 있는 별표는 표시가 아닙니다. 앞에 빈칸이 있어야 표시로
  읽습니다. `3 * 4` 는 이미 그렇게 처리하고 있었는데, 빈칸 없이 붙여 쓴
  `12*34*56` 이 빠져 있었습니다.
- 여는 쪽만 봅니다. 한국어는 닫는 표시 뒤에 조사가 바로 붙습니다 —
  `**중요**합니다` — 양쪽에 빈칸을 요구했다면 이 제품으로 쓰는 덱의 절반이
  표시를 잃었을 것입니다.
- 원래 쓰던 표시는 그대로입니다. `**중요**한 사항`, `(**필수**) 항목`,
  `비고: *검토 필요*` 모두 그대로 굵게, 기울임으로 나갑니다.

글머리 줄과 표의 칸 모두에 적용됩니다. 표의 칸을 다른 줄과 똑같이 읽기
시작한 것이 1.61.0 이고, 그래서 규격표의 크기도 같은 문제를 겪고 있었습니다.

## 확인

- 규격을 적은 덱을 만들어 내보낸 파일과 미리보기를 함께 읽어, 글머리 줄과
  표의 칸 모두에서 `1200*800*750` 이 작성자가 친 그대로 나오는 것을
  확인했습니다.
- 고침을 되돌려 같은 확인을 다시 해, 되돌린 자리에서 `1200800750` 이
  돌아오는 것을 확인했습니다.
