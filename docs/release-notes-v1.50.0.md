# Ptium v1.50.0

**PDF는 막았는데 .pptx는 열려 있었습니다.**

## 1.49.0이 막지 못한 문

1.49.0은 인쇄를 세 개까지로 막았습니다. 그런데 그 관문은 `format=pdf` 갈래 안에만
있었습니다. **.pptx 내보내기는 그대로였습니다.**

```
사진이 매 장에 있는 40장 덱 16개를 동시에 .pptx로 내보내기
  →  0/16 반환 · 최대 1024 MiB (제한과 정확히 같음) · OOMKilled
```

## 개수로 세는 것이 애초에 틀렸습니다

관문을 .pptx에도 붙이고 다시 재 봤더니 **여전히 죽었습니다**(3/16). 그래서 하나씩
재 봤습니다.

```
.pptx 1개 동시  →  362 MiB
.pptx 2개 동시  →  809 MiB
.pptx 3개 동시  →  1Gi 초과 · 사망
```

**.pptx 한 개가 PDF 세 개만큼 듭니다.** 패키지를 그림째 통째로 조립해서 메모리에
들고 있다가 내보내기 때문입니다. "세 개까지"라는 규칙은 PDF에는 맞고 .pptx에는
전혀 맞지 않았습니다.

## 이제 개수가 아니라 비용으로 막습니다

예산은 3이고, PDF는 1을, .pptx는 3을 씁니다.

```
PDF   16개 동시  →  16개 모두 성공 · 34.3초
.pptx 16개 동시  →  14개 성공 · 2개는 `503 printing_busy` · 최대 833 MiB · 살아 있음
```

거절당한 둘은 60초를 기다린 뒤 **이유를 듣고** 돌아갑니다. 예전에는 열여섯 모두
아무것도 받지 못했고 서버도 함께 죽었습니다.
