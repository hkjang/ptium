# Ptium v0.5.0

v0.4.1에서 제안한 고도화 항목을 구현했습니다. AI가 JSON이 아니라 사람이 읽는 슬라이드
언어로 덱을 쓰고, 표와 선 그래프를 텍스트로 표현할 수 있고, 컴파일 경고가 줄 번호를
알려 줍니다.

## AI가 슬라이드 언어로 씁니다

AI 공급자에게 중첩 JSON 스키마를 요구하던 것을 슬라이드 언어로 바꿨습니다.

- 한 줄에 한 구성 요소뿐이라 균형 맞출 괄호가 없고, 실수는 응답 전체가 아니라 한 줄만
  버립니다.
- 모델이 쓴 것이 곧 사람이 편집기에서 읽고 고치는 텍스트입니다. 예전에는 모델 출력이
  슬라이드 객체로 바로 조립되어 중간에 볼 것이 없었습니다.
- 코드 블록(```)으로 감싸 보내거나 앞에 설명을 붙여도 벗겨 냅니다.
- 예전 JSON 형태로 답하는 공급자·튜닝 모델도 계속 동작합니다(응답이 `{`로 시작하면
  이전 경로로 처리).
- 요청보다 많이 쓰면 뒤에서 자르고 소스도 함께 잘라 저장하며, 경고로 알립니다.

## 표와 선 그래프를 텍스트로

```
::table 연간 비용 (억원)
- 항목 | 2026 | 2027 | 2028
- 인건비 | 4.2 | 3.4 | 3.1
::

::line 월별 처리량
- 월 | 1월, 2월, 3월, 4월
- 전환 전 | 120, 118, 121, 119
- 전환 후 | 120, 132, 148, 165
::
```

- 표는 작성자가 쓴 만큼의 열을 가지며 첫 행이 헤더입니다. 예전에는 `label | value`
  두 열만 표현할 수 있었습니다.
- 선 그래프는 계열당 한 행이고, 값이 순수한 숫자가 아닌 행은 시간축으로 읽습니다.
  `1월`처럼 숫자가 섞인 라벨을 값 1로 읽지 않습니다.
- 필드 안의 `|`는 `\|`로 씁니다.

## 컴파일 경고가 줄 번호를 알려 줍니다

`line 12 (slide 3): comparison did not have enough room and was written as text`
처럼 경고가 소스의 줄을 지목하므로, 고칠 곳을 찾을 수 있습니다.

## 고친 결함

- **표의 마지막 행이 항상 사라졌습니다.** 행 높이를 프레임 전체로 나누면서 마지막 행
  아래 괘선 자리를 남기지 않아, 그 행이 자기 자신의 여유 검사에 걸려 잘렸습니다.
- **컴포넌트가 본문 영역을 차지하면 리드 문장이 사라졌습니다.** 이제 컴포넌트의 제목으로
  올라갑니다.
- **첫 슬라이드가 무조건 표지가 되었습니다.** 컴포넌트나 여러 항목을 담은 첫 슬라이드는
  본문으로 컴파일합니다. 한 장짜리 덱에서 내용이 버려지던 문제입니다.
