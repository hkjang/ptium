# Ptium v1.12.20

**v1.12.19 이 넣은 회귀를 고칩니다. 1.12.19 를 쓰고 계시면 올려 주세요.**

## 무슨 일이었나

v1.12.19 는 템플릿을 바꾸면 덱을 **소스에서 다시 컴파일**하게 만들었습니다. 옳은 방향인데,
어느 소스를 쓰는지가 틀렸습니다.

워크스페이스는 편집한 슬라이드와 새 디자인을 **한 요청에 함께** 보냅니다. 그 순간 편집 내용은
슬라이드에는 있고 **저장된 소스에는 아직 없습니다.** 그런데 다시 컴파일하기가 저장된 소스를
읽었으니, 방금 한 편집이 사라졌습니다:

```
제목을 "편집한 제목" 으로 고치고 디자인을 함께 바꾸면
  → 이동 후 제목: "첫 장"        (편집이 없어짐)
  → 소스에도 없음
```

## 이제

이 제품에는 이미 답이 있었습니다. 소스를 읽는 길은 **"슬라이드가 권위"** 라고 적어 두고,
슬라이드가 저장된 소스보다 새로우면 슬라이드에서 소스를 다시 씁니다. 다시 컴파일하기도 같은
길을 씁니다 — 슬라이드가 말하는 소스를 컴파일합니다.

```
→ 이동 후 제목: "편집한 제목"
→ 소스에도 있음
```

v1.12.19 가 고친 것(옮긴 덱이 그 템플릿으로 만든 덱과 같아지는 것)은 그대로입니다.

## 확인

스윕이 이 경우를 지킵니다: 슬라이드를 편집한 상태로 디자인을 함께 바꾸고, **제목과 소스
양쪽에 편집이 남아 있는지** 봅니다. 저장된 소스를 읽도록 되돌리면 2건이 걸립니다. (265 checks)
