# Ptium v1.20.4

지난 판에서 "틀린 지적은 모델에게 전달돼 내용을 지우게 만든다"고 썼습니다. 그러면 **지적이
맞을 때는 어떻게 되는지** 확인해야 합니다. 살아 있는 모델로 `AI로 다시쓰기` 를 눌러 봤습니다.

## 다시쓰기가 PDF에서 가져온 30줄짜리 노트를 조용히 지웠습니다

감독규정 PDF에서 가져온 덱의 한 장입니다. 그 장의 발표자 노트에는 **한 쪽에서 슬라이드에
담기지 않은 30줄**이 들어 있습니다 — v1.18.0에서 "버리지 않는다"고 한 그 내용입니다.

`AI로 다시쓰기` 를 누르면 모델이 자기 노트 한 줄을 써서 돌려주고, 편집기는 **받는 즉시
적용합니다.** 30줄이 1줄이 됩니다. **아무 말도 없이.**

```
notes before: 30 → proposal: 1
warnings: null
```

## 무엇이 사라지는지 말합니다

이제 제안이 원래 노트의 절반도 담지 않으면 이렇게 답합니다.

> 제안의 발표자 노트는 원래의 **6%**만 담고 있습니다 — 나머지는 사라집니다.
> 되돌리기로 복구할 수 있습니다.

- 노트가 짧은 보통 슬라이드에서는 **말하지 않습니다**(원래 200자 미만이면 조용합니다)
- `노트 다시 쓰기` 로 부른 경우도 말하지 않습니다 — 노트를 바꾸라고 시킨 것이니까요

## 덤: 다시쓰기 알림이 영어로 나오고 있었습니다

이 경고를 넣고 보니, `AI로 다시쓰기` 후 나오는 알림은 **서버가 쓴 영어 문장을 그대로**
보여주고 있었습니다. 서버는 영어로 씁니다(로그와 API의 언어니까요). **사람이 읽는 자리에서는
한국어로 옮깁니다** — 이 제품의 다른 모든 자리가 그렇듯이.

## 검사

살아 있는 모델 훑기에 넣었습니다 — 긴 노트를 가진 슬라이드를 실제로 다시 쓰게 하고,
**절반 넘게 사라졌는데 아무 말이 없으면 실패**합니다. 웹 쪽은 그 문장이 한국어로 옮겨지는지
고정했습니다.
