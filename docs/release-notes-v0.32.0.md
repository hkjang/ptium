# Ptium v0.32.0

## AI로 다듬기 — 덱 전체를 다시 씁니다

파일에서 가져온 덱, 급하게 쓴 덱에는 **맞는 사실이 틀린 방식으로** 들어 있습니다. 주제만 적은
제목, 문단이 되어 버린 요점, 무슨 말을 할지 아무것도 적혀 있지 않은 슬라이드. 지금까지 AI는
**한 장씩** 다시 쓰거나 브리프로 **새 덱을 만드는** 것뿐이었고, 후자는 다듬으려던 것을 버립니다.

편집기의 **AI로 다듬기**는 덱 전체를 모델에게 넘깁니다.

**그대로 두는 것 — 사실.** 모든 숫자·이름·주장이 바뀌지 않고 다시 나타납니다. 빈약한 슬라이드는
빈약한 채로 둡니다. 읽기 좋으라고 지어낸 숫자는 읽기 나쁜 슬라이드보다 나쁩니다.

**바꾸는 것 — 솜씨**

- 무엇을 **주장**하는지 말하는 제목 (무엇에 **대한** 것인지가 아니라)
- 제목을 되풀이하지 않는 리드 한 줄
- 한 가지씩만 담은 요점 — 문단도, 흐지부지한 조각도 아닌
- **표지를 제외한 모든 슬라이드에 발표자 노트**
- 덱이 이미 말하고 있는 숫자·순서·표를 지표·단계·표 컴포넌트로

**되돌릴 수 있습니다.** 이전 덱은 버전 이력에 남습니다. 되돌릴 수 없는 "다시 써 줄까요?"는
아무도 누르지 않습니다.

**AI 제공자가 없으면 거절하고 아무것도 바꾸지 않습니다.** 이것 하나만은 오프라인 작성기가
대신할 수 없습니다 — 브리프로 새 덱을 쓰면 다듬으려던 덱이 사라집니다.

### 실측 (자체 호스팅 122B 모델, 일부러 거칠게 쓴 덱)

| | 이전 | 다듬은 뒤 |
| --- | --- | --- |
| 제목 | "실적" · "문제점" · "계획" | "2025 4분기 실적은 신규 채널 확대로 12% 성장" |
| 긴 요점 | "매출은 1,240억으로 전년 대비 12% 증가하였으며 이는 신규 채널의 기여가 컸음" | 리드 한 줄 + 요점 세 개로 분리 |
| 숫자 | 1,240억 · 12% · 9.8% · 300억 · 420억 · 12명 | **전부 그대로** |
| 발표자 노트 | 0장 | **4장(표지 제외 전부)** |
| 측정 | — | **결함 0 · 다듬을 곳 1** |

프롬프트에서 노트를 "없는 슬라이드에 한 줄 추가하라"고 지나가듯 말했을 때는 **한 장도** 쓰지
않았습니다. "표지를 제외한 모든 슬라이드는 `!notes` 줄로 끝난다"는 **규칙**으로 적자 네 장
모두에 썼습니다. 프롬프트는 설득이 아니라 규격입니다.

```
409 nothing_to_rewrite | ai_provider_required
```
