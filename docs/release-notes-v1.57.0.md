# Ptium v1.57.0

**"누가 만들었나"가 전부를 보여 주는 것처럼 보였지만, 285개가 빠져 있었습니다.**

## 관리자 화면이 말하는 것과 담고 있는 것

사용 현황 화면의 숫자들이 서로 맞는지 재 봤습니다.

```
날짜별 합계   generated=4484  failed=52     ← 머리 숫자와 일치
```

날짜는 맞았습니다. 목록이 맞지 않았습니다.

```
누가 만들었나    화면에 보이는 합  4199  ·  실제 전체  4484  ·  말하지 않은 것  285
어떤 디자인으로   화면에 보이는 합  4385  ·  실제 전체  4484  ·  말하지 않은 것   99
실패한 이유     화면에 보이는 합    52  ·  실제 전체    52  ·  말하지 않은 것    0
```

세 목록은 모두 `LIMIT 8`(실패는 6)로 **가장 많은 몇 개**만 가져옵니다. 그런데 화면은
`누가 만들었나`라는 제목 아래 여덟 줄을 보여 줄 뿐, **그것이 일부라는 말이 어디에도
없습니다.**

운영자는 4,484개를 만들었다는 머리 숫자를 보고, 그 아래에서 4,199개까지만 세어지는
목록을 봅니다. 285개를 만든 사람들은 화면에 없고, 없다는 사실조차 없습니다.

## 남은 것을 함께 적습니다

목록과 머리 숫자는 **같은 기간, 같은 조건**으로 세므로 차이가 곧 빠진 몫입니다.
서버가 그 몫을 함께 내주고, 화면이 마지막 줄로 적습니다.

```
누가 만들었나              가장 많은 8개입니다. 나머지는 아래에 함께 적었습니다.
   Ptium Developer                                    2,134
   …
   ─────────────────────────────────────────────────────
   그 밖의 전부   이 목록에 이름이 없는 것들              285
```

빠진 것이 없으면 그 줄도 없습니다 — 실패 목록은 52개를 전부 담고 있으므로 그대로
둡니다.

## 함께 확인하고 문제가 없던 것

* **날짜별 합계 = 머리 숫자** — generated 4484, failed 52, 양쪽 일치
* **정리할 것 화면** — 아무것도 삭제하지 않고 그렇게 적혀 있습니다. 숫자는 판단을
  위한 것이라고 화면 스스로 말합니다
