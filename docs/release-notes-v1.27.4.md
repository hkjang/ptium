# Ptium v1.27.4

API 키 화면의 **만료** 열은 "이 키가 언제부터 안 되는가"를 답하는 자리입니다.
**정작 곧 죽는 키에 대해 "만료 없음"이라고 적고 있었습니다.**

## 회전 유예 중인 키

키를 회전하면 예전 키는 **유예 기간 동안만** 계속 동작합니다(기본 24시간). 예전 키에는
자기 만료일이 없고 **유예 종료 시각(`graceUntil`)** 이 있습니다. 화면은 만료일만 읽었고,
없으니 이렇게 적었습니다 —

```
이름                        상태            만료
유예 표시 점검              회전 유예 중     만료 없음      ← 내일 02:22에 멈춥니다
```

예전 키를 아직 쓰고 있는 작업은 **아무도 화면에서 읽을 수 없었던 시각에** 실패합니다.

## 먼저 오는 쪽을 적습니다

```
유예 표시 점검              회전 유예 중     2026년 8월 28일 유예 종료
```

만료일과 유예 종료가 둘 다 있으면 **먼저 오는 쪽**을 적습니다. 그것이 키가 실제로
멈추는 때입니다.

서버는 이 값을 원래부터 답하고 있었습니다(`graceUntil`) — 화면이 읽지 않았을 뿐입니다.

## 확인한 것들 (문제 없었습니다)

같은 자리를 재는 김에 회전 전체를 확인했습니다.

- 유예 중 **예전 키와 새 키가 모두 동작**하고, 유예가 끝나면 예전 키만 멈춥니다.
- 예전 키는 **목록에서 숨겨지지 않습니다** — 유예 종료 시각과 함께 그대로 보입니다.
- 새 키를 폐기해도 예전 키는 유예가 끝날 때까지 살아 있습니다. 목록에 보이므로
  바로 폐기할 수 있습니다.

## 검사

화면 훑기가 키를 만들어 회전시킨 뒤 그 줄을 읽습니다 — "만료 없음"이면 실패하고,
유예 종료 시각이 없어도 실패합니다. 되돌려 보면 잡습니다.
