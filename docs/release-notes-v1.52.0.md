# Ptium v1.52.0

**줄글 브리프의 표지가 문장 중간에서 끊기지 않습니다.**

## 지난 릴리스에서 못 고쳤다고 적은 것

1.51.1에서 "줄글 브리프의 제목을 더 낫게 뽑는 것은 세 번 시도해 세 번 다 되돌렸다"고
적었습니다. 세 번 모두 같은 이유로 틀렸습니다 — **규칙에 넘겨 준 문장이 이미 다시 쓰인
뒤의 것**이었습니다. 장수도 빠지고 요청도 빠진 뒤라 읽을 문장이 남아 있지 않았습니다.

이번에는 **사용자가 친 그대로의 브리프**를 따로 들고 있다가 규칙에 넘겼습니다.

```
전:  '우리 회사는 내년에 클라우드 비용을 크게 줄여야'
후:  '내년에 클라우드 비용'

전:  '데이터 거버넌스 체계를 세우'
후:  '데이터 거버넌스 체계'
```

한국어 줄글은 무엇에 관한 글인지 먼저 말하고 그 다음에 그것에 대해 말합니다. 그래서
**문장 첫머리부터 첫 조사까지**를 읽습니다. "우리 회사는" 처럼 누구 덱인지만 말하는
구절은 건너뛰고 다음으로 넘어갑니다.

## 요청형 브리프는 하나도 건드리지 않습니다

이 수리는 **잘린 제목이 나왔을 때만** 작동합니다. 요청형 브리프 10개로 확인했고 전부
그대로입니다:

```
사내 PostgreSQL 전환 타당성 검토 결과 · 위험은 무엇인가 · 채용 계획 / 교육 계획 /
평가 제도 개편 · 클라우드 비용 최적화 3개년 로드맵 · 보고 체계 개선 방안
```

작업 중 `위험은 무엇인가` 가 `위험` 으로 잘리는 회귀를 만들었는데, **앞선 반복에서
넣어 둔 테스트가 정확히 그것을 잡았습니다.** 질문형 어미(`인가`·`는가`)는 잘린 조사가
아니라고 규칙에 적어 고쳤습니다.

## 아직 못 고치는 것

여섯 개 줄글 브리프 중 **둘이 고쳐졌고 넷은 그대로**입니다.
`사내 데이터 품질 개선이 필요한 이유는 여러 가지` 처럼 명사로 끝나 잘렸는지 알 수 없는
경우는 잡지 못합니다. `평가`·`국가` 같은 멀쩡한 낱말을 잘린 것으로 오인하지 않으려면
여기서 멈추는 편이 맞습니다.
