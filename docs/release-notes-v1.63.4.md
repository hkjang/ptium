# 1.63.4 — 화면도 같은 답을 합니다

없는 장을 가리키는 점프에 대해 제품이 세 가지로 답하고 있었습니다.

- 내보낸 `.pptx` — 링크를 쓰지 않습니다 (1.63.1).
- 인쇄한 PDF — 주석을 쓰지 않습니다 (1.63.3).
- **화면 — 링크 색에 밑줄까지 그려 놓고, 눌러도 아무 데도 가지 않았습니다.**

세 장짜리 덱에서 `[9장 참고](#9)` 는 편집 화면, 발표 화면, 공유 링크 모두에서
눌러도 되는 것처럼 보였습니다. 발표 화면에서는 아무 일도 일어나지 않고, 공유
화면에서는 마지막 장으로 데려갔습니다.

- 그리는 쪽이 덱의 장 수를 알고, 없는 장을 가리키는 점프는 **글자 그대로**
  그립니다. 글자는 그대로 남고, 링크 색과 밑줄과 누를 수 있음만 없어집니다.
  글머리 줄이든 표의 칸이든 같습니다.
- 있는 장을 가리키는 점프는 그대로 링크입니다.
- 공유 화면에서 없는 장을 가리키는 점프는 이제 **아무 데도 가지 않습니다.**
  마지막 장으로 데려가는 것은 "당신이 가려던 장이 여기입니다" 라고 거짓을
  말하는 일입니다.
- 레이아웃 하나만 미리 보는 화면처럼 덱의 크기를 모르는 자리는 예전과 똑같이
  그립니다.

이제 파일, 종이, 화면 셋이 같은 말을 합니다. 그리고 측정은 예전처럼 어느 줄이
그런지 알려 줍니다.

## 확인

- 세 장짜리 덱의 미리보기와 공유 화면 SVG 에 `#slide-3` 만 남고 `#slide-9` 는
  없으며, "9장 참고" 라는 글자는 그대로인 것을 확인했습니다. 표의 칸도 같습니다.
- 고침을 되돌려 `#slide-9` 가 다시 링크로 그려지는 것을 확인했습니다.
