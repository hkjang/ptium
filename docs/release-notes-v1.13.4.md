# Ptium v1.13.4

감사 기록을 **가지고 나갈 수 있게** 했습니다. 그리고 그걸 만들다 필터의 결을 하나 고쳤습니다.

## 파일로 내려받기

감사인이 요구하는 것은 화면이 아니라 파일입니다. `관리자 → 감사 기록` 에 **CSV로 내려받기**
가 생겼습니다 — **화면의 조건이 그대로** 적용됩니다(기간·동작·검색).

- 스프레드시트가 한글을 깨뜨리지 않도록 바이트 순서 표시를 앞에 붙입니다
- 서버는 500행씩 읽어 곧바로 흘려보냅니다. 한 해치를 손에 다 쥐고 건네는 방식은 보고서
  하나가 서버를 데려가는 방법입니다
- 브라우저는 세션 헤더를 실어 받아옵니다. 새 탭으로 여는 방식은 쿠키만 들고 가므로,
  토큰이나 개발 비밀을 쓰는 배포에서는 받아지지 않습니다

## 동작 이름은 점에서 끊깁니다

필터에서 `presentation.create` 를 고르면 `presentation.create_and_generate` 까지 딸려
왔습니다. 접두 일치였기 때문입니다.

이제 **자기 자신이거나, 점 뒤에 무언가가 더 붙은 것**만 맞습니다:

- `presentation` → 덱과 관련된 모든 기록
- `presentation.create` → 생성만

## 사용자에서 그 사람의 기록으로

`관리자 → 사용자` 에서 한 사람을 열면 **"이 사용자의 기록"** 이 있습니다. 감사 기록 화면이
그 주소로 열리고 필터가 채워져 있습니다.

## 확인

- 저장소 테스트가 경계 규칙을 잡습니다: 한 가족과 그중 하나를 각각 세고, 접두 일치로
  되돌리면 뭅니다
- 스윕이 파일 계약을 지킵니다: 첨부로 오는지, 바이트 순서 표시가 있는지, 표로 읽히는지,
  **화면의 필터가 파일에도 적용되는지**, 그리고 관리자 역할 없는 계정은 403 (319 checks)

## 스윕의 경쟁을 하나 고쳤습니다

큐 검사가 중단 후 상태를 **폴링**해서 읽고 있었습니다 — 작성기와 경주가 되어 가끔 자기가
만든 경쟁을 결함으로 보고했습니다. 중단은 이미 **멈춘 덱을 응답으로 돌려주므로**, 그것을
읽습니다. 두 번 연속 0 failures.
