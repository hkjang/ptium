# Ptium v1.24.2

어제 "심어 둔 기본값은 칠하지 않는다"를 넣었습니다. 그런데 그건 **앞으로 만들 덱** 이야기였습니다.

## 이미 만들어 둔 덱은 여전히 칠해지고 있었습니다

이 배포에 있는 덱을 열어 봤습니다.

```
심어 둔 색(#7C3AED)을 슬라이드에 갖고 있는 덱: 8개
그 색으로 지금 그려지는 덱: 2개      ← 몇 달 전에 만든 덱인데
```

색은 **슬라이드마다 저장되어 있습니다.** 어제 고친 것은 "새로 만들 때 그 값을 쓰지 않는다"
였을 뿐, **이미 저장된 값은 그대로 남아** 그림이 읽습니다. 그래서 예전에 만든 덱을 다시 열거나
내보내면 **회사 템플릿의 색이 보라색으로 바뀝니다.**

## 그리는 자리에서 막습니다

이제 **그림이 그 색을 만나면 무시합니다.** 저장된 값이 무엇이든, 심어 둔 색은 아무도 고른 적이
없으므로 템플릿의 색이 그대로 남습니다. 데이터는 건드리지 않았습니다 — 지우지 않아도 됩니다.

```
같은 덱 8개, 다시 확인: 그 색으로 그려지는 덱 0개   ← 템플릿 그대로
```

이 색을 **일부러 고른 사람**은 템플릿의 강조색을 쓰게 됩니다. 남의 덱을 전부 다시 칠하지
않기 위한 값입니다.

## 왜 이틀 연속인가

색 하나가 **모든 덱의 모든 컴포넌트**에 닿습니다. 어제는 "새로 만드는 덱"을 봤고, 오늘은
**"이미 있는 덱"** 을 봤습니다 — 고친 다음 날 실제로 열어 보지 않으면 알 수 없는 자리입니다.

## 검사

그리는 자리에서 심어 둔 색이 템플릿을 덮지 않는지 고정했습니다. 되돌리면 그 자리에서
실패합니다. 앞선 네 가지(고른 색 · 배포가 고른 색 · 개인 색 · 아무것도 없음)도 그대로입니다.
