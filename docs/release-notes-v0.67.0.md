# Ptium v0.67.0

지난 판에서 발견해 둔 것을 정리했습니다: **사용자에게 나가는 API 오류 문구가 전부 영어**였습니다.

## 토스트가 영어로 말하고 있었습니다

덱을 내보내려다 실패하면 이렇게 떴습니다.

```
Generate or add slides before exporting
The presentation changed in another session
The server could not complete the request
```

API가 영어로 답하는 것은 맞습니다 — 요청 로그를 보는 사람과 API로 직접 개발하는 사람이 읽는
문장이기 때문입니다. 하지만 워크스페이스에 있는 사람은 그 언어를 고른 적이 없고, 그 문장이
**토스트로 눈앞에 뜹니다.**

측정 결과(v0.46~) · 컴파일 경고(v0.64)에 한 것과 같은 처리를 했습니다.

```
내보내려면 먼저 슬라이드를 만들어 주세요.
다른 곳에서 이 덱이 먼저 바뀌었습니다. 새로고침한 뒤 다시 시도해 주세요.
서버가 요청을 처리하지 못했습니다. 관리자에게 오류 센터를 확인해 달라고 요청하세요.
```

- **서버가 보낸 문장**을 열쇠로 씁니다. 49가지를 다시 썼습니다.
- 목록에 없는 문장이면 **오류 코드**로 물러섭니다(`validation_error` → "입력한 값이 올바르지
  않습니다").
- 코드도 모르면 **온 그대로** 보여 줍니다. 어설프게 고친 문장보다 낫습니다.
- **서버는 그대로입니다.** API 응답은 계속 영어이고 코드도 그대로라, API로 개발하는 쪽과
  요청 로그를 읽는 쪽은 달라지는 게 없습니다.

브라우저로 확인했습니다: 없는 덱을 열면 `요청한 항목을 찾을 수 없습니다.`
