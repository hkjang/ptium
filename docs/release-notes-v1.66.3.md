# 1.66.3 — 1.66.2 가 설명만 담고 코드를 빠뜨렸습니다

1.66.2 의 "장과 장을 견줄 때는 제목이 아니라 말한 것만 본다" 는 **주석만 들어
있고 코드가 빠져 있었습니다.** 손으로 되돌렸다 되살리는 과정에서 설명은
돌아오고 세 줄이 돌아오지 않았습니다.

배포 이미지에서 확인하다가 잡았습니다. 브리프 하나로 생성한 덱이 여전히 "앞 장과
같은 내용" 으로 보고되었고, 어느 줄이 걸린 것인지 끝까지 따라가 보니 걸린 것은
**두 장의 제목**이었습니다 — 1.66.2 가 막았다고 적어 둔 바로 그것입니다.

## 왜 시험이 잡지 못했나

1.66.2 에 넣은 시험은 코드가 없어도 통과했습니다. 시험에 쓴 덱은 겹치는 줄이
하나뿐이어서, 이 규칙이 요구하는 "두 줄 이상, 그리고 그 장의 절반 이상" 에
닿지 않았습니다. **이가 없는 시험이었습니다.**

실제로 걸렸던 덱을 그대로 옮겨 왔습니다 — 제목이 주제를 되풀이하고, 비교
컴포넌트의 한 항목이 그 주제를 다시 말하는 네 줄짜리 장. 이제 코드를 빼면 시험이
무너집니다.

## 확인

- 같은 브리프로 여덟 번 생성해 여덟 번 모두 측정이 깨끗한 것을 확인했습니다.
- 코드를 빼면 시험이 실패하는 것을 확인했습니다 (1.66.2 에서는 통과했습니다).
- 같은 내용을 두 장에 옮긴 덱은 그대로 보고됩니다.
