# Ptium v1.12.2

## 덱 전체 다시 쓰기에 **무엇을 바꿀지** 적을 수 있습니다

**AI로 다듬기**는 지금까지 예/아니오였습니다. 눌러 놓고 무엇이 좋아질지는 모델이 정했습니다 —
남의 덱을 두고 제품이 판단하는 셈입니다. 슬라이드 하나에 대한 자유 지시는 이미 있었으니,
사람은 **한 장씩 열어 말해야** 했습니다.

이제 누르면 적는 칸이 나옵니다.

> 3장은 요점 3개로 줄이고, 5장에 비용 비교 표를 넣어 주세요.

**그것만 바뀝니다.** 요청이 건드리지 않은 장은 제목·요점·컴포넌트·노트까지 그대로 둡니다.
비워 두면 예전처럼 덱 전체를 다듬습니다 — 아무 말 없이 누르는 것도 여전히 요청입니다.

실제 모델(122B)로 확인했습니다:

```
"현황 장은 요점 3개로 줄이고 나머지는 그대로 두세요"
   현황: 5개 → 3개      계획: 2개 → 2개      마무리: 1개 → 1개      결함 0 · 권고 0
```

`POST /presentations/{id}/rewrite` 에 `{"instruction": "…"}` 로도 같습니다(최대 2,000자).
지시는 덱에 저장됩니다 — 큐에 들어간 뒤 작업자가 집어 갈 때까지 기다려야 하니까요.

## 만들면서 제가 낸 버그 하나

한글 지시를 보냈는데 **무시**됐습니다. 원인은 제가 넣은 **8KB 본문 제한**이었습니다:
한글 2,000자는 JSON 이스케이프를 거치면 12,000바이트가 넘어 디코더가 중간에서 끊겼고,
**그 오류를 제가 무시하고 있어서** "지시 없음"으로 처리됐습니다.

- 제한을 64KB 로 올렸습니다
- **읽지 못한 본문은 읽지 못했다고 답합니다**(`invalid_json`). 조용히 빈 요청으로 바꾸지
  않습니다 — 이번 일이 정확히 그것 때문이었습니다
- 요청 검증을 **제공자 확인보다 먼저** 합니다. 잘못된 요청은 배포 상태와 무관하게 잘못된
  요청입니다
