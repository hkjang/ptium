# Ptium v1.56.0

**파워포인트에서 가져온 차트가 "무엇의 숫자인지"를 잃어버렸습니다.**

## 밖에서 만든 파일을 가져와 봤습니다

파워포인트가 직접 쓴 파일을 만들어 넣었습니다 — 자리표시자, 세 단계 목록, 표,
발표자 노트, 자리표시자가 아닌 글상자, 묶인 도형, 사진, 하이퍼링크.

```
원본의 문자열 23개 중 23개가 남았습니다
제품이 말한 것:
   · 그림 1개를 이미지 라이브러리에 저장했습니다
   · 그 가운데 0개를 슬라이드에 넣었습니다. 나머지 1개는 …
   · 표 1개를 이 덱의 디자인으로 다시 그렸습니다
```

60장짜리 파일도 넣어 봤습니다. 50장만 들어오고, **그 사실을 말했습니다** —
"이 배포는 한 덱에 50장까지 허용하므로 그 뒤는 가져오지 않았습니다".

차트에서 하나가 걸렸습니다.

## 계열 이름 하나가 사라졌습니다

`매출` 한 계열, `1분기·2분기·3분기` 세 항목짜리 세로 막대 차트를 넣었습니다.

```
::columns              ← 가져온 소스
- 1분기 | 12
- 2분기 | 15.5
- 3분기 | 19.2
::
```

**`매출`이 어디에도 없습니다.** 항목은 *언제*를, 점은 *얼마*를 말하지만, *무엇의*
숫자인지는 계열 이름 한 곳에서만 말합니다. 그것이 사라지면 이름 없는 숫자 세 개가
남습니다. 제품은 "차트 1개를 **숫자째** 가져와 다시 그렸습니다"라고 말했고, 숫자는
정말 가져왔습니다 — 다만 이름은 아니었습니다.

**계열이 둘 이상이면 멀쩡했습니다.** 표로 바뀌면서 계열 이름이 행 이름이 됩니다.
꺾은선도 각 선의 이름을 지킵니다. **계열이 하나인 갈래만** 떨어뜨리고 있었습니다.

## 양쪽 끝이 서로 다른 칸을 보고 있었습니다

가져오기는 이름을 아예 쓰지 않았고, 내보내기는 `block.Heading`을 읽는데 **제품 안에
그 칸을 채우는 곳이 없었습니다** — 소스는 구성요소의 라벨을 `Caption`으로 적습니다.
그래서 계열이 하나인 차트는 작성자가 아무리 이름을 붙여도 언제나 `값`으로
나갔습니다.

둘 다 고쳤습니다. 이제 처음부터 끝까지 이어집니다.

```
파워포인트 파일  →  ::columns 매출  →  내보낸 파일의 계열 이름: ['매출']
```

이름이 없는 계열은 여전히 이름을 지어내지 않고, 덱이 끝내 말하지 않았을 때만 `값`
이라고 적습니다.
