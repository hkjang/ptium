# Ptium v1.11.4

## PDF · 발표자 노트 (유인물)

내보내기에 줄이 하나 늘었습니다. **한 장에 슬라이드 하나, 그 아래에 그 장에서 할 말.**

리허설할 때, 또는 **대신 발표할 사람에게 넘길 때** 필요한 문서입니다. 지금까지는 덱을 주고
노트는 파워포인트를 열어서 보라고 해야 했습니다.

- 슬라이드는 **비율 그대로** 62% 로 줄여 위쪽에 놓고 얇은 테두리를 둘렀습니다. 16:9 을
  잘라서 글자 자리를 넓히면 그건 다른 덱을 인쇄하는 것입니다
- 그 아래에 `2 · 근거 — 발표자 노트` 처럼 몇 장인지와 제목을 적고, 노트를 폭에 맞춰
  줄바꿈해 넣습니다. **글꼴을 실제로 재서** 접기 때문에 한글과 영문이 같은 규칙으로 접힙니다
- 노트가 없는 장도 **페이지는 나옵니다** — "적어 둔 말이 없습니다". 장 번호가 덱과 어긋나면
  유인물로 쓸 수 없으니까요
- 아주 긴 노트는 종이 끝에 닿기 전에 `…` 로 끊습니다
- 줄인 슬라이드 위의 **링크도 그대로 눌립니다** (주석 위치를 같이 옮깁니다)

`GET /presentations/{id}/export?format=pdf&notes=true` 로도 같습니다.

## 만들면서 확인한 것

- 링크가 있는 장의 유인물에서 링크 영역이 줄인 슬라이드 안에 정확히 들어가는지 좌표로 확인
- 120번 반복한 긴 노트가 아래 여백을 침범하지 않는지 확인(마지막 줄 y=26 → 여백 안쪽으로 조정)
- 브라우저에서 두 PDF 를 실제로 내려받아 확인:
  `PDF 내려받기.pdf`, `PDF 내려받기 (발표자 노트).pdf`
