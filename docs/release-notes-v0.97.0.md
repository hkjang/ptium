# Ptium v0.97.0

지난 판에서 **바이트로 세던 길이 비율** 을 찾았습니다(한글 3바이트, 숫자 1바이트). 같은 실수가
더 있는지 코드 전체를 뒤졌습니다.

바이트로 세는 비율은 더 없었고, 문자열을 바이트로 자르는 곳도 없었습니다. 대신 **글자 수로
세는 판단 두 개** 가 나왔습니다. **옷만 갈아입은 같은 실수** 입니다.

## 단 이름: "24글자 이하"

한국어로는 구(句), 영어로는 문장 절반입니다.

| 문구 | 글자 수 | 그리면 |
|---|---|---|
| `2주 집중 교육을 통한 업무 숙달 가속화` | 22자 | **17.2 em** |
| `Implementation and rollout timeline` | 35자 | **15.7 em** |

**영어 쪽이 글자는 더 많고 폭은 더 좁습니다.** 그래서 영어 덱은 컴파일러가 단 이름으로
읽어 주지 않는 이름 쌍을 쓸 수 있었습니다.

## 컴포넌트 값: "6글자 이하면 숫자"

| 값 | 글자 수 | 그리면 | 판정(이전) |
|---|---|---|---|
| `1억 5천만 원` | 8자 | 5.7 em | 문장 취급 ✗ |
| `240,000 USD` | 11자 | 5.9 em | 문장 취급 ✗ |
| `개발/운영 분리` | 8자 | 6.8 em | 문장 ✓ |

둘 다 **숫자인데** 문장 취급을 받아 2열 표로 다시 그려지고 있었습니다.

## 이제 둘 다 그려지는 폭으로 잽니다

측정 함수 하나를 밖으로 내어 두 판단이 같은 자를 씁니다.

- **18 em** — 두 언어가 여기서 만들어 낸 모든 단 이름보다 넓고, 모든 문장보다 좁습니다
- **6 em** — 모든 숫자보다 넓고, 카드 밖으로 넘치던 문구들보다 좁습니다

## 설치

오프라인 설치 방법은 [docs/offline-deployment.md](offline-deployment.md) 를 보세요. 이미지에
Postgres 와 nginx 는 들어 있지 않습니다 — 배포할 때 `DATABASE_URL` 로 DSN 을 지정합니다.
