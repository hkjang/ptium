# Ptium v0.58.0

이번 판은 **측정기를 고쳤습니다.** 잘못 잡아내는 것을 그대로 두면, 점수는 좋은 덱을 깎고 사람은
점수를 무시하게 됩니다.

## 꺾은선 차트마다 "겹침"이 보고되고 있었습니다

x축의 `3월` `4월` 은 눈금 사이 간격 가운데에 놓입니다. 그래서 **글자 상자**는 7cm 폭인데
글자는 두 자입니다. 상자끼리는 49% 겹치고, 글자끼리는 전혀 겹치지 않습니다.

검사기는 상자를 재고 있었습니다. 결과: 추이 차트가 있는 슬라이드마다 `두 줄이 겹칩니다` 가
붙고, **점수가 84점에서 54점으로** 떨어졌습니다. 덱에서 가장 잘 만든 슬라이드가 가장 나쁜
슬라이드로 보고되고 있었던 것입니다.

이제 **잉크**를 잽니다 — 가장 긴 줄의 실제 너비, 가로 정렬(왼쪽 · 가운데 · 오른쪽)까지 반영해서.
지난 판에 세로로 한 것과 같은 계산입니다. 진짜로 겹치는 글자는 그대로 잡힙니다.

## 표지에 "이 연도는 어디서 나왔습니까"를 묻고 있었습니다

표지의 `2026년 상반기` 가 **숫자 주장**으로 읽혀서, 출처 없음이 보고됐습니다. 연도는 주장이
아니라 날짜입니다. 그리고 표지와 구역 페이지는 애초에 논지를 펴는 자리가 아닙니다.

두 가지를 고쳤습니다 — 날짜는 숫자로 세지 않고, 출처 질문은 **논지를 펴는 슬라이드에만**
합니다. `2026년 매출은 1,240억` 은 여전히 묻습니다.
