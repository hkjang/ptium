# Ptium v1.11.9

## 업그레이드도 릴리즈 전에 실제로 해 봅니다

지난 릴리즈에서 "빈 데이터베이스에 이미지를 띄워 보는" 검사를 넣었습니다. 그건 배포 **첫날**
입니다. 그 뒤의 모든 날은 다릅니다 — 이미 덱이 들어 있는 데이터베이스에 새 이미지를 올리는
것이고, 그때 실제로 돌아가는 것은 **마이그레이션** 입니다.

이제 빌드가 그것도 합니다. **가장 오래된 릴리즈 이미지(0.1.0)** 로 데이터베이스를 만들고 덱을
하나 생성한 뒤, 새 이미지를 그 위에 올려 확인합니다.

```
── ptium:0.1.0 wrote it, ptium:1.11.9 opens it ──
   ptium:0.1.0 made a deck: completed, 5 slide(s)
   after the upgrade: 예전 버전에서 만든 덱 · 5 slide(s) · completed
   measured: 0 defect(s), 0 advisory(ies)
   exported and drawn · source 30 lines
```

**200 릴리즈 전에 만든 덱** 이 그대로 열리고, 슬라이드 5장이 그대로 있고, 측정에 결함이 없고,
pptx·PDF·유인물로 나가고, 원본 코드가 30줄로 읽히고, 그림이 그려집니다. 마이그레이션 56개가
지나간 뒤입니다.

호스트에 예전 이미지가 없으면(새로 클론한 곳) **스스로 건너뜁니다** — 돌릴 수 없는 검사는
실패가 아니라 그렇다고 말해야 합니다.

## 그밖에 확인된 것

- 예전 버전이 심어 둔 템플릿 30개가 업그레이드 후 **50개** 가 됩니다(새 기본 템플릿이 추가
  시드됨). 기존 것이 지워지지 않습니다

## 설치

```bash
gzip -dc ptium-1.11.9.tar.gz | docker load
```
