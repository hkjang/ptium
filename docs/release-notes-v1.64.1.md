# 1.64.1 — 이미 써 둔 사진 설명을 가져옵니다

지난 판에서 설명 없는 사진을 묻기 시작했습니다. 그런데 파워포인트에서 이미
설명을 써 둔 사람에게도 똑같이 물었습니다. 가져올 때 그 설명을 버리고 있었기
때문입니다.

사진의 대체 텍스트는 슬라이드를 아무리 들여다봐도 다시 쓸 수 없는 것입니다.
그림 파일과 크기는 그림에 들어 있지만, 그 그림이 무엇을 보여 주는지는 쓴
사람만 압니다.

- 가져올 때 그림의 대체 텍스트를 함께 읽어 `::image 이름 | 설명` 으로
  덱의 소스에 남깁니다. 다시 내보내면 파워포인트 파일에 그대로 들어갑니다.
- 설명이 있는 사진은 이제 아무것도 묻지 않습니다.
- **파일 이름은 설명이 아닙니다.** 파워포인트를 비롯해 덱을 만드는 거의 모든
  도구가, 아무도 설명을 쓰지 않으면 그 자리에 파일 이름을 넣어 둡니다
  (`image.png`, `다운로드.jpg`). 그것을 가져오면 설명 자리에 파일 이름이
  들어앉고, 더 나쁘게는 제품이 진짜 설명을 묻지 않게 됩니다. 공백 없이
  이미지 확장자로 끝나는 이름은 설명으로 치지 않습니다. "보고서 표지
  image.png 를 다시 쓴 것" 처럼 말이 섞인 것은 설명입니다.

## 확인

- 파워포인트에서 대체 텍스트를 써 넣은 파일을 만들어 올리고, 그 문장이 덱의
  소스에 오고 → 측정이 조용하고 → 다시 내보낸 파일에 `descr` 로 들어가는
  것까지 한 바퀴 확인했습니다.
- 파일 이름이 대체 텍스트 자리에 있는 사진은 설명이 없는 것으로 보고, 예전처럼
  묻는 것을 확인했습니다.
- 고침을 되돌려 설명이 다시 사라지는 것을 확인했습니다.
