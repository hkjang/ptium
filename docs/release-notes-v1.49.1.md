# Ptium v1.49.1

**60 MB 파일을 올린 사람이 들은 말: "업로드한 파일을 읽지 못했습니다."**

## 남은 문을 마저 확인하다가

1.48.1은 템플릿 읽기를, 1.49.0은 인쇄를 막았습니다. 같은 크기 한도(최대 64 MB)를
쓰는 문이 하나 더 있습니다 — **덱 가져오기**. 동시에 여러 개를 넣어 봤습니다.

```
19 MB × 8 동시  →  8개 모두 성공 · 최대 582 MiB
```

죽지 않습니다. 그런데 그 다음 시험에서 다른 것이 나왔습니다.

## 한도를 넘긴 파일이 이유를 듣지 못했습니다

32 MB까지 받는 배포에 60 MB 파일을 올리면:

```
이전:  400  {"code":"invalid_upload","message":"The upload could not be read",
             "details":{"reason":"http: request body too large"}}
```

제품 안에는 **제대로 된 답이 이미 있었습니다** — `413 The template must not
exceed 32 MiB`. 그런데 한도를 지키는 리더가 **그 검사보다 먼저** 걸리기 때문에,
정말로 큰 파일에서는 그 답에 영영 도달하지 못했습니다. 좋은 문장을 써 두고 아무도
읽을 수 없는 자리에 둔 셈입니다.

```
지금:  413  {"code":"template_too_large","message":"The upload must not exceed 32 MiB",
             "details":{"limitBytes":33554432}}
```

템플릿 문과 가져오기 문 **둘 다** 같은 리더를 쓰므로 둘 다 고쳐졌습니다. 화면에서도
`파일이 이 배포에서 허용하는 크기를 넘습니다` 로 보이고, 1.48.1·1.49.0에서 추가된
`templates_busy`·`printing_busy` 도 한국어로 옮겼습니다.

## 확인

- 1.49.0 배포 이미지에서 사진 40장짜리 덱 **16개 동시 인쇄 → 16개 모두 성공**
- 두 문에 60 MB 업로드 → 둘 다 `413` 에 한도 명시
- 크기 때문이 아닌 실패는 예전 답을 그대로 유지합니다
