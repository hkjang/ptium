# Ptium v0.61.0

지난 판 릴리스 노트에 적어 둔 것 — "스무 장을 요청해도 아홉 장이 나옵니다" — 을 파고들었더니,
문제는 **장수가 아니라 침묵**이었습니다.

## 생성기는 이유를 말하고 있었습니다. 아무도 듣지 못했을 뿐입니다

코드는 이미 이렇게 적고 있었습니다.

> 20장을 요청받아 9장을 썼습니다. 브리프가 다루는 주제가 1개라 더 늘리면 페이지를 되풀이하게 됩니다.

이 문장은 **서버 로그로만** 갔습니다. 스무 장을 요청하고 아홉 장을 받은 사람은 아무 설명도 듣지
못했습니다. 로그를 읽을 수 있는 사람과 이유를 알아야 하는 사람은 다른 사람입니다.

이제 **덱과 함께 저장되고**(`generation_notes`), API가 돌려주고(`generationNotes`), 편집기
맨 위에 뜹니다. 읽고 닫으면 사라집니다.

**요청한 사람의 언어로 씁니다** — 한국어 · 영어 · 일본어 · 중국어. 그리고 **그 사람이 할 수 있는
일까지 말합니다**: "주제를 더 적어 주시면 그만큼 늘어납니다."

기술적인 경고(어느 레이아웃이 무엇을 못 담았는지)는 계속 로그와 소스 편집기에 남습니다.
요청한 것과 다른 결과가 나왔을 때만 화면에 올라옵니다.

**장수 자체는 그대로 둡니다.** 한 줄짜리 브리프로 스무 장을 정직하게 만들 방법은 없습니다.
채우는 것보다 말하는 편이 낫습니다.

## 그러다 마무리 슬라이드에서 문장 하나가 사라지는 것을 봤습니다

`다음 단계` 슬라이드에는 리드 한 줄과 요청 세 가지가 있었습니다. 그런데 그려진 슬라이드에는
**요청 세 가지만** 있었습니다.

마무리 레이아웃에는 본문 영역이 없어 요점이 부제 자리로 갑니다. 그 자리에는 이미 리드가 있었고,
코드가 **덮어썼습니다**. 덱 전체에서 가장 잃으면 안 되는 슬라이드에서, 무엇을 요청하는지 말하는
문장이 사라진 것입니다.

이제 리드 아래에 요점이 이어집니다.

## 확인

- Go 전 패키지 통과. 마무리 슬라이드 회귀 테스트는 **고치기 전에 실패**하는 것을 확인했습니다.
- 프런트 30건, api 87 · edges 32 · package · flows 0 실패.
- 실제 생성 → 편집기 화면에서 안내 문구가 뜨는 것까지 확인했습니다.
