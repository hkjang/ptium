# Ptium v1.19.2

이번엔 **부탁하는 말을 실제로 사람들이 쓰는 대로** 여러 가지로 써 봤습니다. 여덟 가지 중
**다섯 가지가 안 됐습니다.**

## 부탁을 지시로 착각해 먼저 지워 버리고 있었습니다

| 브리프 | 어제 나온 슬라이드 제목 |
| --- | --- |
| `Q&A 슬라이드 추가해줘` | **Q&A 슬라이드 추가** |
| `경쟁사 비교 장을 만들어 주세요` | **경쟁사 비교 장** |
| `부록 슬라이드도 부탁해` | **부록 슬라이드도** |
| `요약 슬라이드 넣기` | **요약 슬라이드 넣기** |
| `예산 장 하나 만들어줘` | **예산 장 하나** |

원인은 **순서**였습니다. `만들어 줘` · `부탁해` 같은 말은 "이건 지시문이니 주제에서 빼라"는
규칙이 먼저 지웁니다. 그러고 나면 `Q&A 슬라이드 추가해줘` 는 부탁이 아니라 그냥
`Q&A 슬라이드 추가` 라는 말이 됩니다 — **부탁하는 말과 지시하는 말이 같은 단어**라서 생긴 일입니다.

이제 **부탁을 먼저 읽고** 지시를 지웁니다. 여덟 가지 전부, 영어 세 가지도 됩니다.
`넣기` · `포함시켜` · `부탁드립니다` 처럼 빠져 있던 말도 넣었습니다.

## 길이는 여전히 길이입니다

순서를 바꾸니 `세 장을 넣어줘` 가 부탁처럼 보이기 시작했습니다 — `클라우드 전환 계획을 세 장을
넣어줘` 가 **"클라우드 전환 계획을 세" 라는 장**을 만들고 주제를 통째로 잃었습니다.

**몇 장인지를 가장 먼저 읽습니다.** 길이는 길이고, 그 다음이 부탁입니다.

## 덤으로: 표지에 조사가 남아 있었습니다

`2026년 상반기 실적을 이사회에 보고하는 자료로 만들어 주세요` 의 표지 제목은
**`2026년 상반기 실적을 로`** 였습니다. 청중("이사회에 보고하는 자료")을 걷어내면서
**`자료` 는 가져가고 `로` 는 두고 갔기** 때문입니다. 이번 판과 무관하게 예전부터 그랬고,
같이 고쳤습니다 → `2026년 상반기 실적`.

## 검사

부탁하는 말 **9가지**(한국어 7 · 영어 2), **길이를 부탁처럼 쓴 경우**, **조사만 남는 경우**를
각각 고정했습니다. 되돌리면 순서 문제는 네 곳, 길이는 두 곳, 조사는 한 곳에서 잡힙니다.
