# Ptium v0.53.0

편집기 분해를 이어 가되, 이번에는 **어디까지 떼어낼지**를 먼저 정했습니다.

## 저장 상태 기계는 그대로 두었습니다

저장 로직은 열 개 남짓한 상태 설정자와, 요청이 나가 있는 동안 들어온 키 입력을 서버 버전 위에
다시 얹는 **재기준(rebase)** 처리가 얽혀 있습니다. 이것을 훅으로 옮기면 콜백 열 개를 받는 훅이
되고, 그건 지금보다 나쁩니다. **덜 나눈 채로 두는 것이 맞는 자리**라고 판단했습니다.

대신 **깨끗하게 떨어지는 타이밍 로직**을 뺐습니다.

```
web/src/pages/editor/hooks/
  ├─ useAutosave.ts       타이핑이 멈추면 저장 · 편집기를 떠날 때 마지막으로 한 번
  └─ useAutosave.test.tsx
```

`useUnsavedWarning` 도 같은 파일에 있습니다 — 탭을 닫으려 할 때 브라우저에게 **물어봐 달라고
요청하는** 것뿐이라, 보여 줄지 말지는 브라우저가 정합니다. 우리가 정하는 것은 **언제 묻는가**
이고, 그것이 테스트할 수 있는 전부입니다.

## 타이밍은 가짜 시계로 테스트합니다

- **900ms 간격으로 두 번 편집하면 아직 아무것도 저장되지 않습니다.** 문장을 치는 동안 단어마다
  요청이 나가면 안 되기 때문에, 기다림은 편집마다 다시 시작합니다.
- 편집기를 떠날 때 **직전 편집은 저장됩니다.** 깨끗한 편집기는 떠나도 아무 요청도 하지 않습니다.
- 저장이 실패하면 **조용히 잃지 않고 말합니다.**
- 닫기 경고는 **일이 남아 있을 때만** 묻고, 편집기가 사라지면 묻지 않습니다.

`EditorPage.tsx` 70KB → **68KB**, 테스트 24건 → **30건**.
