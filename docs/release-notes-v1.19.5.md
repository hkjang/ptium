# Ptium v1.19.5

지금까지 나란히 놓고 본 브리프는 **거의 한국어**였습니다. 이번엔 **영어 20개**로 같은 것을
했습니다. 두 가지가 나왔고, **둘 다 한국어에서도 똑같이 났습니다.**

## 표지에 `,` 가 혼자 떠 있었습니다

> Budget request **for the design team**, 250M KRW

청중(`for the design team`)은 주제가 아니라서 빼는 것이 맞습니다. 그런데 빼고 나면 **그 자리를
이었던 쉼표**가 남습니다.

```
Budget request , 250M KRW     ← 표지 제목
Roadmap , FY2026              ← 표지 제목
```

빈자리를 닫습니다 → `Budget request, 250M KRW` · `Roadmap, FY2026`.

## `2026` 이 슬라이드 한 장이 되고 있었습니다

> Cost reduction plan for cloud infrastructure**, 2026**
> 클라우드 비용 절감 계획**, 2026**

끝에 붙인 연도가 **하나의 주제**로 잡혀서, **제목이 그냥 `2026` 인 슬라이드**가 세 장씩
따라 나왔습니다. 연도는 *언제*이지 *무엇*이 아닙니다.

- 혼자 있는 시점(`2026` · `FY2026` · `2026-2028`)은 장이 되지 않습니다
- 앞에 붙어 주제를 꾸미는 시점(`2026년 계획`)은 **그대로 주제**입니다 — 지난 판에서 살린 그 규칙입니다
