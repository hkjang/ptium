# Ptium v1.29.1

실제 PDF 두 개를 가져와 봤습니다. 하나는 **35쪽짜리 발표 자료**였는데 —

```
슬라이드 2장
"33쪽은 그림뿐이라 글자를 가져오지 못했습니다"
```

## 33쪽이 아니라 33개 쪽이었습니다

읽어 보니 **35쪽 가운데 33쪽에 글자가 없었습니다.** 그림으로 내보낸 발표 자료였고,
글자가 있는 쪽은 2쪽뿐이라 슬라이드도 2장이 나온 것입니다. 여기까지는 정확합니다.

문제는 **문장**입니다. `33쪽은 그림뿐…`은 우리말에서 **33번째 쪽**을 가리키는 말입니다.
파일 주인은 **한 쪽을 못 읽었다**고 읽습니다. 실제로는 **33쪽을 못 읽었습니다.**

가장 크게 잃어버린 경우에 **가장 작게 말하고 있었습니다.**

## 세어서 말합니다

```
35쪽 가운데 33쪽은 그림뿐이라 글자를 가져오지 못했습니다
이 파일은 대부분 그림입니다. 원본 문서나 텍스트가 살아 있는 PDF로 올리면 전부 가져옵니다
```

절반 이상이 그림이면 **무엇을 올리면 되는지**도 함께 말합니다 — 글자가 하나도 없는
파일에 하던 안내와 같은 말입니다. 6쪽 중 1쪽처럼 일부만 그림이면 그 사실만 말하고
"대부분 그림"이라고 하지 않습니다.

## 함께 확인한 것 (문제 없었습니다)

- 글자가 아예 없는 11.8MB PDF는 **422로 거절**하며 이유를 말합니다 — "이 PDF에는 글자가
  없습니다. 스캔했거나 그림으로 내보낸 파일로 보입니다."
- 읽은 2쪽은 **출처(`!source … | 29쪽`)와 함께** 슬라이드가 되었습니다.

## 검사

6쪽 중 4쪽이 그림인 파일과 6쪽 중 1쪽이 그림인 파일을 만들어 문장을 고정했습니다 —
숫자를 세어 말하는지, 쪽 번호처럼 말하지 않는지, 대부분 그림일 때만 안내가 붙는지.
예전 문장으로 되돌리면 그 자리에서 잡습니다.
