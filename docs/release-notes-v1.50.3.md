# Ptium v1.50.3

**그 결함을 잡아내는 검사가 하나도 없었습니다.**

## 1.50.2가 고친 것을 아무도 지키지 않고 있었습니다

지난 릴리스에서 "덱의 원문을 그대로 다시 적용하면 그림 두 장이 자리를 바꾼다"를
고쳤습니다. 그런데 그 결함은 **620개 검사 중 어느 것도 잡지 못했습니다.** 모든 검사가
"덱이 무엇을 담고 있는가"를 물었고, **"적어 두었다가 다시 읽으면 같은 덱인가"** 는
아무도 묻지 않았기 때문입니다.

## 이제 묻습니다

스위프에 왕복 검사를 넣었습니다.

```
그림 두 장이 한 장에 있는 덱을 만든다
  → 원문을 읽는다
  → 두 번 읽어 같은 문서인지 본다
  → 그대로 다시 적용한다
  → 슬라이드 내용이 하나도 달라지지 않았는지 확인한다
```

**이 검사가 진짜 무는지 확인했습니다** — 결함이 남아 있는 1.50.1 이미지에 대고
돌렸더니 그대로 걸립니다:

```
✗ applying a deck's own source changed it, on slide(s) [1]
```

api 스위프는 620개에서 **635개**가 됐습니다.

## 남겨 둘 말

"두 번 읽어 같은 문서인가" 쪽은 이 합성 덱으로는 실제로 물지 않습니다 — 그 경로는
템플릿이 이름 붙인 특수한 영역에서만 지나갑니다. 그쪽은 단위 테스트가 지키고 있고,
여기서는 앞으로 다른 모양의 회귀를 잡을 수 있게 값싸게 남겨 두었습니다.
