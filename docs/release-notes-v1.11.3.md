# Ptium v1.11.3

## 모든 장을 건너뛴 덱을 PDF 로 받으면 **500** 이 났습니다

건너뛰기(`!skip`)로 표시된 장은 인쇄하지 않습니다 — 발표에서 넘어가는 장은 배포본에서도
넘어가는 게 맞으니까요. 그런데 **모든** 장이 그렇게 표시된 덱은 인쇄할 페이지가 하나도 없고,
그걸 서버 오류로 답하고 있었습니다.

```
전: 500  "The server could not complete the request"
후: 409  "모든 슬라이드가 건너뛰기로 표시되어 인쇄할 장이 없습니다.
          한 장 이상 발표에 넣어 주세요."
```

**사용자가 고칠 수 있는 일** 은 사용자가 고칠 수 있게 말해야 합니다. 500 은 "제품이 고장났다"
는 뜻이고, 받는 사람은 버그로 신고하게 됩니다. 워크스페이스에서는 한국어 토스트로 나옵니다.

같은 덱을 **PPTX 로 받는 건 그대로 됩니다** — 파워포인트에서는 숨긴 슬라이드도 슬라이드입니다.

## 그밖에

- 내보내기 관련 오류 문구 세 개(슬라이드 없음·인쇄할 장 없음·지원하지 않는 형식)를 코드
  기준으로도 번역하도록 넣었습니다. 서버 문구가 바뀌어도 한국어로 나옵니다.
- API 명세에 이 409 를 적었습니다.

스윕 162 checks — 전부 건너뛴 덱이 500 을 내면 실패하고, 같은 덱의 PPTX 가 안 나와도
실패합니다.
