# Ptium v1.26.1

지난 판에서 **디자인 선택**을 고쳤습니다. 같은 화면의 다른 칸도 같은 모양이었습니다.

## 저장된 값이 화면에서 사라지는 자리가 두 곳 더 있었습니다

**발표 톤**과 **작성 언어**는 정해진 목록이 아닙니다 — API는 80자까지 어떤 문자열이든
받고, 관리자가 정한 기본값이 모든 프로필로 흘러들며, 다른 서비스가 API로 무엇이든
저장할 수 있습니다. 그런데 화면은 정해진 몇 개만 내놓고 있었습니다.

```
저장된 톤 'academic'   개인화 화면: 아무 칩도 선택되지 않음
저장된 언어 'fr'       개인화 화면: "한국어"          ← 실제 값은 fr
```

`academic`은 **관리자 설정 화면이 직접 내놓는 값**입니다. 그 기본값을 쓰는 사람은
자기 톤을 화면에서 볼 수 없었습니다. 언어 칸은 더 나쁩니다 — 목록에 없는 값을 가진
`select`는 **첫 번째 항목을 대신 보여 주기 때문에**, 화면이 실제와 다른 언어를
이름으로 말하고 있었습니다.

## 저장된 값은 언제나 화면에 있습니다

톤과 언어 모두, 저장된 값이 목록에 없으면 **그 값을 그대로 목록에 넣어 보여 줍니다.**
아는 값은 우리말 이름으로, 모르는 값은 적힌 그대로입니다. 저장할 수 있는 범위는
좁히지 않았습니다 — 화면이 사실을 말하게 했을 뿐입니다.

```
저장된 톤 'academic'   → 학술적인 (선택됨)
저장된 톤 'concise'    → concise (선택됨)
저장된 언어 'fr'       → fr
```

관리자 설정 화면의 톤·언어 칸도 같습니다.

## 검사

화면 훑기가 톤 `concise`와 언어 `fr`을 실제로 저장해 두고 화면을 읽습니다. 되돌리면
두 가지 모두 잡습니다(`2 failures`).
