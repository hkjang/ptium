# Ptium v0.86.0

이번엔 **편집기를 브라우저로 직접 몰아 봤습니다.** 두 가지가 나왔습니다.

## 템플릿이 준 자리를 안 쓰고 있었습니다

비교 레이아웃에는 영역이 넷 있습니다.

| 영역 | 용도 | 템플릿이 준 서식 |
|---|---|---|
| `body` / `body2` | 각 단의 **머리말 한 줄** | 파랑 / 주황 굵은 글씨 |
| `body3` / `body4` | 각 단의 **요점 목록** | 본문 |

Ptium 은 머리말을 **요점 영역 안** 에 리드 문단으로 써 넣고, 템플릿의 머리말 자리는 **비워
뒀습니다.** 그래서 모든 비교 슬라이드가 단 이름을 본문 글씨로 보여 주고 그 위에 빈 상자 두
개를 달고 있었습니다.

이제 머리말은 템플릿이 정한 자리로 갑니다. 슬롯 이름이 아니라 **위치로** 찾습니다 — 그 단
위쪽, 같은 가로 폭, 한 줄짜리 본문 영역. 한 줄에 안 들어갈 만큼 긴 머리말은 **잘라내지 않고**
요점 영역에 남습니다. 말없이 문장을 자르느니 자리를 옮기지 않는 편이 낫습니다.

덱을 글로 다시 쓸 때도 이제 **행이 아니라 열 순서** 로 훑습니다. 비교 슬라이드는 `머리말 ·
그 요점 · 머리말 · 그 요점` 으로 나오고, 그대로 다시 읽으면 같은 슬라이드가 됩니다.

## 새 텍스트 상자가 안내 문구를 내용으로 갖고 있었습니다

캔버스에서 텍스트 상자를 하나 넣고, 아무것도 안 치고 다른 곳을 누르면 —

```
텍스트를 입력하세요
```

이 문장이 **슬라이드에 남습니다.** 미리보기에도, 내보낸 파일에도, 회의실에도.

- 새 상자는 **빈 채로** 시작합니다
- 아무것도 안 쓰고 나가면 **상자를 지웁니다**
- 미리보기도 파일도 **내용 없는 텍스트 상자는 그리지 않습니다**

## 설치

오프라인 설치 방법은 [docs/offline-deployment.md](offline-deployment.md) 를 보세요. 이미지에
Postgres 와 nginx 는 들어 있지 않습니다 — 배포할 때 `DATABASE_URL` 로 DSN 을 지정합니다.
