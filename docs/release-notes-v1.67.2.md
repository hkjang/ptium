# 1.67.2 — 배포가 실제로 갖는 기본값을 적습니다

API 설명서가 통합하는 사람에게 이렇게 말하고 있었습니다: *생략하면 관리자가
정한 생성 기본값을 씁니다 (처음에는 `aurora`)*. 두 군데에 그렇게 적혀 있었고,
예시 값 네 개도 `aurora` 였습니다.

**새로 올린 배포가 갖는 값은 `slate-classic` 입니다.** 테마 다섯 개에서 디자인
쉰 개로 넘어오면서 마이그레이션이 옮겨 놓았고, 설명서는 따라오지 않았습니다.

`aurora` 자체는 살아 있습니다 — 예전 버전에서 쓰던 이름을 계속 받아 주도록
`plum-rail` 로 이어 둔 것이고, 그 연결이 어긋나지 않게 지키는 시험도 이미
있습니다. 다만 **아무 배포도 그 값을 갖고 있지 않습니다.**

- 설명서의 "처음에는 …" 두 군데를 `slate-classic` 으로 고쳤습니다.
- 예시 값 네 개는 지금 쓰는 디자인 키로 바꿨습니다. 예시는 가르치는 것이고,
  가르칠 이름은 지금 쓰는 이름이어야 합니다.
- `docs/mcp.md` 의 create 예시도 마찬가지입니다. 에이전트가 그대로 보내는
  값입니다.

## 다시 어긋나지 않게

설명서가 "처음에는 `x`" 라고 적은 값이 **실제 시드 값 가운데 하나인지** 검사하는
시험을 두었습니다. 시드는 마이그레이션에서 직접 읽습니다.

## 확인

- 살아 있는 배포에 물어 `generation.default_theme` 가 `slate-classic` 인 것을
  확인했습니다.
- MCP 문서에 적힌 두 단계 흐름(create → generate → get)을 실제 엔드포인트로
  끝까지 돌려, 9장짜리 덱이 completed 로 끝나는 것을 확인했습니다.
- 설명서를 예전 값으로 되돌리면 시험이 무너지는 것을 확인했습니다.
