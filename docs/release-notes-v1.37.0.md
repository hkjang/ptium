# Ptium v1.37.0

관리자 고도화 다섯 번째 — **정리할 것**입니다. 다만 **읽기만 합니다.**

## 무엇을 얼마나 오래 둘지는 정해야 하는 일입니다

휴지통 자동 비움을 오래전에 여쭈었고, 아직 답을 받지 못했습니다. **자동 삭제는 만들지
않았습니다.** 대신 그 결정을 내리려면 반드시 필요한 것 — **무엇이 얼마나 쌓였는지** —
를 보여 드립니다.

```
이 화면은 아무것도 지우지 않습니다

휴지통에 있는 덱                21개    가장 오래된 것 2026년 8월 26일
30일 넘게 실패로 남은 덱          없습니다
90일 넘게 손대지 않은 초안         없습니다
기한이 지난 공유 링크             없습니다
어느 덱도 쓰지 않는 이미지        470개   55.9MB   가장 오래된 것 2026년 8월 21일
한 달 넘게 쓰이지 않은 이미지      없습니다
```

## 한 가지 조심한 것

**"어느 덱도 쓰지 않는 이미지"에는 오늘 올려서 아직 넣지 않은 이미지도 들어갑니다.**
그것을 지울 대상으로 세면 남의 오전 작업을 지우게 됩니다. 그래서 **한 달이 지나도록
쓰이지 않은 이미지**를 따로 셉니다 — 판단은 그 숫자로 하시면 됩니다.

숫자가 0이면 **"없습니다"** 라고 적습니다. 0을 늘어놓는 화면은 읽히지 않습니다.

## 검사

- REST 훑기: 여섯 가지를 모두 세는지, 음수가 없는지, **0개인데 "가장 오래된 것"이 있지
  않은지**, **한 달 넘은 미사용이 전체 미사용보다 많지 않은지**, 그리고 **두 번 읽어도
  숫자가 그대로인지**(읽기만 한다는 뜻입니다).
- 화면 훑기: 화면이 세고 있는지, 그리고 **"지우지 않습니다"라고 말하고 있는지**.
- 크기 표기(KB·MB·GB)와 "없습니다" 표기를 단위 테스트로 고정했습니다.

전체 Go 테스트 · 웹 169개 · REST 618개 · deep · 화면 훑기 0 failures.
