# Ptium v1.12.17

**공유 링크가 숨긴 슬라이드를 보여주고 있었습니다.**

## 무슨 일이었나

`!skip` 은 "이 장은 발표에서 뺀다"는 표시입니다. 파워포인트로 내보내면 숨겨지고(`show="0"`),
PDF 핸드아웃에서도 빠집니다. 그런데 **링크로 공유하면 그대로 나왔습니다.**

```
공유 페이로드의 슬라이드 수: 3     ← 숨긴 장 포함
익명 미리보기 slide=2 → 200        "숨긴 장 · 아직 공유하지 않을 내용"
```

링크를 받은 사람이면 누구나 볼 수 있었습니다.

## 이제

링크는 **발표에 들어가는 장만** 셉니다. 숨긴 장은 목록에도, 제목에도, 미리보기에도 없습니다.
링크의 2번은 덱의 3번째 장을 그립니다 — 세는 것과 그리는 것이 같은 곳을 가리킵니다.

## 함께 확인한 경계들

이번 점검은 계정 경계 전반을 재는 데서 시작했습니다. 나머지는 모두 견고했습니다:

- 남의 프레젠테이션: 조회·소스·검사·미리보기·내보내기·수정·생성·삭제 **전부 404**
  (있는지조차 알려주지 않습니다)
- 남의 이미지, 남의 조각 슬라이드, 남의 API 키 — 전부 404, 키는 그대로 살아 있습니다
- 공유 페이로드에는 **발표자 노트도 소스도 없습니다**. 내보내기·소스·검사는 401
- 회수한 링크는 410

## 확인

`shownSlides` 의 거르기를 떼어내고 스윕을 돌리니 세 군데가 걸립니다:

```
✗ a link with one skipped slide shows 3 slides, want 2
✗ a slide taken out of the show is named on the link
✗ the link draws the skipped slide at position 2
```
