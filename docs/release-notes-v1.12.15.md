# Ptium v1.12.15

**숨긴 슬라이드가 보이는 슬라이드로 들어오고 있었습니다.**

## 잃는 것보다 나쁩니다

파워포인트에서 슬라이드를 숨기면 파일에는 `show="0"` 이 적힙니다 — 지운 것이 아니라
**이번 발표에서 빼기로 한 것**입니다. 가져오기는 그 표시를 읽지 않았습니다:

```
# 숨긴 장
- 아직 공유하지 않을 내용      ← 평범한 슬라이드로 들어옴
```

이건 무언가를 잃는 것과 다릅니다. 누군가가 **보여주지 않기로 결정한 것을 다시 방 앞에
내놓는 것**입니다. 그대로 두면 화면에도, 내보낸 pptx 에도, PDF 에도 나갑니다.

## 이제

`show="0"` 을 읽어 덱 소스의 `!skip` 으로 옮깁니다. 숨긴 채로 들어오고, 편집기에서 언제든
다시 켤 수 있습니다 — 결정은 저자의 것으로 남습니다.

```
# 숨긴 장
- 아직 공유하지 않을 내용
!skip
```

## 확인

- 읽는 쪽과 쓰는 쪽 각각 되돌려 테스트가 무는지 확인했습니다
- 스윕이 지킵니다: 내장 소스를 뗀 pptx 를 가져와 링크·굵게와 함께 `!skip` 이 남는지.
  `!skip` 을 쓰지 않게 되돌리니 스윕이 `a deck carried in from PowerPoint lost '!skip'`
  으로 잡았습니다 (226 checks)
