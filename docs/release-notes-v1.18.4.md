# Ptium v1.18.4

## 발표자 노트에서 세로줄이 슬래시로 바뀌고 있었습니다

v1.18.0에서, 한 쪽에 다 안 들어가는 줄을 **발표자 노트**로 보내기 시작했습니다. 그 노트를
쓰는 코드가 "필드"용 처리를 쓰고 있었습니다 — **세로줄(`|`)을 슬래시(`/`)로 바꾸는** 처리입니다.

`|` 가 구분자인 자리는 있습니다. 출처 줄(`!source 파일 | 12쪽`)과 표의 칸이 그렇습니다.
**노트는 아닙니다.** `!notes` 뒤는 전부 그냥 글이라서, 문서가 쓴 세로줄은 문서의 문장부호입니다.

파서에도 확인했습니다 — `!notes 단가 | 수수료 | 거래세` 는 세로줄째 그대로 들어옵니다.
바꿀 이유가 없었고, 바꾸면 **쓴 사람의 글을 고쳐 쓰는 것**입니다.

실측: 손에 있는 PDF 가운데 **8개 파일 · 16줄**이 세로줄을 쓰고 있었습니다.

```
거래내역서 …   단가 수수료 거래세 제세금 변제/연체합 …
              수량단위 : 주, 원 | : 원
```

이제 그대로 옵니다. 슬라이드의 **요점**은 원래부터 그대로였고(같은 처리를 쓰지 않았습니다),
**노트만** 달랐습니다.

## 검사

- 한 쪽에 안 들어가는 세로줄 문장을 노트로 보내고 **세로줄째 도착하는지**, 요점 쪽도 함께
  고정했습니다. 되돌리면 실패합니다.
- REST 훑기의 PDF 구간도 그렇게 바꿨습니다(477개 점검) — 넘친 줄이 노트에 있고, 그 노트의
  문장부호가 그대로인지 한 번에 봅니다.
