# Ptium v0.85.0

지난 다섯 판의 수정은 전부 **미리보기(SVG)로만** 확인했습니다. 미리보기는 저자가 덱을
판단하는 화면이고, **회의실이 보는 것은 파일** 입니다. 그런데 그 둘을 대조하는 것은 아무것도
없었습니다.

## 대조해 봤습니다 — 일치합니다

생성한 덱을 python-pptx 로 다시 읽었습니다. 컴포넌트가 파일에서는 **그룹 도형** 이 되므로 그
안까지 들어가서 훑었습니다.

- 9장 전부, 미리보기가 그리는 **모든 줄이 파일에 있습니다**
- 발표자 노트도 8장 모두 들어 있습니다 (표지는 노트가 없는 게 맞습니다)

처음 돌렸을 때는 "슬라이드 2·5·8 의 컴포넌트가 파일에 없다" 고 나왔는데, **점검 도구가 그룹
안을 안 본 것** 이었습니다. 도구를 못 믿으면 결과도 못 믿습니다.

## 이제 매번 대조합니다

`scripts/e2e/package.py` 가 실행할 때마다 슬라이드마다 미리보기와 파일을 **줄 단위로**
맞춰 봅니다. 파일에 안 써지기 시작한 컴포넌트나 미리보기에만 있는 줄은 이제 **스윕 실패** 로
잡히지, 누군가의 화면에 도착하지 않습니다.

대조 도구가 배워야 했던 두 가지 — 둘 다 파일이 글자보다 많은 것을 담기 때문입니다.

- 진짜 차트는 축 이름과 값을 도형 글자가 아니라 **차트 파트** 에 둡니다
- 파일은 불릿 기호를 **PowerPoint 의 목록 서식** 에 맡기고, 미리보기는 직접 그립니다

## 범례가 말을 더듬었습니다

기본 체크리스트는 칸을 `진행` 으로 표시하고 뜻을 `진행 중` 으로 적어 둡니다. 범례는 둘을
공백으로 이었습니다.

```
완료 확인됨   진행 진행 중   미착수 시작 전   위험 조치 필요
```

한쪽이 이미 다른 쪽을 말하고 있으면 **하나면 충분합니다.**

```
완료 확인됨   진행 중   미착수 시작 전   위험 조치 필요
```

## 설치

오프라인 설치 방법은 [docs/offline-deployment.md](offline-deployment.md) 를 보세요. 이미지에
Postgres 와 nginx 는 들어 있지 않습니다 — 배포할 때 `DATABASE_URL` 로 DSN 을 지정합니다.
