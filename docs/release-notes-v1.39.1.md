# Ptium v1.39.1

**울타리가 제 일을 한 것은 장애가 아닙니다.**

## 오류 센터에서 가장 큰 그룹이 정상 동작이었습니다

1.39.0에서 오류에 버전이 붙자마자 바로 드러났습니다. 열린 오류 중 압도적 1위가
`presentation generation state changed` **151회** — 그리고 그중 하나가 가리키는 덱을
열어 보니 **정상적으로 완성된 덱**이었습니다.

덱 하나를 두 작업자가 동시에 쓰지 못하도록 리스가 있습니다. 늦게 도착한 시도는
완료를 거절당하고 조용히 물러나야 하는데 — 그 거절이 **error 등급 장애로 기록**되고
있었습니다. 사용자가 생성을 중단시켜도, 관리자가 취소해도, 덱을 지워도 마찬가지였습니다.
모두 누군가가 그렇게 하기로 한 일입니다.

결과적으로 운영자가 실제로 조치해야 할 오류들이 **정상 동작 151건 밑에 깔려** 있었습니다.

## 이제

작업자는 실패를 기록하기 전에 **그 덱이 아직 자기 것인지** 먼저 확인합니다.

- 리스를 잃은 경우 — 중단·취소·삭제·다른 작업자가 가져감 — 오류 센터에 아무것도
  남기지 않고 운영 로그에 한 줄만 남깁니다:
  `this deck moved on while it was being written`
- 리스를 **쥔 채로** 실패한 경우는 진짜 장애이므로 그대로 기록됩니다. 조용해지지 않습니다.
- 저장소에 물어볼 수 없으면 기록하는 쪽을 택합니다. 데이터베이스에 닿지 않는다는 것은
  침묵할 이유가 아닙니다.

작성자에게 가는 메시지와 덱의 상태는 달라지지 않았습니다. 중단된 덱은 여전히 중단된
이유를 달고 있고, 다시 쓰기에 실패한 덱은 여전히 원래 내용을 유지합니다.

## 실제로 확인한 것

- 40장 생성을 작성 중에 관리자 취소 → 오류 그룹 152 그대로, 운영 로그에 한 줄.
- 44,547건 동시 요청(생성 477·삭제 477·내보내기 477 포함) → 그룹 증가 0.
- 리스를 쥔 채 실패하면 오류 센터에 반드시 도달하는지도 함께 고정했습니다.
