# Ptium v1.60.1

**취소선 그은 줄이 멀쩡히 살아 있는 줄로 들어왔습니다.**

## 마크다운에 대응이 없는 서식을 넣어 봤습니다

밑줄, 빨간 글씨, 40pt 큰 글씨, 취소선을 섞은 파워포인트를 가져왔습니다.

```
글자는 전부 살아남았습니다 (6/6)
색·크기·밑줄·취소선은 모두 사라졌고, 제품은 아무 말도 하지 않았습니다
```

**색과 크기가 사라지는 것은 옳습니다.** 덱은 도착한 디자인으로 다시 그려집니다 —
예전 덱의 색이 새 디자인과 싸우면 안 되고, 표와 차트에 대해서도 제품은 이미
"이 덱의 디자인으로 다시 그렸습니다"라고 말합니다.

**취소선은 다릅니다. 그건 꾸밈이 아니라 뜻입니다.**

> 취소선 그은 옛 계획

작성자가 "이 줄은 이제 아니다"라고 표시해 둔 것인데, 가져오면 **다른 줄과 똑같이
살아 있는 줄**이 됩니다. 글자가 사라진 게 아니라 **뜻이 뒤집힌** 것이라, 없어진
것보다 나쁩니다. 취소된 항목이 현재 계획으로 읽힙니다.

## 옮길 수 없으면 말이라도 합니다

가져오기는 애초에 `strike`를 **읽지도 않고** 있었습니다. 이제 읽고, 옮길 마크업이
없다는 사실을 말합니다.

```
취소선이 그어져 있던 줄 1개는 그 표시를 가져오지 못했습니다.
취소된 내용이라면 지우거나 다시 표시해 주세요.
```

표·차트·그림에 대해 이미 하던 것과 같은 방식입니다. 그은 줄이 없으면 아무 말도
하지 않습니다.

## 조사를 또 틀렸습니다

처음 쓴 문장은 **"1줄는"**이었습니다. 줄은 받침으로 끝나므로 `은`이어야 합니다 —
v1.56.3에서 고쳤던 것과 같은 함정입니다. 개수를 `개`로 세도록 바꿔 해결했습니다:
`개`는 **자리로 읽힐 수 없고**(이 세션에서 두 번 문제가 됐던 것), 뒤에 오는 조사도
바뀌지 않습니다.
