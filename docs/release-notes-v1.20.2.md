# Ptium v1.20.2

**살아 있는 모델**로 덱을 만들어 새 검사를 통과시켜 봤습니다. 제목 검사는 조용했습니다
(모델이 쓴 제목은 멀쩡했습니다). 대신 **다른 검사가 틀린 말을 하고 있었습니다.**

## 비교 표를 "같은 말을 두 번 했다"고 지적했습니다

모델이 쓴 재고 회전율 덱의 비교 슬라이드입니다.

```
⚠ 같은 말을 두 번 합니다: "과잉 재고 품목 비율: 12%" 와 "과잉 재고 품목 비율: 24% 증가"
⚠ 같은 말을 두 번 합니다: "투자 대비 수익률 (ROI): 0%" 와 "투자 대비 수익률 (ROI): 300% 예상"
⚠ 같은 말을 두 번 합니다: "재고 부패/폐기 비용: +30% 증가" 와 "재고 부패/폐기 비용: 기준선"
```

**같은 것을 두 값으로 재는 것 — 그게 비교 슬라이드입니다.** 지적대로 고치면 표의 절반을
지워야 합니다.

`AI로 고치기` 를 누르면 모델은 그 지적을 읽고 **정말로 지웁니다.** 틀린 측정이 내용을
지우게 만드는 자리였습니다.

### 두 가지로 구분합니다

- **숫자가 다르면** 다시 말한 것이 아니라 **비교한 것**입니다 — `12%` 와 `24%`
- **한쪽에 숫자가 없어도** 그렇습니다. 비교의 한쪽은 흔히 **기준선**이라 숫자가 없습니다.
  `이름: 값` 꼴에서 **이름이 같고 값이 다르면** 비교입니다

말을 바꿔 같은 뜻을 두 번 쓴 경우는 **여전히 잡습니다** — 그건 진짜 반복이니까요.

같은 덱을 다시 만들어 재 봤습니다: **92점 → 98점**, 남은 지적은 진짜인 것 두 개(마지막 줄에
한 조각만 남음, 숫자의 출처 없음)뿐입니다.

## 검사

모델이 실제로 쓴 세 쌍을 그대로 고정하고, **말만 바꾼 진짜 반복**도 함께 넣었습니다.
숫자 규칙만 되돌리면 한 곳, 둘 다 되돌리면 세 곳에서 실패합니다.
