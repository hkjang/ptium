# Ptium v1.58.0

**10장을 요청하면 5장이 나오는데, 왜인지 말하지 않았습니다.**

## 설정이 지켜지는지를 쟀습니다

설정 화면의 숫자가 맞는지가 아니라, **그 설정대로 제품이 움직이는지**를 쟀습니다.

```
기본 장수를 3으로 두고 장수를 말하지 않으면  → 3장     ✓ 지켜집니다
최대 장수를 5로 두고 10장을 요청하면       → 5장     ✓ 지켜집니다
```

둘 다 지켜집니다. 다만 두 번째가 **201로 조용히** 돌아왔습니다. 10장을 달라고 했고
5장을 받았는데, 응답에도 덱에도 그 이야기가 없습니다.

## 앞문만 조용했습니다

같은 상한이 다른 두 곳에서는 스스로를 밝힙니다.

* 파워포인트 파일을 가져올 때 — "이 배포는 한 덱에 50장까지 허용하므로 그 뒤는
  가져오지 않았습니다"
* 코드를 적용할 때 — 같은 방식으로 알려 줍니다

**새 덱을 만드는 사람만** 듣지 못했습니다.

게다가 잘라내기가 검사보다 **먼저** 일어납니다. `validatePresentationInput`에는
"요청 장수는 1에서 %d 사이여야 합니다"라는 거절이 있지만, 그 자리에 도달할 때는 이미
값이 잘려 있어 **결코 발동하지 않습니다.** 거절할 수 있는 길과 조용히 자르는 길이
함께 있었고, 언제나 뒤쪽이 이겼습니다.

## 자른 만큼 말합니다

무엇을 요청받았는지를 알아야 말할 수 있으므로, 상한을 씌우기 전의 값을 따로
내놓게 했습니다(`SlideCountAsked`). 덱이 요청보다 짧으면 다른 두 곳이 쓰는 자리에
같이 적습니다 — 편집기가 이미 보여 주는 곳입니다.

```
10장을 명시적으로 요청   → 5장 · 10장을 요청하셨지만 이 배포는 한 덱에 5장까지 허용하므로 5장으로 만들었습니다.
브리프 안에서 12장 요청  → 5장 · 12장을 요청하셨지만 …
허용 범위 안(4장)      → 4장 · (아무 말 없음)
영어 덱                → 5장 · You asked for 9 slides. This deployment allows 5 to a deck, so it was made with 5.
```

브리프에 적힌 "12장짜리로 만들어 줘"도 요청입니다. 자른 것이 없으면 아무 말도 하지
않습니다.

## 함께 확인하고 문제가 없던 것

* **AI 설정은 환경변수로 덮이지 않습니다** — 저장된 설정이 유일한 출처라 화면이
  보여 주는 값이 곧 제품이 쓰는 값입니다
* **기본 장수 > 최대 장수**는 이미 거절합니다. 이유까지 말해 줍니다
* **오류 센터**의 네 숫자는 모두 `표시된 …`이라 적혀 있고 실제로는 전부 가져옵니다
