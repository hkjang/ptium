# Ptium v1.12.4

작은 릴리즈입니다 — 이번 주에 넣은 것들을 점검하면서 나온 정합성 하나와, 제품의 핵심
동작에 대한 검사 하나입니다.

## 생성 단계는 "지금 일어나는 일"입니다

v1.12.3 에서 넣은 진행 표시가, **실패했을 때와 회수됐을 때** 그대로 남아 있었습니다. 크래시된
작업자의 덱은 10분 뒤 큐로 돌아오는데, 그동안 화면은 "슬라이드를 쓰고 있어요"라고 말할 수
있었습니다. 두 경로 모두 비웁니다.

## 덱을 다른 템플릿으로 옮기는 것을 스윕이 지킵니다

이 제품의 약속은 "템플릿이 곧 디자인"이고, 그 약속의 뒷면은 **이미 쓴 덱을 다른 템플릿으로
옮길 수 있다** 는 것입니다. 서버에도 워크스페이스(디자인 패널)에도 이미 있었는데, 스윕에는
없었습니다.

이제 매 스윕이 확인합니다: 덱을 다른 기본 템플릿으로 옮기고 → 템플릿 이름이 바뀌었는지 →
**그리는 결과가 실제로 달라졌는지** → 결함 0인지 → 새 디자인으로 내보내지는지. (198 checks)

## 점검하면서 확인한 것들

- 생성이 자동으로 얹은 이미지는 **내보내기까지 갑니다** — pptx 의 `ppt/media/`, PDF 의 이미지
  객체 양쪽에 들어 있습니다
- 모델에 닿지 못하면 실패가 아니라 **오프라인 작성기로 넘어갑니다** — 그러라고 있는 길입니다
- 템플릿 교체 전후로 결함 0, 권고는 오히려 줄었습니다(새 레이아웃에서 어떤 장이 논증을
  담는지 다시 판정되기 때문입니다)

## 설치

```bash
gzip -dc ptium-1.12.4.tar.gz | docker load
```
