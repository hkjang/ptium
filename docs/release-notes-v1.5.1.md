# Ptium v1.5.1

저장된 덱 **1,019개** 의 원본을 전부 꺼내, **compile → 다시 쓰기 → compile** 을 돌렸습니다.
코드 보기를 열고 그대로 적용했을 때 덱이 그대로여야 한다는 규칙입니다.

**3개가 줄을 잃었습니다.**

```
# 투자 대비 리스크 분석
@comparison
> 투자 비용            ← 왼쪽 열 이름
- 12억 원 투자 필요
- 기술 부채 해소
> 잠재 손실            ← 오른쪽 열 이름  ✗ 사라짐
- 거래 중단 매출 손실
- 고객 이탈 장기 손실
```

코드 보기를 열었다 적용하면 **오른쪽 열의 이름이 없어지고**, 그 항목들이 왼쪽 목록에 이어
붙었습니다. 두 열짜리 비교 슬라이드가 **한 덩어리 목록** 이 됩니다.

## 왜 사라졌나

열 이름을 다시 써 주는 규칙에 **"그 영역의 첫 줄일 때만"** 이라는 조건이 붙어 있었습니다.
본문 영역이 **하나뿐인 레이아웃** 에서는 두 열이 같은 영역에 담기고, 두 번째 열 이름은
**목록 한가운데** 에 놓입니다. 첫 줄이 아니니 조건에서 빠졌고, 조건에서 빠지면 **버려졌습니다.**

이제 슬라이드 자신의 리드가 아닌 리드는 **어디에 있든** 열 이름으로 다시 씁니다.
