# 1.63.2 — 공유 링크에서도 3장은 3장입니다

공유 링크는 작성자가 건너뛰기로 표시한 장을 빼고 보여 줍니다. 그래서 공유
화면의 세 번째 자리는 덱의 세 번째 장이 아닙니다.

다섯 장짜리 덱에서 2장을 건너뛰면 공유 화면에는 네 장이 보입니다.

| 공유 화면의 자리 | 실제 덱의 장 |
| --- | --- |
| 1 | 1장 |
| 2 | **3장** |
| 3 | 4장 |
| 4 | 5장 |

여기서 `[3장 참고](#3)` 를 누르면 공유 화면은 세 번째 자리로 갔습니다.
**4장입니다.** 검토하는 사람은 엉뚱한 장을 보고 의견을 남깁니다. 앞에
건너뛴 장이 있는 만큼 한 장씩 밀립니다.

- 공유 링크가 각 자리마다 그것이 덱의 몇 번째 장인지 함께 알려 줍니다.
- 점프는 그 번호를 가진 장으로 갑니다. 건너뛴 장을 가리키는 점프는 그
  다음으로 보여 주는 장으로 갑니다 — 발표 화면이 하는 것과 같습니다.
- 예전 서버에 물어보는 캐시된 페이지는 예전처럼 동작합니다.

발표 화면은 처음부터 맞게 동작하고 있었습니다. 같은 규칙을 공유 화면도
쓰게 됐습니다.

## 확인

- 5장 덱에서 2장을 건너뛰고 공유해, 브라우저에서 사람이 누르듯 `#slide-3`
  링크를 눌러 `2 / 4` (셋째 장) 로 가는 것을 확인했습니다.
- 고침을 되돌려 같은 클릭이 `3 / 4` (넷째 장) 로 가는 것을 확인했습니다.
