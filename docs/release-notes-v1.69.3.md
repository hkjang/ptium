# Ptium 1.69.3

## 다음 슬라이드를 미리 그려둡니다

지난 판에서 화면에 보이지 않는 썸네일을 미리 그리지 않도록 바꾸면서, 곧 보게 될
600px 앞까지는 미리 그려두겠다고 적어두었습니다. 실제로는 그러지 못했습니다.

"가까운지"를 재는 여백은 관찰자가 기준으로 삼은 영역에만 적용됩니다. 기준을 창으로
두었더니 여백이 창 밖으로만 넓어졌고, 썸네일이 실제로 오르내리는 슬라이드 레일은
742px 높이에서 그대로 잘렸습니다. 레일의 접힌 자리 바로 아래 61px에 있는 칸조차
미리 그려지지 않았습니다. 50장짜리 덱을 열었을 때 레일 밖에 미리 그려둔 칸은
0개였습니다.

이제 여백을 창이 아니라 썸네일이 실제로 스크롤되는 패널을 기준으로 잽니다. 같은
덱을 열면 화면 밖 5칸이 미리 그려집니다. 읽는 사람이 레일을 내리면 그 자리에서
시작하는 회전 표시 대신 이미 그려진 그림을 만납니다.

한 번에 그리는 양은 여전히 적습니다. 50장짜리 덱을 여는 데 6장이던 요청이 11장이
되었을 뿐, 예전의 50장에는 한참 못 미칩니다.

## 지키는 장치

`scripts/e2e/ui.py`가 50장짜리 덱을 새로 만들어 열고, 레일의 접힌 자리 너머에
미리 그려둔 칸이 하나도 없으면 실패합니다. 고침을 빼고 돌려 실제로 실패하는 것을
확인했습니다.
