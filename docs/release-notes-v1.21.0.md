# Ptium v1.21.0

## 이미지 라이브러리가 이미지가 아닌 것을 받고 있었습니다

파일 이름만 `.png` 로 바꿔 올려 봤습니다.

```
"nope not an image at all"          → 201 저장됨
"<!doctype html>…"                  → 201 저장됨
PDF 앞부분 2,000바이트                → 201 저장됨
```

전부 **그림으로 저장**되고, 슬라이드에 놓이고, `.pptx` 로 내보내집니다. 그리고 그 파일을 여는
사람은 **PowerPoint가 "파일이 손상되었다"고 말하는 것**을 봅니다. 무엇이 잘못됐는지도 모른 채로요.

## 파일 이름은 아무것도 정하지 않습니다

원인은 마지막 한 줄이었습니다. 바이트를 보고 형식을 알아내되, **알아내지 못하면 브라우저가
보낸 `Content-Type` 을 믿었습니다.** 브라우저는 사람이 고른 파일이 무엇이든 확장자대로
`image/png` 라고 보냅니다.

**무엇인지는 바이트가 정합니다.** PNG · JPEG · GIF · SVG 의 실제 표시가 없으면 받지 않습니다.

- SVG는 글이라서 `<?xml …?>` 나 주석이 앞에 올 수 있습니다 — **앞 4KB 안**에서 찾습니다
- 진짜 이미지는 그대로 올라갑니다

거절도 한국어로 말합니다.

> 이미지 파일이 아닙니다. PNG · JPEG · GIF · SVG만 넣을 수 있습니다 — **확장자만 바뀐 파일일
> 수 있습니다.**

## 어떻게 찾았는지

사람이 흔히 하는 실수 12가지를 실제로 API에 넣어 보고, **각각 무엇이라고 답하는지** 읽었습니다.
열한 가지는 제대로 답했고(전부 한국어였습니다 — 서버는 영어로 쓰고 화면이 옮깁니다),
**한 가지는 답하지 않고 받아들였습니다.**

## 검사

바이트로 알아내는 네 가지와 거절하는 다섯 가지를 고정하고, REST 훑기에도 넣었습니다 —
글 · 웹페이지 · PDF를 `.png` 이름으로 올려 **거절되는지**, 그리고 **진짜 PNG는 여전히
올라가는지**(495개 점검).

전체 Go 테스트 · 웹 · REST 495개 · edges 33 · deep · 화면 훑기 전부 0 failures.
