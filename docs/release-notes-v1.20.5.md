# Ptium v1.20.5

이 제품의 대표 기능 — **가진 PowerPoint 템플릿에 맞춰 만들기** — 를 **가진 파일로** 직접
돌려 봤습니다. `.pptx` 13개를 템플릿으로 올리고, 각각에 8장짜리 덱을 만들고, 재고,
내보냈습니다.

```
12개 템플릿 · 전부 8장 · 결함 0 · 점수 97~99 · pptx 내보내기 정상
1개 거절     · 문서보안(DRM)으로 잠긴 파일
```

거절도 맞는 판단이고, **무엇이 문제인지 정확히 말합니다.** 그런데 **다른 문 하나가 거짓말을
하고 있었습니다.**

## `.pptx` 를 올렸는데 ".pptx는 못 읽는다"고 답했습니다

같은 잠긴 파일을 **가져오기**(템플릿이 아니라)로 올리면:

```
{"code": "unsupported_document",
 "message": "Ptium reads .pptx presentations and .xlsx, .csv, .docx, .pdf and .md documents"}
```

**`.pptx` 를 올린 사람에게 ".pptx를 읽는다"고 답하는 문장**입니다. 읽지 못한 진짜 이유는
말하지 않고요.

이유는 흐름이었습니다 — 프레젠테이션으로 열리지 않으면 **문서 리더에게 넘기고**, 문서 리더는
`.pptx` 를 자기가 읽는 형식 목록에서 못 찾아 그 문장을 답합니다.

**열리지 않는 프레젠테이션은 "못 읽는 형식"이 아니라 "문제가 있는 프레젠테이션"입니다.**
이제 템플릿 문과 같은 말을 합니다.

> 문서보안(DRM)으로 잠긴 파일입니다. 보안을 해제한 .pptx 파일을 올려 주세요.

예전 형식(`.ppt`)도 마찬가지입니다 — "PowerPoint에서 [다른 이름으로 저장] → .pptx" 라고
말합니다. `.xlsx` · `.pdf` 같은 진짜 문서는 예전처럼 문서 리더로 갑니다.

## 검사

거절 문구 세 가지(잠긴 파일 · 예전 형식 · 평범한 zip)를 고정하고, REST 훑기에도 넣었습니다 —
잠긴 `.pptx` 를 올려 **DRM이라고 말하는지**, 그리고 **"읽는 형식 목록"으로 답하지 않는지**
함께 봅니다(489개 점검).
