# Ptium v1.59.3

**"새로고침한 뒤 다시 시도해 주세요" — 시키는 대로 하면 방금 쓴 글이 사라집니다.**

## 두 창에서 같은 덱을 열어 봤습니다

한 덱을 두 창에서 열고, A가 1번 장을 고쳐 저장한 뒤 B가 2번 장을 고쳐 저장했습니다.

```
창 A: 저장했습니다.
창 B: 저장하지 못했습니다: 다른 곳에서 이 덱이 먼저 바뀌었습니다. 새로고침한 뒤 다시 시도해 주세요.
덱:   ['A가 고친 첫째 장', '둘째 장', '셋째 장']
```

**충돌 처리는 옳습니다.** 오래된 창이 덮어쓰지 못하고, 거절당하고, 이유를 듣습니다.
A의 작업은 그대로 남습니다.

문제는 **거절 다음에 시키는 일**이었습니다.

## 시키는 대로 하면 잃습니다

B의 작성자는 방금 문단을 하나 썼습니다. 재 봤습니다.

```
거절 뒤 화면에 글이:      남아 있음
시키는 대로 새로고침한 뒤:  사라짐
```

이 메시지를 내는 두 곳은 **둘 다 편집기의 저장**입니다. 즉 이 문장을 읽는 사람은
언제나 방금 무언가를 타이핑한 사람입니다. 그 사람에게 새로고침을 시키면서 **그것이
무엇을 없애는지 말하지 않으면**, 제품이 자기 작업을 버리라고 시키는 셈입니다.

## 무엇이 사라지는지 먼저 말합니다

```
다른 곳에서 이 덱이 먼저 바뀌었습니다. 여기서 고친 내용은 아직 화면에 있지만
새로고침하면 사라집니다. 필요한 부분을 복사해 두고 새로고침한 뒤 다시 넣어 주세요.
```

토스트치고는 깁니다. 짧게 써서 사람이 자기 글을 잃는 것보다는 낫습니다.

## 판단이 필요한 것

지금은 사람에게 복사를 시킵니다. 더 나은 답은 **편집기가 대신 합치는 것**입니다 —
거절당하면 최신 덱을 다시 받아 와서, 다른 창이 건드리지 않은 장에 한해 작성자의
수정을 다시 얹고 저장하는 것입니다. 두 창이 서로 다른 장을 고쳤다면 충돌은 사실
없습니다.

다만 같은 장을 고쳤을 때 무엇을 이길지는 제품이 정할 문제라, **제가 정하지 않고
남겨 둡니다.**
