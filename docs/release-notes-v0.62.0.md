# Ptium v0.62.0

이번 판은 **문서 가져오기**를 감사했습니다. csv · tsv · md · docx를 각각 넣고, 나온 덱을
슬라이드 단위로 읽고, 검사기를 통과시키고, 마지막 장은 그려서 봤습니다.

## 보고서를 넣으면 덱 이름이 "report" 였습니다

`report.md` 를 올리면 이렇게 됐습니다.

```
1장 (표지)  report          ← 파일 이름
2장          결제 시스템 이중화 이행 보고   ← 문서가 스스로 붙인 제목. 본문 없음.
3장          지금의 문제
```

문서는 **첫 줄에서 자기 이름을 말합니다.** 그것을 표지로 쓰지 않고 파일 이름을 쓴 다음, 문서의
진짜 제목에는 **아무것도 없는 슬라이드**를 준 것입니다. 읽지 않았다고 광고하는 셈입니다.

이제 문서의 첫 제목이 덱의 이름이 됩니다.

```
1장 (표지)  결제 시스템 이중화 이행 보고
             > report.md          ← 어디서 왔는지는 표지 아래 줄에 남습니다
2장          지금의 문제
```

**첫 절에 내용이 있으면 그 슬라이드는 그대로 둡니다.** 문장을 표지로 올리면 그 문장의 출처
줄을 잃기 때문입니다 — 표지에는 쪽 번호 자리가 없고, 출처 줄은 그 자리에 섭니다. 잃지 않는
쪽을 택했습니다.

스프레드시트에는 스스로 붙인 제목이 없으므로 파일 이름이 그대로 덱 이름입니다.

## 감사에서 확인한 것

| 파일 | 결과 |
|---|---|
| `quarterly.csv` | 표 한 장 · 범위 출처 `A1:D5` · 98점 |
| `kpi.tsv` | 표 한 장 · 범위 출처 `A1:C4` · 98점 |
| `report.md` | 5장(전 6장) · 절마다 출처 · 97점 |
| `strategy.docx` | 4장 · 제목 정상 · 98점 |

결함(defect)은 한 건도 없었고, 남은 지적은 전부 `발표자 노트 없음` — 문서에서 가져온 덱은
말할 내용을 아직 안 적었으니 맞는 지적입니다.

마지막 장(`요청`)은 그려서 확인했습니다: 문장 하나와 발 밑의 `출처: report.md, 요청`.
v0.61에서 고친 마무리 슬라이드 문제가 가져오기 경로에서도 제대로 동작합니다.
