# Ptium v0.24.0

업무용 덱이라면 당연히 있는 두 가지가 없었습니다.

## 페이지 번호

기본 제공 마스터에는 번호 자리(`sldNum`)가 처음부터 있었는데 **PowerPoint에는 아무것도 보이지
않았습니다.** PowerPoint는 **슬라이드 자신이 그 도형을 가지고 있을 때만** 번호를 그립니다 —
머리글/바닥글 대화상자가 하는 일이 그 도형을 넣는 것입니다.

이제 Ptium이 넣습니다.

- **디자인이 번호 자리를 둔 경우에만** 넣습니다. 자리가 없는 디자인에는 넣지 않습니다.
  디자이너가 그렇게 정한 것입니다.
- **표지에는 넣지 않습니다.** 표지에 번호를 붙이는 덱은 없습니다.
- **필드로 넣습니다.** PowerPoint에서 순서를 바꾸면 번호가 따라옵니다.
- **미리보기도 같은 자리에 같은 색·크기로** 그립니다. 화면과 파일이 다르지 않습니다.
- **올린 회사 템플릿은 그 템플릿의 자리에** 그 템플릿의 서식으로 넣습니다. 레이아웃이 번호
  자리를 다시 선언하지 않았다면 마스터의 것을 물려받습니다(마스터 도형을 끈 레이아웃은 제외).

## 7장 이상이면 목차로 시작합니다

표지 다음에 **목차**가 들어가고, 다룰 구역을 순서대로 적습니다. 6장 이하에는 넣지 않습니다 —
바로 뒤 네 장이 할 말을 한 장 더 쓰는 것이기 때문입니다.

계획 단계의 프롬프트에도 같은 규칙을 넣었으므로, **AI가 붙은 배포와 폐쇄망 배포가 같은 모양의
덱**을 만듭니다.

실측(폐쇄망, AI 제공자 없음): "…9장짜리 자료" → 9장, 2장이 목차, 결함 0 · 다듬을 곳 0,
내보낸 파일에서 1장은 번호 없음 · 2·3장은 번호 있음.

gzip -dc ptium-0.24.0.tar.gz | docker load
