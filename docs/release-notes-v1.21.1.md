# Ptium v1.21.1

지난 판에서 "사람이 흔히 하는 실수 12가지"를 넣어 본 결과를 다시 읽었습니다. 답은 전부
한국어였는데, **여섯 개가 같은 문장**이었습니다.

```
제목을 400자로              → 입력한 값이 올바르지 않습니다.
슬라이드 수를 900장으로        → 입력한 값이 올바르지 않습니다.
빈 의견 남기기              → 입력한 값이 올바르지 않습니다.
없는 템플릿 고르기            → 입력한 값이 올바르지 않습니다.
AI 공급자에 숫자 넣기         → 입력한 값이 올바르지 않습니다.
빈 파일 올리기              → 입력한 값이 올바르지 않습니다.
```

**서버는 정확히 무엇이 잘못됐는지 말했습니다.**

```
title is required and must not exceed 200 characters
requestedSlideCount must be between 1 and 50
a comment needs something to say
the selected template does not exist
```

옮기는 표가 **문장 전체를 그대로 맞춰 보는 방식**이라, 숫자가 들어간 문장은 어느 것과도
맞지 않아 **코드의 기본 문장**으로 떨어졌습니다. 제품이 아는 것을(**어느 칸**이 **몇 자까지**인지)
말하지 않고 "값이 틀렸다"고만 한 것입니다.

## 이제 이렇게 말합니다

```
제목은 비워 둘 수 없고 200자를 넘을 수 없습니다.
슬라이드 수는 1에서 50 사이여야 합니다.
의견을 입력해 주세요.
고른 템플릿이 없습니다. 목록에서 다시 골라 주세요.
AI 공급자는 fallback · openai · openai-compatible 중 하나여야 합니다.
올린 파일이 비어 있습니다.
```

- 숫자와 칸 이름이 든 문장은 **규칙으로** 옮깁니다(제목 · 이름 · 브리프 · 슬라이드 수 …)
- **조사는 한국어가 고르는 대로** 붙입니다 — `제목은` · `슬라이드 수는`. `제목은(는)` 은
  아무도 고르지 않았을 때 나오는 모양입니다
- 영어가 섞이던 자리도 정리했습니다 — `fallback, openai, or openai-compatible` → `·` 로
- **규칙이 없는 문장은 서버가 쓴 그대로** 보여 줍니다. 반만 옮긴 문장이 안 옮긴 문장보다
  나쁘니까요
