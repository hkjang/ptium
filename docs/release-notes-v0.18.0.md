# Ptium v0.18.0

발표 화면이 청중에게 **발표 노트를 보여 주고** 있었습니다. 순서가 거꾸로였습니다.
그리고 템플릿에는 색과 여백만 있었지, 무엇에 대한 발표인지 말해 주는 **그림**이 없었습니다.

## 발표자 보기

발표 화면에는 이제 **슬라이드만** 나옵니다. 발표자가 필요한 것은 전부 두 번째 창으로
옮겼습니다(**P** 또는 조작 막대의 발표자 아이콘).

- 지금 슬라이드, **다음 슬라이드와 그 제목**, 큰 글씨의 **발표 노트**, **경과 시간**(일시정지·
  초기화)과 현재 시각.
- 어느 창에서 넘기든 두 화면이 함께 움직입니다. 같은 브라우저 안에서 직접 주고받으므로
  서버를 거치지 않고 키를 누른 만큼 즉시 반응합니다.
- 발표를 끝내면 발표자 창도 함께 닫힙니다.

## 발표 화면

- **숫자 + Enter** 로 그 장으로 건너뜁니다. **G** 로 전체 슬라이드 목록을 열어 눌러서 이동합니다.
- **B** 검은 화면, **W** 흰 화면 — 잠시 화면에서 눈을 떼게 할 때 쓰는 그 키입니다.
- **L** 레이저 포인터, **F** 전체 화면(Fullscreen API), ← → · Space · PageUp/Down · Home/End.
- **다음·이전 슬라이드를 미리 받아 둡니다.** 청중 앞에서 로딩 표시가 보이는 순간은
  없어야 합니다.
- 마우스를 2.6초 멈추면 포인터와 조작 막대가 사라지고, 움직이면 돌아옵니다.

## 시각적 메타포 템플릿 6종

색만 다른 템플릿은 무엇에 대한 발표인지 말해 주지 않습니다. 도형으로 이야기를 여는 계열을
더했습니다. 각 계열은 표지에서 한 번 크게 말하고, 본문 슬라이드에서는 같은 도형을 아주
조용히 되풀이합니다.

| 계열 | 그림 | 어울리는 이야기 |
| --- | --- | --- |
| **Orbit** 원 | 오른쪽에서 떠오르는 큰 원과 궤도 | 성장 · 확장 |
| **Arc** 아치 | 화면 아래를 가로지르는 아치 | 여정 · 단계 |
| **Diagonal** 사선 | 화면을 가르는 사선 | 전환 · 대비 |
| **Dots** 도트 | 모서리에 모인 점의 밀도 | 데이터 · 규모 |
| **Layers** 레이어 | 겹쳐진 반투명 판 | 구조 · 계층 |
| **Wash** 그라데이션 | 표지를 채운 그라데이션과 얇은 원 | 비전 · 출시 |

모든 도형은 프리셋 도형과 그라데이션으로 그려지므로 **미리보기와 PowerPoint가 같은 그림**을
그립니다. 팔레트마다 하나씩 배정해 라이브러리는 **50종**이 되었고, 기존 40종의 조합은
그대로 남아 있습니다.

기본 제공 디자인 회귀 테스트(표지·본문·컴포넌트·표·차트를 쓰는 실제 덱을 그려 결함을 세는)
는 이제 50종 전부를 지나갑니다. 새 계열도 결함 0으로 통과합니다.

## 캔버스 편집

구글 슬라이드에서 손이 먼저 기억하는 동작들을 채웠습니다.

- **끌어서 여러 개 선택** — 빈 곳에서 끌면 선택 밴드가 그려지고, 걸친 개체가 선택됩니다.
- **Shift** — 이동은 축 고정, 크기 조절은 비율 유지, 회전은 15도 단위.
- **Alt + 끌기** — 원본은 두고 복제본을 끌고 갑니다.
- **오른쪽 클릭** — 개체에는 복사·복제·맨 앞으로·맨 뒤로·잠금·삭제, 영역에는 텍스트 편집·
  이미지 넣기·원래 자리로·서식 초기화·AI로 다시 쓰기·내용 비우기, 빈 곳에는 텍스트·도형·표
  추가와 붙여넣기.

### 고쳐진 것

- 오른쪽 클릭이 개체가 아니라 페이지의 메뉴를 열던 문제. 누르는 순간 드래그가 포인터를
  캡처하고, 캡처된 포인터는 뒤따르는 메뉴 이벤트를 페이지로 보냅니다. 보조 버튼은 이제
  선택만 하고 드래그를 시작하지 않습니다.
- Alt+끌기가 복제 대신 글상자 편집을 열던 문제. Alt를 누른 채 누르는 것은 결코 더블클릭이
  아닙니다.
- 사이드바 기둥이 다크 테마에서 진흙색이 되던 문제(색 혼합이 선형 광에서 이뤄져 12%가
  중간 회색이 됩니다).
