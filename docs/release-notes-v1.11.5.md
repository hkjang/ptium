# Ptium v1.11.5

어제 넣은 **유인물(PDF · 발표자 노트)** 의 노트 영역에 세 가지 구멍이 있었습니다. 셋 다
"노트도 덱의 다른 줄과 똑같이 쓴 글"이라는 한 가지를 빠뜨려서 생긴 것입니다.

## 1. 노트의 마크업이 그대로 찍히고 있었습니다

```
전: 근거는 [분기 보고서](https://reports.example.com/q3)에 있습니다. **꼭** 확인하세요.
후: 근거는 분기 보고서에 있습니다. 꼭 확인하세요.        ← "분기 보고서" 는 눌리는 링크
```

슬라이드 위의 글은 v1.10.3 부터 런으로 쪼개 그리고 있었는데, 유인물의 노트만 **글자를 그대로
그리고** 있었습니다. 이제 노트도 같은 런으로 그립니다 — 굵게·기울임이 적용되고, 링크는 밑줄과
함께 **PDF 링크 주석** 이 붙습니다(종이가 아니라 화면에서 열면 눌립니다).

## 2. 유인물이 출처를 빠뜨리고 있었습니다

PPTX 의 발표자 노트 페이지에는 `!source` 로 적어 둔 출처가 **제목·위치까지** 들어갑니다.
유인물에는 슬라이드에 그려지는 짧은 줄만 있고 그게 없었습니다. 같은 사람이 읽는 같은
문서인데 서로 다른 것을 담고 있던 셈입니다. 이제 **한 함수**(`NotesWithSources`)에서
둘 다 나옵니다.

## 3. 링크 주소를 UTF-16 으로 쓰고 있었습니다

PDF 의 `/URI` 는 ASCII 문자열입니다. 읽는 쪽이 알아서 처리해 주기는 했지만, 규격이 아닌
것을 쓰고 있었습니다. 이제 ASCII 로 쓰고 비ASCII 문자는 퍼센트 인코딩합니다.

## 이걸 어떻게 찾았나

유인물을 릴리즈한 직후, **방금 만든 것에 어제 고친 것과 같은 종류의 구멍이 있는지** 보는
습관대로 노트에 링크를 넣어 뽑아 봤습니다. 바로 나왔습니다.

테스트는 PDF 안의 **압축된 그리기 스트림을 풀어서** 글리프 번호로 검사합니다 — 파일 바이트를
그냥 훑으면 폰트 파일 4MB 안의 우연한 일치를 잡습니다(실제로 처음에 그렇게 잘못 잡았습니다).

## 설치

```bash
gzip -dc ptium-1.11.5.tar.gz | docker load
```
