# Ptium v1.11.0

## PDF 내보내기

내보내기 대화상자의 PDF 줄이 이제 **눌립니다.**

- **한 장에 한 페이지**, 덱과 같은 크기(16:9 덱이면 960×540pt)
- **화면과 같은 그림**입니다. 워크스페이스가 이미 그리고 있는 그 SVG — 썸네일·미리보기·공유
  화면·발표 화면이 쓰는 것과 **같은 그림** — 을 PDF 로 옮깁니다. 레이아웃을 다시 계산하지
  않기 때문에 화면과 종이가 어긋날 수가 없습니다. 실제로 재 봤습니다:

  | 줄 | 화면 (x, y) | 종이 (x, y) |
  | --- | --- | --- |
  | 3분기 실적 | (66.0, 97.6) | (66.0, 97.6) |
  | 매출 12% 성장 | (66.0, 165.6) | (66.0, 165.6) |
  | 첫 줄 | (66.0, 194.1) | (66.0, 194.1) |

- **글자는 글자입니다.** 그림으로 굽지 않아서 복사·검색·선택이 됩니다
- **링크가 살아 있습니다.** 바깥 주소는 그대로, `#3` 같은 덱 안 링크는 그 페이지로 가는
  PDF 링크가 됩니다
- **건너뛴 장은 인쇄되지 않습니다.** 발표에서 넘어가는 장은 배포본에서도 넘어갑니다

`GET /presentations/{id}/export?format=pdf` 로도 같습니다.

## 글꼴은 하나입니다 — 이게 이 기능의 대가입니다

PDF 리더가 반드시 갖고 있는 글꼴 14 종은 **전부 라틴 문자** 입니다. 한글이 든 PDF 는 글꼴을
파일 안에 실어야만 만들어집니다. 그래서 이미지에 **나눔바른고딕**(SIL Open Font License)을
싣고, PDF 는 그 글꼴로 조판합니다.

**템플릿의 글꼴이 아닙니다.** PowerPoint 템플릿은 글꼴의 *이름* 만 담고 파일은 담지 않습니다 —
덱 어디에도 맑은 고딕이 어떻게 생겼는지는 없습니다. 그러니:

- 템플릿 글꼴 그대로가 필요하면 **PPTX** 를 받으세요. 덱의 디자인이 사는 곳은 거기입니다
- 어디서나 열려야 하면 **PDF** 입니다

내보내기 대화상자와 사용 가이드에 이 문장이 그대로 적혀 있습니다. 보내고 나서 알게 되는 것이
아니라 보내기 전에 보이도록.

## 안에서 무슨 일이 있었나

- PDF 를 직접 씁니다(외부 바이너리 없음 — 에어갭 이미지라 넣을 수 없습니다). 텍스트는
  Identity-H 로 글리프를 쓰고, `ToUnicode` 를 함께 넣어 **복사하면 글자가 나옵니다**
- 글꼴은 잘라내지 않고 통째로 싣습니다. TrueType 을 자르려면 외곽선과 그걸 가리키는 표를 전부
  다시 만들어야 하고, 잘못 자르면 **글자가 빠진 파일** 이 됩니다. 4MB 큰 파일보다 나쁩니다.
  문서당 한 번만 들어갑니다(페이지마다가 아니라)
- 실제 PDF 리더로 읽어 확인했습니다: 4페이지, 960×540, 한글 텍스트 그대로 추출, 바깥 링크와
  4페이지로 가는 내부 링크 둘 다 주석으로 존재
- 이미지가 약 4MB 커집니다. 글꼴 파일 값입니다

## 그밖에

- 루트 `node_modules` 의 vitest 캐시 파일 하나가 **저장소에 커밋돼 있었습니다.** 무시 목록에
  넣고 추적에서 뺐습니다.
