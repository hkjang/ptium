# Ptium v0.31.0

## 가져오기가 그림까지 가져옵니다

v0.29에서 기존 `.pptx`를 덱으로 가져오게 됐지만, **사진은 두고 왔습니다.** 논지는 넘어오고
그림은 남는 반쪽짜리 기능이었습니다.

이제 넘어옵니다.

- 각 그림은 **이미지 라이브러리에 저장**되고 새 디자인의 **그림 자리**에 들어갑니다.
- **같은 파일은 한 번만** 저장됩니다(바이트가 같으면 같은 이미지입니다). 여러 장에 쓰인 사진이
  다섯 개의 사본이 되지 않습니다.
- **놓여 있던 좌표는 가져오지 않습니다.** 한 레이아웃을 위해 고른 위치는 다른 레이아웃에서
  의미가 없습니다. 새 디자인이 그림을 위해 비워 둔 자리가 사람이 다시 만들 때 놓을 자리입니다.

**일부러 빼는 두 가지**:

- **절반 이상의 슬라이드에 나오는 그림** = 회사 로고. 슬라이드의 내용이 아닙니다.
- **페이지의 3% 미만**을 차지하는 그림 = 장식.

둘 다 그림 자리를 차지하면 그 슬라이드의 진짜 내용을 밀어냅니다. 몇 개를 넣었는지는 알려 줍니다.

실측: 모든 장에 로고가 있고 진짜 사진 2장이 든 5장짜리 덱 → **로고는 빠지고 사진 2장이
들어왔으며, 덱은 결함 0**.

## 오프라인 설치

```bash
gzip -dc ptium-0.31.0.tar.gz | docker load
sha256sum -c ptium-0.31.0.tar.gz.sha256
```
