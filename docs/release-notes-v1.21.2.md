# Ptium v1.21.2

**한 바퀴 돌려 봤습니다.** 모든 문법을 쓴 덱을 만들고 → `.pptx` 로 내보내고 → 다시
가져와서 → 처음 코드와 **한 줄씩 비교**했습니다.

Ptium이 만든 파일은 **글자 하나 다르지 않았습니다**(내보낸 파일이 자기 코드를 품고 있으니까요).
그래서 **누군가 PowerPoint에서 열어 저장한 경우** — 품고 있던 코드가 사라진 파일 — 로도
돌려 봤습니다. 그림에서 읽어야 하는 그 경우에 **출처가 두 번** 들어왔습니다.

```
!notes 숫자는 출처와 함께 말합니다 출처 2026 시장 조사 보고서 — p.42   ← 노트 안에 한 번
!source 2026 시장 조사 보고서, p.42                              ← 출처로 한 번
```

## 왜 두 번인가

출처는 **나갈 때 두 군데**에 적힙니다 — 슬라이드에 그려지고, **발표자 노트 아래에도** 적힙니다
(발표자가 읽을 수 있게). 들어올 때 둘 다 읽으면 같은 출처가 두 번 들어옵니다.

그걸 막는 장치는 이미 있었습니다. 다만 **"출처"라는 낱말을 앞에서부터 찾고** 있었습니다.
그런데 이 제품의 폐쇄망 작성기가 그런 슬라이드에 붙이는 노트가 하필

> **숫자는 출처와 함께 말합니다**

입니다. 첫 번째 "출처"가 문장 한가운데 있으니 뒤에 오는 것이 인용이 아니고, 그래서 아무것도
지우지 못했습니다. **내보내고 가져올 때마다 한 벌씩 늘어납니다.**

## 고친 것

- **마지막 "출처"부터 거꾸로** 찾습니다. 문장 속의 낱말이 아니라 **인용을 여는 자리**를 찾습니다
- 비교는 **글자와 숫자만**으로 합니다 — 그려질 때는 `보고서 — p.42`, 저장될 때는
  `보고서, p.42` 라서 구두점까지 맞추면 영영 안 맞습니다
- "출처"로 시작해 **다른 말이 이어지는 노트**는 그대로 둡니다(`출처 확인이 필요합니다`)

세 바퀴를 돌려 확인했습니다 — **노트도 출처도 그대로**입니다.
