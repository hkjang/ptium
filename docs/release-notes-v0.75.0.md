# Ptium v0.75.0

지난 판에서 모델에게 `!source` 를 쓸 수 있다고 알려 줬습니다. 이번에는 **그것이 효과가
있었는지 재 봤습니다** — 그리고 재 보길 잘했습니다.

## 측정: 안내는 효과가 있었습니다

세 가지 브리프로 모델 덱을 만들어 인구조사와 같은 방식으로 쟀습니다.

| 브리프 | 점수 | 결과 |
|---|---|---|
| 근거를 밝힌 브리프 | 94 | `!source` 3건 |
| 담당 체계와 준비 상태 | **100** | `::grid` 2건 · 컴포넌트 4개 |
| 근거를 밝히지 않은 브리프 | 99 | `!source` **3건** ← 문제 |

앞의 둘은 지난 두 판의 안내가 그대로 작동한 것입니다. 문제는 셋째입니다.

## 모델이 없는 출처를 지어냈습니다

브리프는 출처를 **하나도** 말하지 않았습니다. 그런데 덱에는 이렇게 붙어 있었습니다.

```
!source 내부 시장 보고서 | 2026-08
!source 고객 경험 분석 데이터 | 2026-07
!source 보안 감사 보고서 | 2026-08
```

안내에 "지어내지 말라"고 적혀 있습니다. 모델은 무시했습니다.

**없는 출처는 없는 것보다 나쁩니다.** 슬라이드 발 밑에 인쇄되고 발표자 노트에 실려 근거처럼
읽히는데, 회의실에서 물어보면 무너지는 유일한 항목이기 때문입니다.

이제 **제품이 확인합니다.** 브리프(다시 쓰기라면 원본 덱)가 뒷받침하지 않는 출처는 지웁니다.

- 비교는 **단어 단위**입니다. `통계청 2026 소비 동향` 은 브리프의 `통계청 2026 소비 동향(표 3)`
  과 맞으므로 남습니다.
- 모든 출처에 들어가는 말 — 보고서 · 자료 · 데이터 · 내부 · 분석 — 은 근거로 세지 않습니다.
  그러지 않으면 "보고서"라는 말 하나로 지어낸 출처가 전부 통과합니다.
- 그런 말만으로 된 출처(`내부 자료`)는 아무것도 인용하지 않은 것입니다.
- 지운 건수는 **덱이 말합니다**: "브리프에 없는 출처 2건을 AI가 지어내 지웠습니다. 필요한
  출처는 슬라이드에 직접 적어 주세요."

**실제 모델로 양쪽을 확인했습니다.**

```
출처 없는 브리프  → 남은 !source 0건 + 위 안내
출처 있는 브리프  → !source 통계청 2026 소비 동향 | 표 3  (그대로 유지, 안내 없음)
```

편집기에서 사람이 직접 적는 출처에는 이 규칙이 적용되지 않습니다. 저자는 무엇이든 인용할 수
있고, 그것이 저자의 몫입니다.
