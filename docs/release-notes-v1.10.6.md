# Ptium v1.10.6

## 발표 중에 링크를 누를 수 있습니다

v1.10.3 에 링크를 넣으면서 이렇게 적었습니다 — "브라우저 발표 화면은 슬라이드 그림이라
누를 수는 없습니다." 그 문장을 지웁니다.

발표 화면이 슬라이드를 **직접 그립니다.** 그림(`<img>`) 안의 것은 무엇도 누를 수 없어서,
같은 서버가 그린 같은 그림을 페이지가 그대로 그리도록 바꿨습니다.

- **바깥 링크** 를 누르면 새 탭에서 열립니다. 발표는 있던 자리에 그대로 있습니다
- **`#3` 같은 덱 안 링크** 를 누르면 그 슬라이드로 넘어갑니다 — 부록을 물어보면 눌러서
  가고, 뒤로 돌아오면 됩니다
- **평소 클릭은 그대로** 다음 장으로 넘어갑니다. 링크를 눌렀을 때만 넘어가지 않습니다

브라우저에서 실제로 눌러 확인했습니다: 3장짜리 덱에서 `#3` 링크를 누르면 `1 / 3` → `3 / 3`,
바깥 링크를 누르면 새 탭이 열리고 발표는 `1 / 3` 에 머무르며, 빈 곳을 누르면 `2 / 3` 로
넘어갑니다.

넘겨 둔 다음 장을 미리 받아 두는 것도 그대로입니다 — 방 앞에서 다음 장을 넘겼는데 로딩이
도는 것은 있을 수 없는 일이니까요.

## 설치

```bash
gzip -dc ptium-1.10.6.tar.gz | docker load
```
