# Ptium v1.23.1

MCP를 **클라이언트처럼** 다시 몰아 봤습니다 — `initialize` → `tools/list` → 만들기 → 생성 →
확인. 전부 정확했습니다(5장 완성, 없는 덱은 `not_found`).

그런데 도구 목록을 읽다가 **에이전트가 덱을 찾을 방법이 없다**는 것이 보였습니다.

```
ptium.list_presentations   받는 것: limit, offset      ← 그게 전부
```

## 3,500개 중에서 하나를 찾아야 합니다

에이전트가 가장 먼저 하는 일은 **어느 덱에 손댈지 고르는 것**입니다. 그런데 목록 도구가 받는
것은 몇 개씩·몇 번째부터뿐이라, "클라우드 전환 로드맵 덱"을 찾으려면 **수천 개를 한 장씩
넘겨봐야** 합니다. 그건 찾는 게 아닙니다.

REST에는 처음부터 있던 검색이 **MCP에만 없었습니다.**

```
ptium.list_presentations { "q": "클라우드" }   →  133개 중 3개
ptium.list_presentations { "q": "존재하지않는말" } →  0개
```

도구 설명에도 적었습니다 — 에이전트가 읽는 유일한 설명서니까요. 문서(`docs/mcp.md`)도
같이 고쳤습니다.

## 검사

도구 목록에 `q` 가 있는지, 그리고 **넘긴 검색어가 실제로 저장소까지 닿는지** 고정했습니다.
전달을 끊으면 그 자리에서 실패합니다.
