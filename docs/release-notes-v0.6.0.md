# Ptium v0.6.0

덱에 이미지를 올릴 수 있습니다. 제안했던 고도화 항목의 마지막입니다.

## 이미지

먼저 업로드하고, 소스에서 이름으로 부릅니다.

```bash
curl -H 'Authorization: Bearer <key>' \
     -F 'file=@logo.png' -F 'name=로고' \
     http://localhost:8080/api/v1/assets
```

```
# 브랜드 자산
@picture
> 로고는 여백 없이 쓰지 않습니다.
::image 로고 | 2026 브랜드 마크
```

- 레이아웃에 그림 영역이 있으면 거기에, 없으면 가장 넓은 본문 영역에 놓습니다.
- 프레임 비율에 맞춰 **가운데를 잘라** 넣습니다(늘리지 않습니다). 내보낸 PPTX에서도
  같은 부분이 보이도록 `srcRect`로 자르고, 미리보기는 같은 결과가 되는 SVG
  `preserveAspectRatio="slice"`를 씁니다.
- 덱은 이미지의 **참조**만 가집니다. 같은 로고를 스무 장에 써도 한 번만 저장되고, 한 곳에서
  바꾸면 전부 바뀝니다.
- 이름으로 부르므로 소스를 사람이 읽을 수 있고, 텍스트로 왕복해도 이름이 유지됩니다.
- 업로드하지 않은 이름은 줄 번호와 함께 경고로 알립니다. 조용히 빠지지 않습니다.
- PNG · JPEG · GIF · SVG, 각 16 MiB까지. 형식은 파일 확장자가 아니라 바이트로 판별합니다.
  계정별로 이름이 유일하며 같은 이름으로 다시 올리면 교체됩니다.
- 내보낸 파일에는 이미지 파트, 슬라이드 관계, `<p:pic>` 도형, 콘텐츠 타입 선언이 모두
  들어갑니다. PowerPoint에서 그대로 편집할 수 있습니다.
- `GET/POST /api/v1/assets`, `GET/DELETE /api/v1/assets/{id}`.

## 고친 결함

- **리드 문장이 두 번 그려졌습니다.** 리드를 본문 영역에 넣고도 슬라이드의 부제로도
  기록해서, 부제 영역이 있는 레이아웃에서 같은 문장이 두 군데 나왔습니다.
- **리드 문장이 사라지는 경우가 있었습니다.** 부제 영역이 없는 레이아웃에서 항목이 하나라도
  있으면 리드가 버려졌습니다. 이제 항목들 앞에 놓입니다.

## 오프라인 설치

```bash
gzip -dc ptium-0.6.0.tar.gz | docker load
sha256sum -c ptium-0.6.0.tar.gz.sha256
```
