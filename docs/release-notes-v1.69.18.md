# Ptium 1.69.18

## 워드 문서의 그림이 말없이 사라졌습니다

워드 문서에서 덱을 만들면 글과 표는 들어오지만 그림은 들어오지 않습니다. 그런데
**들어오지 않았다는 말도 없었습니다.** 사진을 넣어 만든 보고서를 올린 사람은,
사진이 빠진 덱을 받아 들고도 무엇이 빠졌는지 알 방법이 없었습니다.

파워포인트 파일을 가져올 때는 오래전부터 그 말을 해 왔습니다. 워드 쪽만 조용했던
것이라, 같은 문장을 그대로 씁니다.

```
그림 2개는 가져오지 않았습니다. 이미지 탭에서 올려 다시 넣어 주세요
```

워드가 그림을 적는 두 가지 방식(`w:drawing`, 그리고 오래된 파일과 일부 내보내기
도구가 쓰는 `w:pict`)을 모두 셉니다. 그림이 없는 문서에는 이 말이 붙지 않습니다.

## 지키는 장치

`internal/docs/wordpictures_test.go` 가 그림 두 장이 든 문서, 오래된 방식으로 그림을
넣은 문서, 글만 있는 문서를 각각 읽어 말이 붙는지·안 붙는지 봅니다. 되돌려 돌리면
앞의 두 가지가 실패합니다.

## 확인만 하고 고치지 않은 것

이번에 넣어 본 파일 중 나머지는 모두 제대로였습니다.

- **여러 시트 통합문서**: 시트마다 슬라이드가 되고, 숫자 두 열은 막대 차트로
  그려집니다. 각 장에 `시트이름!A1:B3` 으로 출처가 붙습니다
- **병합된 표 칸**: 병합된 머리글의 글자가 한 번만 들어가고 이어지는 칸은 빈 칸으로
  남아, 열이 밀리지 않습니다
