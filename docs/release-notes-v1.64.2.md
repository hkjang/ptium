# 1.64.2 — 표와 카드도 덱의 언어로 말합니다

파워포인트의 모든 글자 조각은 자기가 어느 언어인지 선언합니다. 화면을 읽어
주는 프로그램은 그걸 보고 목소리를 고르고, 파워포인트는 그걸 기준으로 맞춤법을
검사합니다.

영어로 쓴 덱을 내보내면 이런 상태였습니다.

| 슬라이드에 있는 것 | 선언된 언어 |
| --- | --- |
| 글머리 줄 | `en-US` ✓ |
| **표의 칸** | `ko-KR` |
| **KPI 카드** | `ko-KR` |
| **차트 라벨** | `ko-KR` |
| **자유 배치 텍스트 상자** | `ko-KR` |

"Infrastructure", "Throughput" 같은 낱말이 한국어라고 선언되어 있었습니다.
읽어 주는 프로그램은 한국어 목소리로 읽고, 파워포인트는 한국어 맞춤법 오류로
밑줄을 긋습니다.

컴포넌트가 그리는 글자, 표의 칸, 차트의 축과 라벨, 자유 배치 텍스트 상자와 표가
이제 모두 덱의 언어를 씁니다. 영어 덱은 `en-US` 만, 일본어 덱은 `ja-JP` 만,
한국어 덱은 예전 그대로 `ko-KR` 만 선언합니다.

## 확인

- 영어·일본어·한국어 덱을 각각 내보내, 슬라이드 안에 선언된 언어가 한 가지뿐인
  것을 확인했습니다 (영어 26곳 전부 `en-US`).
- 고침을 되돌려 표의 칸 4곳이 다시 `ko-KR` 로 돌아가는 것을 확인했습니다.
