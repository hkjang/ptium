# Ptium v1.17.4

## 합의된 슬라이드가 "1. 회사 소개 및 기술적 우위" 에도 들어갑니다

회사가 승인한 슬라이드를 등록해 두면, 덱이 그 자리를 만났을 때 **회사가 합의한 그 장이
그대로** 들어갑니다. 모델에게도 "이 제목을 **그대로** 쓰라"고 지시합니다.

그런데 모델은 제목에 **번호를 붙이고 살을 붙입니다.** 실제로 이렇게 썼습니다.

```
등록된 이름:  회사 소개
모델이 쓴 제목: 1. 회사 소개 및 기술적 우위
```

이름이 제목의 절반에 못 미쳐서 **승인된 장은 선반에 남고** 모델이 지어낸 회사 소개가
나갔습니다. 회사 표준을 지키자고 만든 기능이 정작 그 순간에 작동하지 않았습니다.

이제 **번호와 덧붙인 말을 감안해서** 알아봅니다. 다만 느슨해지지 않도록 세 가지를 함께
요구합니다.

- 제목이 **그 이름으로 시작**해야 합니다(앞의 `1.`, `제2장` 은 넘어갑니다)
- 제목이 이름의 **세 배를 넘지 않아야** 합니다
- 그 이름을 가진 등록 슬라이드가 **하나뿐**이어야 합니다

그래서 이런 것들은 **여전히 바뀌지 않습니다**: `회사 소개를 곁들인 2026년 상반기 사업
계획과 조직 개편 보고`(지나가는 말), `2026년 계획과 예산`(`계획` 은 이름이라기엔 흔한 말),
`회사 소개 상세 및 연혁`(후보가 둘이면 아무것도 넣지 않습니다). **틀린 장을 방 앞에 세우는
것은 아무것도 안 하는 것보다 나쁩니다.**

## 알게 된 것 하나

같은 시험을 여러 번 돌려 보니, 모델이 **아예 다른 제목**을 쓰는 경우도 있었습니다
(`Ptium의 검증된 역량과 신규 사업의 시너지`). 이때는 알아볼 이름 자체가 없습니다.
브리프가 등록 슬라이드를 이름으로 부른 경우 **합의된 장을 제품이 직접 끼워 넣는** 방법이
있는데, 덱의 길이와 흐름을 바꾸는 일이라 이번에는 넣지 않았습니다.

## 설치

```bash
gzip -dc ptium-1.17.4.tar.gz | docker load
```
