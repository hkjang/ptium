# Ptium v1.17.1

## `!build` 를 버튼으로도 켭니다

1.17.0 에서 넣은 "요점을 한 줄씩" 은 **원문에 `!build` 를 직접 적어야만** 켤 수 있었습니다.
원문 보기를 여는 사람은 많지 않습니다.

이제 슬라이드 도구 줄에 버튼이 있습니다 — **복제 · 요점을 한 줄씩 · 건너뛰기 · 삭제**.
누르면 원문에도 `!build` 가 들어가고, 원문에 적혀 있으면 버튼이 눌린 상태로 보입니다.
어느 쪽으로 켜도 같은 한 가지입니다.

## 확인

- 브라우저: 버튼을 눌러 저장하면 슬라이드와 원문 양쪽에 남고, 다시 누르면 사라집니다
- 스윕: 원문이 `!build` 인 덱을 편집기에서 열면 그 버튼이 눌린 상태여야 합니다

## 설치

```bash
gzip -dc ptium-1.17.1.tar.gz | docker load
```
