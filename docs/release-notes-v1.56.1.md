# Ptium v1.56.1

**구성요소의 캡션이 소스를 다시 쓸 때마다 백슬래시를 하나씩 더 달고 있었습니다.**

## 어제 낸 흠부터

v1.56.0은 차트의 계열 이름을 지키게 했습니다. 그런데 그 이름을 **`escapeItemField`**로
적었습니다 — 그건 `|`로 나뉜 행의 칸을 지키는 도구입니다. 캡션은 줄 끝까지 이어지는
자리라 나눌 칸이 없습니다.

```
파일에 있던 '매출|비용'   →  덱에 들어온 '매출\|비용'
파일에 있던 '경로\합계'   →  덱에 들어온 '경로\\합계'
```

아무도 치지 않은 백슬래시가 덱에 들어갔습니다.

## 고치려다 더 오래된 것을 찾았습니다

올바른 도구를 찾으러 기존 작성기를 봤더니 거기는 **`escapeSourceLine`**을 쓰고
있었습니다. 줄이 `#`이나 `\`로 시작할 때 그 줄을 지키는 도구입니다. 그런데 캡션은
`::종류 ` 다음에 오므로 **줄 첫머리에 서는 일이 없습니다.** 지킬 것이 없는데 표시를
붙이고, 파서는 그것을 되돌리지 않습니다.

그래서 쌓였습니다.

```
소스를 1번 다시 쓰고 나면: "\# 매출"
소스를 2번 다시 쓰고 나면: "\\# 매출"
소스를 3번 다시 쓰고 나면: "\\\# 매출"
소스를 4번 다시 쓰고 나면: "\\\\# 매출"
```

슬라이드를 고칠 때마다 소스가 슬라이드로부터 다시 쓰이므로, `#`이나 `\`로 시작하는
캡션은 **덱을 만질 때마다** 백슬래시가 하나씩 늘어납니다.

이 길은 저장된 소스가 슬라이드와 어긋났을 때만 지나가므로, 어제의 왕복 측정에는
걸리지 않았습니다. 직접 그 함수를 불러 보고서야 나왔습니다.

## 고친 것

캡션 자리를 위한 도구 하나를 두고 두 작성기가 함께 씁니다. 줄바꿈만 펴고, 나머지는
건드리지 않습니다 — 그 자리에서는 어느 글자도 표시가 아니기 때문입니다.

```
파일에 있던 '매출|비용'    →  덱에 들어온 '매출|비용'
파일에 있던 '경로\합계'    →  덱에 들어온 '경로\합계'
파일에 있던 '# 매출'      →  덱에 들어온 '# 매출'
소스를 네 번 다시 써도    →  '# 매출'
```

* 파워포인트가 쓴 차트 네 개의 계열 이름을 브라우저 없이 파일로 확인
