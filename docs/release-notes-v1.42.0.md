# Ptium v1.42.0

**브리프에 사실을 적으면, 그 사실이 슬라이드 제목이 되어 잘려 나갔습니다.**

## 좋은 브리프일수록 나쁜 덱이 나왔습니다

```
사내 PostgreSQL 전환 타당성 검토 결과를 경영진에게 보고해줘.
현재 오라클 라이선스가 연 4억이고, 전환 대상은 리포팅 DB 12개,
목표는 2026년 3분기 완료야.
```

여덟 장 중 세 장의 머리글이 이렇게 나왔습니다.

| | 제목 |
| --- | --- |
| 5장 | **현재 오라클 라이선스가 연** |
| 6장 | **전환 대상은 리포팅 DB** |
| 7장 | **목표는 2026년 3분기 완료야** |

`연 4억`에서 숫자만 뽑혀 나가고 `연`이 남았습니다. `12개`는 제목 정리 과정에서
잘렸습니다. 마지막은 브리프 문장이 반말 어미까지 그대로 올라간 것입니다.

**같은 절이 두 번 쓰이고 있었습니다** — 한 번은 수치로(제대로), 또 한 번은
아무 말도 하지 않는 제목으로.

그리고 이 덱의 측정 점수는 **99점**이었고, 지적은 한 건도 없었습니다.

## 문법이 갈라 줍니다

절 하나가 "구간 이름"인지 "사실 서술"인지는 내용이 아니라 문법이 정합니다.
구간 이름은 명사구이고, 사실 서술은 **주어와 서술어**를 갖습니다. 둘 다 요구합니다.

- 주어 표지만으로는 부족합니다 — `위험은 무엇인가` 같은 질문형 주제를 같이 지웁니다.
- 수치만으로도 부족합니다 — `클라우드 비용 최적화 3개년 로드맵` 을 같이 지웁니다.

그래서 **표지된 주어가 있고**(…은/는/이/가) **그 절이 서술어로 끝나거나 그 절에서
수치가 이미 읽혔을 때만** 제목 후보에서 뺍니다.

## 사실은 사라지지 않습니다 — 제자리로 갑니다

같은 브리프를 다시 생성한 결과:

```
1. 사내 PostgreSQL 전환 타당성 검토 결과      부제: 2026년 3분기 · 임원
2. 전환 타당성 검토 결과                     KPI: 연 4억 · 리포팅 DB 12개
3. 전환 타당성 검토 결과 — 이행 순서
4. 전환 타당성 검토 결과 — 비용과 효과
5. 전환 타당성 검토 결과 — 리스크와 대응
6. 결정이 필요한 사항
7. 실행 준비 상태
8. 다음 단계
```

브리프가 말한 `4억`·`12개`·`2026년 3분기`가 전부 덱 안에 있습니다 — 잘린 제목이
아니라 KPI와 부제로.

여러 주제를 실제로 나열한 브리프는 그대로 나뉩니다:
`채용 계획, 교육 계획, 평가 제도 개편` → 세 구간. 이 점도 테스트로 고정했습니다.
